## Overview

**パターン名：** skill-matrix-dot-table
**概要：** スキル（行）×担当（列）の対応を3段階のドット（●／◐／○）だけで一覧するマトリクス表。罫線は横1本だけで、ヘッダーは英字ラベル＋日本語、下に凡例を添える
**適したシーン：** 体制のスキル分布、サービス・プラン・機能の対応比較、対応可否チェックリストの提示

## Structure（構造）

コンテンツエリア（左右余白48px）に表と凡例を置き、まとめて上下中央にする。列構成は「行見出し（左端1列・幅240px）」＋「担当（4列・等幅）」。ヘッダー行は各列に英字ラベル（10px）と日本語（16px・太字）を縦に重ね、1列目は左ぞろえ、担当列は中央ぞろえ。行は5行（高さ52px）で、行見出しは16px・太字。データセルは文字を持たず、3段階のドット（●＝アクセント塗り／◐＝左半分だけ塗り／○＝1.5pxの罫線色の枠）を中央に1つ置く。罫線は横の1px（罫線色）だけで、縦罫線・ヘッダーの面塗りは持たない。表の下に凡例（11.5px・muted）を1行添える。ドットは面の塗りに数えない。

    structure:
      layout: data-table (matrix) + legend
      columns:
        - row-label (skill name, left, 240px)
        - member-1..member-4 (dot cell, centered, equal width)
      header-row:
        kicker: english label (10px)
        label: japanese (16px, bold)
        fill: none
      rows: 5 (height 52)
      rules: horizontal 1px only (line color)
      cell_values:
        - full-dot (アクセント塗り)
        - half-dot (左半分だけ塗り)
        - empty-dot (1.5px line-color ring)
      legend: below table (11.5px, muted)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | ヘッダー行の上段 | `Director`・`Designer` のように列の役割を英字で示す（アクセント色） |
| 列見出し | ヘッダー行の下段（16px・太字） | 担当者名・プラン名など、列が何かを示す |
| 行見出し | 各行左端（16px・太字） | 比較対象のスキル・機能・項目名 |
| ドットセル | 各行×各列の交点（中央） | ●（ひとりで担当できる）／◐（補助があればできる）／○（これから習得）の3段階を記号だけで表す |
| 横罫線 | ヘッダーと各行の下 | 行の境界。縦罫線は引かない |
| 凡例 | 表の下（11.5px・muted） | 3段階のドットの意味を1行で説明する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-skill-matrix-dot-tableのレイアウトで、[5つのスキル]×[4人の担当]の対応表を作成してください。ヘッダーは英字ラベル（役割）＋日本語（名前）、各セルは●（できる）／◐（補助があれば）／○（これから）の3段階だけで表し、表の下に凡例を1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- セルの中に説明文字を入れない。ドット1つで完結させる（可読性と再現性のため）
- 行は5行、列は4〜5列までが可読性を保てる上限。それ以上は表を分割するか項目を統合する
- 凡例は必ず付ける（ドットの意味は表の外で一度説明する）。凡例の文言は内容に合わせて書き換えてよい
- ●・◐・○の使用頻度が偏りすぎると一覧性が下がるため、実データの傾向をそのまま反映させる（見た目のために操作しない）
- 列を「担当」でなく「プラン」にすれば対応比較表としても使える。その場合も面の塗りや縦罫線は足さない
