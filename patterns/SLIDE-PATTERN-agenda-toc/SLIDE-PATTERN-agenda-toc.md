# SLIDE-PATTERN-agenda-toc

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
目次は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・セクションと同じ扱い）。

## Overview

**パターン名：** agenda-toc
**概要：** 左上に小さな英字ラベル（AGENDA ／ 目次）、その下に「2桁の番号｜細い縦罫線｜項目名 …… 頁」の行を等間隔で縦に積む1カラム目次。番号だけアクセント色、点線リーダーと頁参照は細く薄く添え、塗りは使わない。
**適したシーン：** プレゼンテーションの目次・アジェンダスライド。章立てのある資料の冒頭や、セクション区切りの案内。頁参照を添えたいとき。

## Structure（構造）

コンテンツエリア（左右余白48px）の全幅に、上から「英字ラベル（KICKER）」「番号付きの行」を積んだ1カラム構成。行は左から「番号｜細い縦罫線｜項目名｜点線リーダー｜頁」で、番号と項目名の1行目の高さを合わせる。行の束は本文エリアの上下中央に置き、項目数が変わっても上下の余白は均等にする。

    structure:
      layout: single-column
      area: 本文エリア（上下中央）
      header:
        kicker: "Agenda ／ 目次"      # 10px / 700 / 字間 .18em / 大文字 / アクセント色
      list:
        items: 3〜6行（gap 28px・行高 28px）
        item:
          - number: 2桁ゼロ埋め        # 24px / 400 / アクセント色。幅 48px
          - vline: 1px × 22px          # var(--sk-line)。左右余白 12px / 20px
          - title: 項目名              # 16px / 400 / 字間 .1em / インク色。1行（折り返さない）
          - leader: 点線               # 1px dotted var(--sk-line)。項目名と頁の間を埋める
          - page: "p.n"                # 11.5px / 400 / muted 色。右端
      fill: none

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 行の束の左上 | 目次であることを示す小さな英字ラベル（`Agenda ／ 目次`）。アクセント色 |
| 番号（01〜） | 各行の左端（24px・細め） | 章の順序。このスライドで唯一の大きなアクセント色 |
| 縦罫線 | 番号と項目名の間 | 1pxの細い罫線（`--sk-line`）。番号と項目名を区切る |
| 項目名 | 縦罫線の右 | 章タイトル。16pxで1行に収める |
| 点線リーダー | 項目名と頁の間 | 視線を右端の頁へ導く。細く薄く（`--sk-line`） |
| 頁（p.n） | 各行の右端（11.5px・薄く） | 対応するページ。省略してよい（省略時は点線も外す） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-agenda-tocのレイアウトで、目次スライドを作成してください。項目は 01 [章名] p.[n]、02 [章名] p.[n]、…の順に書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 項目は3〜6個。7個以上は行間が詰まるので、章を束ねるか2カラム系の目次（toc-two-column 等）を検討する
- 項目名は1行（全角20文字程度）に収める。長い場合は言い切りに削る（文字を小さくしない）
- 頁参照が不要なら `p.n` と点線リーダーをまとめて外す。番号・縦罫線・項目名だけでも成立する
- 塗りは使わない。アクセント色は英字ラベルと番号だけ（縦罫線・点線は `--sk-line`、頁は `--sk-muted`）
- 項目数が減っても行の束は上下中央のまま（上に張り付けない）

## v2 での描き直し（2026-09-02）

- 28pxの太字タイトル「目次」と11pxグレーの「AGENDA」を、10px・.18em・アクセント色の英字ラベル1行（`Agenda ／ 目次`）に置き換え、行の束を本文エリアの上下中央に置いた
- 行を「番号（24px・400・アクセント色）｜1px縦罫線｜項目名16px」の型にそろえ、番号の太字と文字の `|` 区切りをやめた
- 点線リーダーと頁参照は残しつつ `--sk-line`／`--sk-muted` の11.5pxに細く薄くし、`.slide` の文字の組み（palt・字間.06em・インク色）と左右余白48pxに合わせた
