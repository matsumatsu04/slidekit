# SLIDE-PATTERN-gap-to-essence-conclusion

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** gap-to-essence-conclusion
**概要：** 左ゾーン（薄グレー地）に現状を示す白カード2枚を縦に置き、間の上下対の小矢印で「対立・ギャップ」を示す。中央の右向き大矢印を挟み、右ゾーン（淡アクセント地）に本質を番号バッジ付きの白カード3枚で列挙する。最下部に全幅1行の結論バンドを置く。
**適したシーン：** 現状分析から本質・結論への橋渡し、課題の構造化、コンサル型の論点整理。

## Structure（構造）
- 本体は左右2ゾーン＋下部の結論行
  - 左ゾーン（薄グレー地・角丸12px・幅約45%）
    - 上部中央に小見出し
    - 白カード「上」（タイトル＋箇条書き2行）
    - 上下対の小矢印（対立・ギャップを示す。差し色を使うならここ1箇所）
    - 白カード「下」（枠線強調＝アクセント系1.5pxボーダー。タイトル＋箇条書き3行）
  - 中央: 右向き大矢印（グレー）
  - 右ゾーン（淡アクセント地・角丸12px・残り幅）
    - 上部中央に見出し（鉤括弧付きキーワード）＋補足2行（一部強調スパン）
    - 白カード3枚縦（丸番号バッジ＋太字の項目名＋右端に小さめの補足）
- 下部: 結論バンド（全幅1行・太字中央揃え。鉤括弧内キーワードと「＝」の右側に強調スパン）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 現状カード（上） | 左ゾーン上 | 現状の一方の側面（例. 建前・期待） |
| ギャップ矢印 | 左ゾーン中央 | 上下カードの対立・ギャップを示す |
| 現状カード（下・枠線強調） | 左ゾーン下 | 現状のもう一方の側面（例. 実態・課題）。枠線で注目させる |
| 右向き大矢印 | 中央 | 現状→本質への読み進み |
| 本質リスト × 3 | 右ゾーン | 本質を構成する要素の列挙（番号バッジ＋項目名＋補足） |
| 結論バンド | 最下部・全幅 | スライドの言い切り1行 |

## Usage Guide（AIへの使い方）
- 左は「対立する2つの現状」、右は「そこから導く本質3点」、下は「結論1行」という3段の読み順を崩さない
- 結論バンドは1行に収める（長くなるなら本文を削る）
- 強調スパンは右ゾーンの補足と結論バンドに限定し、合計1〜2箇所に抑える
- 上部のメッセージはメッセージライン（sk-msg）と併用するとよい（パターン自体に大見出しは持たない）
- 単純な「課題→解決」の2ゾーンだけなら problem-solution を検討する。本パターンは「現状内の対立」と「結論バンド」を持つ点が違い
