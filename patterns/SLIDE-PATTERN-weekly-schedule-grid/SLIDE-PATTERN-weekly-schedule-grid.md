## Overview

**パターン名：** weekly-schedule-grid
**概要：** 列＝月〜金、行＝午前・午後・夜の3帯で組む週間グリッド。列見出しは KICKER（`MON ／ 月`）、行見出しは帯の名前（16px太字）＋時間帯の注記。セルは横1pxの罫線だけで区切り（縦罫線・面の塗りは置かない）、予定は淡い地・角丸6px・14pxのチップをセル幅いっぱいのブロックで上ぞろえに積む。塗りは今週の要になる予定1つだけ（白文字）。下に注記を1行添える。
**適したシーン：** 週間の稼働イメージ・標準スケジュールの提示、業務時間割の共有、コンサル/講座の週間サポート体制の説明

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 列見出し（KICKER） | 最上段・5列 | `MON ／ 月` のように英字＋日本語で曜日を示す |
| 行見出し | 左端列 | 帯の名前（午前・午後・夜）16px太字＋時間帯の注記 |
| 横罫線 | 列見出しの下・各帯の下 | 帯の境界（1px・罫線色）。縦罫線は引かない |
| 予定チップ | 各セル内・上ぞろえ | 予定名を淡い地の角丸チップで示す（1セル2個まで） |
| 塗りチップ | 全体で1つ | 今週の要になる予定（白文字）。1枚に1つだけ |
| 空きセル | チップの無いセル | 予定が無い時間帯。何も置かない |
| 注記 | 表の下 | 「例：〜」で塗りの意味や運用ルールを1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-weekly-schedule-gridのレイアウトで、月〜金・午前／午後／夜の週間スケジュールを作成してください。各セルに予定を1〜2個のチップで置き、水曜午後の「お客様定例」だけを塗ってください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 行は3帯（午前・午後・夜）が基本。1時間刻みのように行を増やさない（細かい時間割は枚数を分けるか、day-timeline-single-bar を使う）
- チップは1セル2個まで。3個以上になるなら文言をまとめる
- チップの文言は短い体言止め（7文字以内）。長文を入れない（文字を小さくしない）
- 塗りは1つだけ。曜日ごとに色分けしたり、種類ごとに塗り分けたりしない
- 旧版の「1時間刻み9行・破線の横罫線・縦罫線・soft塗りのヘッダー帯・左辺バー付きブロック」は廃止
