# SLIDE-PATTERN-alternating-milestone-timeline

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** alternating-milestone-timeline
**概要：** 本文エリアの垂直中央に1pxの幹線（罫線色）を引き、12pxの白丸ノード（1.5px 罫線色の枠）5つを等間隔に置く。各ノードから上下交互に短いステム（1px・28px）を伸ばし、その先に「日付（KICKER）→ 見出し16px太字 → 説明14px muted」のブロックを中央ぞろえで付ける。塗りは「今ここ（最新）」のノード1つだけ。写真・アイコンは使わず、線とテキストだけで構成する。
**適したシーン：** 沿革・長期ロードマップ。項目数が多い時系列を、上下振り分けで密度高く読ませる場面。

## Structure（構造）

コンテンツエリア（左右48px）の上下中央に、高さ固定（288px）のタイムラインを置く。幹線とステムは1枚のSVGで引き、ノードとテキストブロックはそれと同じ「%」の位置に絶対配置する（文言の長さで端点がずれない）。幹線の端点は最初と最後のノードの中心（10%・90%）で止める。

    structure:
      layout: alternating-milestone-timeline
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      timeline:
        height: 288px               # 幹線は中央（144px）
        lines: single-svg           # 幹線＋ステムを1枚のSVGで引く（1px・var(--sk-line)）
        trunk:
          from: first node center   # 10%
          to: last node center      # 90%
        stems:
          length: 28px              # ノード中心から上（奇数番目）／下（偶数番目）へ
      nodes:
        count: 5                    # 標準。4〜6で同じCSSが使える（位置の % を等間隔に振り直す）
        positions: [10%, 30%, 50%, 70%, 90%]
        shape: circle 12px          # 白丸・1.5px 罫線色の枠。幹線の上に載る
        surfaces:
          default: outline-line
          now: accent_fill          # 「今ここ（最新）」の1つだけ塗り
      items:
        width: 168px                # ノード中心に対して中央ぞろえ
        offset: 32px                # 幹線からブロックの端まで（ステム28px＋余白4px）
        order: [up, down, up, down, up]
        elements:
          - kicker: "2026.04"       # 10px / 700 / .18em / muted。今ここは "2026.10 ／ 今ここ" でアクセント色
          - heading                 # 16px / 700（6文字以内）
          - body: 1 line            # 14px / 400 / muted（10文字以内）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 幹線 | 垂直中央の水平線（1px・罫線色） | 時間軸。端点は最初と最後のノードの中心で止める |
| ステム | 各ノードから上下交互（1px・28px） | ノードとテキストブロックをつなぐ枝線。長さは全部同じ |
| ノード | 幹線上に等間隔5つ（12px白丸） | 各出来事の接続点。「今ここ」の1つだけアクセント塗り |
| 日付（KICKER） | ブロックの最上段 | `2026.04` 形式の年月。muted。今ここは `2026.10 ／ 今ここ` でアクセント色 |
| 見出し | 日付の下（16px・700） | 出来事の名称（6文字以内） |
| 説明 | 見出しの下（14px・muted） | 内容の補足を1行（10文字以内） |

## Usage Guide（AIへの使い方）

> 「SLIDE-PATTERN-alternating-milestone-timelineのレイアウトで、導入プロジェクトの5つの節目（キックオフ→要件確定→試作→本番導入→効果測定）を年月つきで示してください。本番導入を「今ここ」として塗り、他は白丸のままにしてください。各ブロックは日付・見出し（6文字以内）・説明1行（10文字以内）の順で書いてください。デザインはSLIDE.mdに従ってください。」

- 塗るのは「今ここ（最新）」のノード1つだけ。全部を塗ったり、完了分をまとめて塗ったりしない
- ノードは4〜6個。7個以上は文字が入らないので期間を分けて2枚にする。数を変えるときは、SVGの線・ノード・ブロックの `%` を等間隔に振り直す（例: 4個なら 12.5% / 37.5% / 62.5% / 87.5%）
- 上下の順は「1つ目＝上」から交互。ステムの長さは変えない（旧版の「長さを循環させる」は廃止）
- 見出しは6文字・説明は10文字以内。入らなければ文言を短くする（文字を小さくしない）
- 旧版の「ドット10個・2pxの幹線・長さの違うステム・9pxの説明」は廃止

## v2 での描き直し（2026-09-03）
- ドット10個・2pxの幹線・長さの違うステムを、5つの12px白丸ノード＋1pxの幹線＋同じ長さのステム（1枚のSVG）に変え、端点を最初と最後のノードの中心で止めた
- 全ノードをアクセント塗りにしていたのをやめ、「今ここ（最新）」の1つだけ塗りにした（塗りは1枚に1つ）
- テキストを「日付（KICKER・10px）／見出し16px太字／説明14px muted」の型に揃え、幅168pxのブロックとして中央ぞろえにした
