# SLIDE-PATTERN-alternating-milestone-timeline

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** alternating-milestone-timeline
**概要：** 本文エリアの垂直中央に水平線を引き、ドット10個前後を等間隔に置く。各ドットから上下交互に長さの違う縦ステムを伸ばし、先端に「年号太字＋出来事1〜2行」のテキストブロックを付ける。写真・アイコンは使わず、線とテキストだけで構成する。
**適したシーン：** 沿革・長期ロードマップ。項目数が多い時系列を、上下振り分けで密度高く読ませる場面。

## Structure（構造）
- 水平線: 本文エリアの垂直中央。最初のドット中心から最後のドット中心まで（コンテンツ幅いっぱいに伸ばさない）
- ドット: 等間隔に10個前後（上限12個）
- 縦ステム: 各ドットから上下交互に伸ばす。長さは数種類を循環させて隣接ブロックの高さをずらす
- テキストブロック: ステム先端に接続。年号（太字）＋出来事1〜2行。上側ブロックは年号を下（ステム側）に置く

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 水平線 | 垂直中央 | 時間軸の幹線。端点は両端ドットの中心で止める |
| ドット | 線上に等間隔 | 各出来事の接続点 |
| 縦ステム | ドットから上下交互 | 出来事ブロックと幹線をつなぐ枝線（長さは交互に変える） |
| 年号 | ブロックのステム寄り | 太字の年表示 |
| 出来事 | 年号に隣接 | 1〜2行の短い説明文 |

## Usage Guide（AIへの使い方）
- 項目は最大12まで（超えると読めない。多い場合は期間を分けて2枚にする）
- 出来事の説明は1〜2行・20文字前後まで。長文はこのパターンに載せない
- ステムの長さを2〜3種類で循環させ、隣り合うブロックが同じ高さに並ばないようにする
- 項目数を減らす場合もドットは等間隔を保ち、線の端点は両端ドットの中心に合わせ直す
