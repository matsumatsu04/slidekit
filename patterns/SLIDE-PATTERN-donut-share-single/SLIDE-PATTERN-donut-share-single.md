# SLIDE-PATTERN-donut-share-single

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** donut-share-single
**概要：** 左に大きなドーナツ1つ（SVG の `circle` を2本重ねる。太さ20px・面塗りなし。下は残り分＝罫線色、上は主要セグメント＝アクセント色の弧で、`stroke-dasharray` を静的に計算し-90°回して12時から始める）、中央に割合（28px/700・tabular-nums）とKICKER。右に見出し・凡例2行・説明・注記を置く。
**適したシーン：** 市場シェア・構成比・利用率など「全体の中の割合」を1つだけ見せる場面。

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、ドーナツ列と説明列の行を置く。列同士は上ぞろえ。

    structure:
      layout: 2 columns（左＝ドーナツ240px固定／右＝凡例と説明・可変）
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        gap: 48px
        align_items: flex-start     # 列同士は上ぞろえ
      donut:                        # SVG 240×240・circle r=100・stroke-width 20（面塗りなし）
        track: "var(--sk-line)（残り分）"
        value: "var(--sk-accent)、stroke-dasharray「達成長 628.319」、rotate(-90deg)"
        # 達成長 = 割合 × 628.319（例: 62% → 389.56）。<script> は使わず静的に書く
        center:
          - kicker: "英字ラベル（10px / 700 / .18em）"
          - number: "割合（28px / 700 / tabular-nums）"
      info:                         # 右カラム
        elements:
          - kicker: "英字ラベル（10px / 700 / .18em）"
          - title: "見出し（18px / 700）"
          - rule: "細罫線（1px・var(--sk-line)）"
          - legend:
              rows: 2               # 行高44px・2行目に上罫線・ブロックの下にも罫線
              chip: "12px角。1つはアクセント塗り、もう1つは var(--sk-line)"
              label: "セグメント名（16px / 400）"
              value: "割合（16px / 700 / tabular-nums・右ぞろえ）"
          - body: "本文 16px / 400 / 行間1.8"
          - note: "例：〜（11.5px・muted）"

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| ドーナツ | 左 | 割合を弧の長さで見せる。主要セグメントはアクセント色、残りは罫線色（塗り面は持たない） |
| 中央の数値＋KICKER | ドーナツ中心 | 結論の割合（28px・太字）。英字ラベルを上に小さく添える |
| 見出し | 右カラム上部 | 「その割合が何を意味するか」を1行で言い切る |
| 凡例 | 見出しの下 | 12px角のチップ＋セグメント名＋割合。色とセグメントの対応を示す |
| 説明 | 凡例の下 | 内訳の差（単価・所要日数など）を2〜3行で補足 |
| 注記 | 最下部 | 「例：」で集計期間・母数の定義を1行 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-donut-share-singleのレイアウトで、受注の内訳（紹介・継続契約62% / 広告・問い合わせフォーム38%）を描いてください。中央は KICKER: SHARE / 数値: 62%。右は 見出し: 受注の6割は、紹介と継続契約から生まれている / 説明: 〜 / 注記: 例：FY26上期・受注件数ベースの構成比。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 弧の長さは表示する割合と一致させる（`stroke-dasharray` の第1値 = 割合 × 628.319）。数値・凡例だけ変えて弧を変え忘れない
- セグメントは2つまで（3つ以上に分けるなら kpi-donut-chart-grid か横棒のパターンへ）
- アクセント色を使うのは「弧」と「凡例の主要チップ」だけ。中央の数値・ラベルはインク色のままにする
- 主要セグメントが50%を大きく下回るときは、中央の数値と見出しの主語をそろえる（何の割合かを言い切る）
- 12時始まり・時計回りを崩さない（`transform-origin` は円の中心）

## v2 での描き直し（2026-09-04）
- `conic-gradient` の円盤＋白抜き円のドーナツを、SVGの `circle` 2本（太さ20px・主要セグメントはアクセント色の弧・残りは罫線色・`stroke-dasharray` を静的計算）に描き直し、面塗りをなくした
- 中央を KICKER＋割合28px/700 tabular-nums に組み直し、右カラムを「KICKER → 見出し18px/700 → 細罫線 → 凡例2行（12pxチップ＋16pxラベル＋値）→ 本文16px → 例：注記11.5px」の型にそろえた
- 凡例のチップを12px角（アクセント塗り／罫線色）にし、文字をv2の表（字間.06em・インク色・太さ400/700）にそろえた
