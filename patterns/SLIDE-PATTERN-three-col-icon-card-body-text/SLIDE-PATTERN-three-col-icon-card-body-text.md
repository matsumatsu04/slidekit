## Overview

**パターン名：** three-col-icon-card-body-text
**概要：** 本文を3〜4行たっぷり書く3列カード。淡い地の等高カードに「小さなアイコン→英字ラベル→見出し→細罫線→本文3〜4行→例：」の型で組み、中央の1枚だけ塗りで主役にする
**適したシーン：** 課題・問題点・よくあるつまずきを3つ列挙して説明するスライド。各項目に2文程度の説明を添えたいとき（本文が短いなら three-column-icon-card）

## Structure（構造）

コンテンツエリア（左右余白48px）を3等分した等高カード（352px・gap 16px・角丸11px・`--sk-soft` 地）で構成する。中身は左ぞろえ・上ぞろえで、上から「小さなアイコン（20px・白の丸地40px）」「英字ラベル（KICKER）」「見出し（18px・太字）」「細罫線」「本文（16px・3〜4行）」「例：の注記」の順に置く。3枚のうち中央だけを塗りカード（白文字・罫線は白の半透明）にして主役を示す。カード群は本文エリアの上下中央に置く。three-column-icon-card との違いは、カードが淡い地で本文が3〜4行あること。

    structure:
      layout: three-equal-columns
      cards:
        equal_height: true (352px)
        gap: 16
        background: soft
        emphasis: center (filled, 1 of 3)
      card:
        order:
          - icon (20px, in a small white circle)
          - kicker (english label + japanese supplement)
          - heading (18px, bold)
          - thin-rule
          - body (16px, 3-4 lines)
          - note ("例：" 11.5px)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| アイコン | 各カード左上（40pxの白い丸地に20px） | 項目を一目で識別させる小さな目印。主張させない |
| 英字ラベル（KICKER） | アイコン下 | `Before ／ 着手前` のように英字＋日本語補足で項目の分類を示す。アクセント色 |
| 見出し | ラベル下（18px・太字） | 項目のキーワード（10字前後） |
| 細罫線 | 見出しと本文の間 | 見出しと本文の切り替え。塗りカード内は白の半透明線 |
| 本文 | 罫線下（16px・3〜4行） | 状況と対処を2文で。1文目に問題、2文目に直し方 |
| 注記（例：） | 本文下（11.5px・薄く） | 具体例を1行で添える |
| 塗りカード | 中央 | 3項目の主役。1枚のスライドで塗りは1つだけ |

このパターンをAIに指示する際のプロンプト例：

**注意点：**
- 本文は3〜4行（カード幅1行13字前後・40〜50字）。5行になるなら文字を小さくせず、文言を削るか枚数を分ける
- 塗りは中央の1枚だけ。他の2枚まで塗らない（強調が散る）
- アイコンは Font Awesome Solid を20pxで使う。大きな図版・写真にしない（主役は本文）
- 本文が2行以内で済むなら three-column-icon-card、見出しに一言添えたいなら three-card-icon-with-subheading を使う
