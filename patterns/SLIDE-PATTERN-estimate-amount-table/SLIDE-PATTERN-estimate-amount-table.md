# SLIDE-PATTERN-estimate-amount-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** estimate-amount-table
**概要：** 見積の明細を「項目／内容／数量／単価／金額」の5列で示す金額表。ヘッダーは英字ラベル（10px）＋日本語（14px）の2段で塗らず、行は横の細い罫線（`--sk-line`）だけで区切る。数量・単価・金額は右ぞろえの等幅数字。表の下に合計行を1つ置き、そこだけ淡い地（`--sk-soft`・角丸6px）にして合計金額を20px・太字・アクセント色で見せる。下に「例：〜」の注記（税別・有効期限など）を1行添える。
**適したシーン：** 概算見積・料金提示・費用内訳の説明スライド、提案書の見積ページ、数量×単価で金額の根拠を見せたい明細。

## Structure（構造）

コンテンツエリア（左右余白48px）に、表→合計行→注記を縦に並べ、まとめて上下中央にする。表は本物の `<table>` で、ヘッダーはKICKER英字＋日本語の2段（塗りなし・下罫線だけ）、データ行は高さ48px・横罫線だけ。合計行は表の8px下に置く淡い地の1行（角丸6px）で、左に「合計」、中に税区分の小さな注記、右端に20pxのアクセント色の金額。塗り（アクセント色の面）は持たない。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 列見出し | 表の最上行 | `Item` ＋「項目」のように英字ラベル＋日本語の2段で列の意味を示す。塗らない |
| 項目名 | 最左列 | 行の主語（16px・太字） |
| 内容 | 2列目 | 何をするかの補足（12文字以内で1行） |
| 数量・単価 | 3〜4列目 | 金額の根拠。右ぞろえの等幅数字で桁を揃える |
| 金額 | 最右列 | 行ごとの金額（右ぞろえ）。合計行の金額と右端を揃える |
| 行罫線 | 各行の下 | 行の区切り。縦罫線・塗り・縞模様は使わない |
| 合計行 | 表の下 | 唯一の地色（淡い地）。合計金額だけ20pxのアクセント色で目立たせ、税区分を小さく添える |
| 注記 | 合計行の下 | 「例：」で有効期限・追加費用の目安など条件を1行 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-estimate-amount-tableのレイアウトで見積スライドを作成してください。明細は『Webデザイン｜TOP＋下層4ページ｜5ページ｜¥64,000｜¥320,000』『実装｜スマホ対応・フォーム設置｜1式｜¥240,000｜¥240,000』…の4行、合計 ¥700,000（税別）。合計行の下に有効期限を「例：」の注記で1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは持たない。旧版の「金額バッジ＋44pxの特大金額」「ヘッダーと合計行の反転塗り」「内訳の小見出しバー」は廃止した。合計は淡い地の1行に絞る
- 数字はすべて右ぞろえ・`tabular-nums`。金額は「¥」＋3桁区切りで統一し、単位（ページ・式）は数量セルに書く
- 明細は4〜5行まで。6行を超える明細は枚数を分けるか line-item-table を検討する
- 内容セルは12文字以内で1行に収める。入らないときは文字を小さくせず、文言を短くする
- 合計行の金額は明細の金額の合計と必ず一致させる
