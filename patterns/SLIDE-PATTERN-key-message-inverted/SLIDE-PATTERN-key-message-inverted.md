# SLIDE-PATTERN-key-message-inverted

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。反転面は共通見出し（`sk-head`）OFFが既定です（ONにしても崩れないよう、見出し・縦バーは白抜きになります）。

## Overview
**パターン名：** key-message-inverted
**概要：** スライド全面をアクセント色で塗り、白文字の主張1つを中央に置く反転配色。上から「英字ラベル（KICKER・白60%）」「主張（28px・太字・字間.1em・2行まで）」「細い白罫線1本（幅48px・白35%）」「補足1行（16px・白80%）」を中央ぞろえで積む。塗りは背景1つだけで、図形・影・差し色を足さない。白地版 `key-message-single` と同じ骨格で、色だけを反転させる。
**適したシーン：** 章の結論・最重要メッセージ。白地スライドが続いた後の「ここが山場」の1枚（1デッキ1〜2枚まで）。

## Structure（構造）

コンテンツエリア（左右余白48px・見出しON時は上76px以降）の上下左右中央に、KICKER→主張→罫線→補足を中央ぞろえで積む。主張と補足は最大幅760pxで折り返す。

    structure:
      background: var(--sk-accent)        # 全面塗り（唯一の塗り）。グレー版のフォールバックは #555555
      layout: content-area-centered
      align: center (text-align center)
      elements:
        - kicker: "Key Message ／ 結論"   # 10px / 700 / 字間 .18em / 大文字 / rgba(255,255,255,.6)
        - message: 主張 1〜2行            # 28px / 700 / 字間 .1em / 行間 1.6 / 白。max-width 760px
        - rule: 48px × 1px                # rgba(255,255,255,.35)。唯一の装飾
        - sub: 補足 1行                   # 16px / 400 / rgba(255,255,255,.8)
      fill: background only

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 主張の上（白60%） | このスライドの種別を小さく示す（`Key Message ／ 結論`） |
| 主張 | 中央（28px・太字・白） | 最も伝えたい1文。2行まで（1行20字前後）で言い切る |
| 細い白罫線 | 主張と補足の間（48px・1px・白35%） | 主張と補足の切り替え。唯一の装飾 |
| 補足 | 罫線の下（16px・白80%） | 主張の根拠・条件・言い添えを1行で |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-key-message-invertedのレイアウトで、主張「[主張]」、補足「[補足1行]」のスライドを作成してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 1デッキ1〜2枚まで（乱用すると効果が消える）。通常は白地版 `key-message-single`、山場だけ反転版
- 主張は1文・最大2行（1行20字前後）。長いと効果が薄れるので、言い切りに削る。標語調にしない
- 補足は1行（40字以内）。省略してもよい（省略時は罫線も外してよい）
- 文字はすべて白（濃色地に #333 系を載せない）。差し色・図形・影・グラデーションを足さない
- 共通見出しは付けないのが既定。背景画像レイヤー（`slides[].bg`）は OFF にする（全面塗り）

## v2 での描き直し（2026-09-03）
- 32pxの主張＋2pxの白線（上）を、KICKER（白60%）→主張（28px・700・字間.1em）→白35%の細罫線1本（48px）→補足16px（白80%）の型に変え、`key-message-single` と骨格をそろえた
- 補足を13pxから16pxに上げ、左右余白48px・最大幅760pxの中央ぞろえにした。見出しON時は見出し・縦バーが白抜きになる上書きを足した
- `.slide` の文字の組み（palt・禁則・字間.06em・行間1.8・太さ400/700）に合わせ、プレースホルダを型が伝わる具体例にした
