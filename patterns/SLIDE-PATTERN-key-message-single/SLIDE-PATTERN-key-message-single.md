# SLIDE-PATTERN-key-message-single

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** key-message-single
**概要：** 1枚に1つの主張だけを置く強調スライド。コンテンツエリアの中央に大きな主張（28px・太字・字間.08em）、その上に小さな英字ラベル、下に細い罫線1本と補足1行を置く。塗りは使わず、装飾は罫線1本だけ。
**適したシーン：** 重要な結論・発見・主張を強調する場面、章の締めくくり、印象付けたい1枚

## Structure（構造）

コンテンツエリア（左右余白48px）の上下左右中央に、上から「英字ラベル（KICKER）」「主張（1〜2行）」「細い罫線1本」「補足1行」を中央ぞろえで積む。主張と補足は最大幅760pxで折り返す。塗り・囲み・図形は置かない。

    structure:
      layout: content-area-centered
      align: center (text-align center)
      elements:
        - kicker: "Key Message ／ 結論"   # 10px / 700 / 字間 .18em / 大文字 / アクセント色
        - message: 主張 1〜2行            # 28px / 700 / 字間 .08em / 行間 1.6 / インク色。max-width 760px
        - rule: 48px × 1px                # var(--sk-accent2)。唯一の装飾
        - sub: 補足 1行                   # 16px / 400 / muted 色
      fill: none

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 主張の上 | このスライドの種別を小さく示す（`Key Message ／ 結論`）。アクセント色 |
| 主張 | 中央（28px・太字） | 最も伝えたい1文。1〜2行で言い切る |
| 細い罫線 | 主張と補足の間（48px・1px） | 主張と補足の切り替え。差し色（`--sk-accent2`）を使う唯一の場所 |
| 補足 | 罫線の下（16px・薄く） | 主張の根拠・出典・言い添えを1行で |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-key-message-singleのレイアウトで、主張「[主張]」、補足「[補足1行]」のスライドを作成してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 主張は1文・最大2行（1行22字前後）。長いと効果が薄れるので、言い切りに削る
- 補足は1行（40字以内）。省略してもよい（省略時は罫線も外してよい）
- 主張はインク色のまま。アクセント色の文字や塗りで強調しない（余白と大きさで見せる）
- 主張は「〜する」「〜が決め手」など断言形にすると印象が強まる。「〜ではなく」で振る型は使わない

## v2 での描き直し（2026-09-02）

- 22pxの主張＋上下2本の罫線を、KICKER→主張（28px・700・字間.08em・インク色）→罫線1本→補足の型に変え、装飾を差し色の細い罫線1本だけにした
- 補足を13pxから16px（muted）に上げ、主張・補足とも最大幅760pxで中央ぞろえにした
- `.slide` の文字の組み（palt・字間.06em・行間1.8・インク色）と左右余白48pxに合わせ、プレースホルダを型が伝わる具体例にした
