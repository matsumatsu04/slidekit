# SLIDE-PATTERN-section-center-circle-number

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い。ONにした場合は本文エリアが上76pxから始まる）。

## Overview
**パターン名：** section-center-circle-number
**概要：** 白地の中央に、1.5pxの `--sk-line` 枠線だけの72pxの円を置き、中に章番号（24px・400・アクセント色）を入れる。その下に「英字KICKER → 章タイトル（28px・700）→ 説明1行（16px・muted）」を中央ぞろえで縦に積み、全体を本文エリアの上下中央に置く。塗りはなく、円は枠線だけ。
**適したシーン：** プレゼンの章区切り、セクション導入。白地のまま静かに章を切り替えたい場面（塗りで反転させたいときは section-divider / section-minimal-center へ）。

## Structure（構造）
```yaml
layout: section-center-circle-number
background: 白
content-area:                     # left/right 48px・全高の上下中央（見出しON時は top 76px）・中央ぞろえ・縦積み
  circle: 72px                    # 枠線 1.5px var(--sk-line)・塗りなし
    number: "02"                  # 24px / 400 / 字間 .04em / アクセント色。円の中央
  kicker: "SECTION"               # 10px / 700 / 字間 .2em / 大文字 / アクセント色。上に 24px
  title:  章タイトル               # 28px / 700 / 字間 .06em / 行間 1.5 / インク色。max-width 760px・1〜2行。上に 12px
  sub:    説明1行                  # 16px / 400 / 行間 1.8 / muted 色。max-width 760px。上に 12px（省略可）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 円 | 中央上 | 枠線だけの72pxの円。章番号の器。塗らない（塗ると「塗り1つ」を消費する） |
| 章番号 | 円の中央 | 2桁ゼロ埋めの細字（400）・アクセント色。このスライドで色を使う主役 |
| KICKER | 円の下 | 「SECTION」の英字ラベル（アクセント色・字間広め） |
| 章タイトル | KICKERの下 | 章の内容を1〜2行で言い切る。標語調にしない |
| 説明 | タイトルの下 | この章で扱うことを1行で補う（省略可） |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-center-circle-number を使って中扉を1枚生成してください。
【章番号】02
【KICKER】SECTION
【章タイトル】試作を現場に入れるまでの3つの手順
【説明】小さな案件で試し、結果を人が読んでから次の工程へ広げる
```
### 注意点
- 円は枠線のまま（アクセント塗り・白抜き・影にしない）。番号は400のまま太くしない
- 章タイトルは28pxで2行まで（1行あたり全角20文字程度）。2行にするときは `<br>` を意味の切れ目に入れる
- 上下の余白は均等（本文エリアの上下中央）。要素を減らしても上に張り付けない
- 背景画像レイヤー（`slides[].bg`）は白地なので ON のままでよい

## v2 での描き直し（2026-09-03）
- 「全面アクセント塗り＋白枠の56px円＋36px白太字タイトル」の旧構成から、白地・塗りなしの中扉に描き直した（円は1.5pxの `--sk-line` 枠線だけ、番号はアクセント色の細字）
- 円を72pxに、番号を24px/400に、章タイトルを36pxから28px/700に落とし、英字KICKERと説明1行（16px・muted）を型どおりに足した
- 太さを400/700の2つに絞り、`palt`・`line-break:strict`・左右48px・`.content-area`（見出しON時は上76px）の上下中央の組みに揃えた
