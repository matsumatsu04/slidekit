## Overview

**パターン名：** executive-summary-banner-stack
**概要：** 横長の行を3段縦に積むエグゼクティブサマリー。各行は「左に英字ラベル（`POINT 1 ／ 現状`）→右に見出し（18px・太字）→本文（16px）」の2カラム。行は1pxの細罫線で区切り、1段目だけ `--sk-soft` 地（角丸11px）で主役にする。3段は等高・上ぞろえ。塗りは1段目だけで、タグ・バッジ・アクセント塗りは使わない。
**適したシーン：** 経営層向けのエグゼクティブサマリー・報告書冒頭の要点整理・現状／課題／方針など性質の異なる3項目の並列提示

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 行 | コンテンツエリアに縦3段（等高） | 1項目分の情報のまとまり。細罫線で区切る |
| 英字ラベル（KICKER） | 各行の左（128px幅） | `POINT 1 ／ 現状` のように番号と分類を小さく示す。アクセント色の文字（塗らない） |
| 見出し | ラベルの右・上段（18px・太字） | その項目の結論を1文で言い切る |
| 本文 | 見出しの直下（16px） | 見出しを補う根拠・具体を1〜2行で |
| 淡い地 | 1段目だけ（角丸11px） | 最初に読ませる項目を主役にする。塗りはここだけ |
| 細罫線 | 2段目以降の上 | 行と行の区切り（1px・`--sk-line`） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-executive-summary-banner-stackのレイアウトで、以下3項目を3段の行でまとめてください。デザインはSLIDE.mdに従ってください。
>
> 【1】ラベル: POINT 1 ／ 現状 / 見出し: 問い合わせは月に約40件、うち半数が既存客からの追加依頼 / 本文: 新規の流入は横ばいで、紹介経由に依存している。次の入口がまだ無い。
> 【2】ラベル: POINT 2 ／ 課題 / 見出し: 確認工程に時間がかかり、納期の後ろ倒しが続いている / 本文: 1件あたりの確認に平均3日。担当者ごとに見る順番が違い、同じ指摘が二度出る。
> 【3】ラベル: POINT 3 ／ 方針 / 見出し: 確認の手順を型にし、来期は新規の入口を1本足す / 本文: 数字・固有名詞・リンクの3点を先に見る手順に統一する。紹介以外の流入を小さく試す。」

**注意点：**
- ラベルの補足（現状／課題／方針など）は2〜3文字に揃え、3段で文字数の差を出さない
- 見出しは1行（30字以内）・本文は2行以内（1行38字前後）。行末に1〜2文字だけ残る折り返しは文言を削って避ける
- 淡い地は1段目だけ。全段を同じ扱いにしたいときは地を外し、全段を罫線区切りにしてよい
- 4項目以上は行が窮屈になるので、本パターンではなくリスト系パターンを検討する
- 3段は重要度順または時系列順など、一貫した並び順で構成する
