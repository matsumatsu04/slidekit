# SLIDE-PATTERN-section-divider

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い。ONにした場合は本文エリアが上76pxから始まる）。
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません（全面塗りの頁では白抜きにする）。

## Overview
**パターン名：** section-divider
**概要：** 全面をアクセント色で塗り、白文字・左ぞろえで章を切り替える中扉の基本形。左右48pxの本文エリアの上下中央に「英字KICKER（白60%）→ 章番号（64px・400・白）→ 章タイトル（28px・700）→ 白35%の罫線1本（全幅・1px）→ 説明1行（16px）」を縦に積む。塗りは背景の1つだけ、装飾は罫線1本だけ。
**適したシーン：** プレゼンの章区切り、セクション導入、アジェンダ後の各パートの冒頭。表紙が淡い地なら中扉は塗りで反転させる（デザインの規律 v2・6）。

## Structure（構造）
```yaml
layout: section-divider
background: var(--sk-accent)      # 全面塗り。文字はすべて白（グレー版のフォールバック地は #555555）
content-area:                     # left/right 48px・全高の上下中央（見出しON時は top 76px）・左ぞろえ・縦積み
  kicker: "SECTION"               # 10px / 700 / 字間 .2em / 大文字 / rgba(255,255,255,.6)
  number: "01"                    # 64px / 400 / 字間 .04em / 行間 1 / 白。上に 20px
  title:  章タイトル               # 28px / 700 / 字間 .06em / 行間 1.5 / 白。max-width 760px・1〜2行。上に 16px
  rule:   全幅 × 1px              # rgba(255,255,255,.35)。上 28px・下 24px。唯一の装飾
  sub:    説明1行                  # 16px / 400 / 行間 1.8 / rgba(255,255,255,.85)。max-width 760px
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 左上 | 「SECTION」の英字ラベル。章であることを小さく示す（白60%） |
| 章番号 | KICKERの下 | 2桁ゼロ埋めの細字（400）・64px。塗り・囲みにせず、大きさと細さで見せる |
| 章タイトル | 番号の下 | 章の内容を1〜2行で言い切る。標語調にしない |
| 白罫線 | タイトルと説明の間・全幅 | 1px・白35%。タイトルと説明の切り替え。このスライドで唯一の装飾 |
| 説明 | 罫線の下 | この章で扱うことを1行で補う（省略可。省略時は罫線も外してよい） |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-divider を使って中扉を1枚生成してください。
【KICKER】SECTION
【章番号】01
【章タイトル】現状の制作フローと、時間を取られている工程
【説明】1案件の工程を分解し、待ちと手戻りが起きる点を先に見る
```
### 注意点
- 章番号は「01」「02」のようなゼロ埋め2桁。太字にしない（400のまま。太くすると番号が主役になる）
- 章タイトルは28pxで2行まで（1行あたり全角20文字程度）。2行にするときは `<br>` を意味の切れ目に入れる
- 文字はすべて白（濃色地に #333 系を載せない）。KICKER・説明は半透明白で階調を付ける
- アクセント色の塗りはこの1枚で全面に使うため、他の塗り・差し色・面・影は足さない
- 背景画像レイヤー（`slides[].bg`）は OFF にする（全面塗り）
- 現在地（全章の中の位置）を見せたい場合は section-tag-progress、中央ぞろえにしたい場合は section-minimal-center へ

## v2 での描き直し（2026-09-03）
- 白地に「灰色の縦バー＋淡い番号＋#333の見出し＋右下の頁範囲」を置く旧構成から、全面アクセント塗り＋白文字・左ぞろえの中扉に描き直した（塗りは背景1つ・面を置かない）
- 章番号を「48px太字の淡グレー」から「64px・400・白」に、章タイトルを32pxから28px/700に落とし、英字KICKER（白60%）を上に、白35%の罫線1本と説明16pxを下に揃えた
- 左右余白を80pxから48pxに、太さを400/700の2つに絞り、`palt`・`line-break:strict`・`.content-area`（見出しON時は上76px）の組みに揃えた
