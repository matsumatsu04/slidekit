# SLIDE-PATTERN-history-year-list

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** history-year-list
**概要：** 左に年（20px・400・アクセント色）、中央に1pxの幹線と小さな丸ノード、右に見出し16px太字と本文16pxを置く沿革リスト。最新の1件だけノードをアクセント塗り＋見出しをアクセント色にする。
**適したシーン：** 会社沿革・サービスの歩み・プロジェクト履歴。5〜7項目の時系列提示。

## Structure（構造）

コンテンツエリア（左右余白120px＝幅720px）の上下中央に、高さ固定（72px）の行を5つ積む。各行は「年（幅120px）→ ノード列（幅40px）→ テキスト（見出し→本文）」の3列。幹線（1px・罫線色）はノード列の中心に引き、最初のノードの中心から最後のノードの中心まで（`top:14px; bottom:72-14px`）で止める。年・ノード・見出しは行高28pxで垂直中心を合わせる。最新の行だけノードを塗り、見出しをアクセント色にする。

    structure:
      layout: history-year-list
      content_area:
        padding: "24px 120px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      rows: 5                       # 標準。6〜7行のときは行高を56pxにして本文を省く
      row:
        height: 72px                # 固定（幹線の端点をノードの中心で止めるため）
        left:
          year: "2019"              # 20px / 400 / .12em / アクセント色・行高28px。幅120px
        center:
          node: circle              # 12px の白丸・1.5px 罫線色の枠。列幅40pxの中心（幹線の上に載る）
          now: accent_fill          # 最新の1件だけ塗り（塗りは1枚に1つ）
        right:
          padding_left: 16px
          elements:
            - heading               # 16px / 700 / 行高28px（最新の1件はアクセント色）
            - body: 1 line          # 16px / 400 / 行間1.8（30文字以内）
      trunk:
        type: vertical-line
        width: 1px
        color: line                 # var(--sk-line)。塗り・矢印なし
        left: 140px                 # 年列120px＋ノード列の中心20px
        from: first node center
        to: last node center

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 年 | 各行の左端 | `2019` のように年を示す。20px・400・アクセント色（太字にしない） |
| 幹線 | ノード列の中心 | 最初のノードの中心から最後のノードの中心までの1px線。時系列を示す |
| 丸ノード | 幹線の上・各行の見出しと同じ高さ | 各時点の印。白丸に罫線色の枠 |
| 見出し | ノードの右・行の上端 | その年の出来事（12文字前後。最新は「（現在）」を添えてよい） |
| 本文 | 見出しの下 | 内容を1行で（30文字以内） |
| 塗りノード＋アクセント見出し | 最新の1行 | 「現在」「到達点」を塗りで区別する。1枚に1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-history-year-listのレイアウトで、創業から現在までの5つの出来事を年表で説明してください。各行は年・見出し・本文1行（30文字以内）の順で書き、最新の1行は「現在」としてノードを塗ってください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは最新の1件だけ。途中の年を強調したい場合も2つ以上塗らない（本文で言い切る）
- 5行が標準。6〜7行は行高を56pxにして本文を省く（見出しだけ）。8行以上は枚数を分ける
- 本文は1行に収める。入らないときは文字を小さくせず、文言を短くする
- 幹線はノードの中心で止める（行高を変えるときは `bottom` の値＝行高−14px を保つ）
- 旧版の「太字の年号・2pxの幹線・白フチの大ドット・差し色（accent2）の重要行」は廃止。線とノードと文字だけで組み、差し色は使わない

## v2 での描き直し（2026-09-02）
- 年を16px太字から20px・400・アクセント色（字間.12em）に変え、2pxの幹線と白フチ付きドットを1pxの幹線＋12pxの白丸ノード（罫線色の枠）にした
- 出来事1行のみだった右列を「見出し16px太字＋本文16px」の2段にし、行高72px固定で幹線の端点を最初と最後のノードの中心で止めた
- 差し色（accent2）の大ドット＋太字の重要行を廃し、最新の1件だけノード塗り＋見出しアクセント色にした（塗りは1枚に1つ）
