# SLIDE-PATTERN-ok-ng-comparison

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** ok-ng-comparison
**概要：** 左に NG（淡い地・× 記号・muted寄りの文字）、右に OK（アクセント塗り・✓ 記号・白文字）を同じ型のパネルで並べる対比レイアウト。テイストを揃えて「対立だけ」を作る。アクセント色で塗るのは右パネルの1つだけ。
**適したシーン：** ビフォーアフター・推奨/非推奨・誤解と正解の対比。ノウハウ解説や提案の説得パート。

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各パネル左上 | `NG ／ よくあるやり方`・`OK ／ 推奨`。左はアクセント色、右（塗り）は白 |
| 見出し | KICKER の下 | そのやり方を1行で言い切る（18px・700）。標語調にしない |
| 細罫線 | 見出しと項目の間 | 左は `--sk-line`、右は白の半透明線 |
| 項目 | 罫線の下・3行 | 左は × ＋ muted の文字、右は ✓ ＋ 白文字。本文16px |
| 注記 | パネル最下 | 「例：〜」で具体を1行添える（11.5px） |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.mdのデザインシステムと、以下のSLIDE-PATTERN-ok-ng-comparisonパターンを使って
スライドを1枚生成してください。

【スライドタイトル】確認のタイミングをどこに置くか

【NG（左・淡い地）】
- KICKER: NG ／ よくあるやり方
- 見出し: できてから、まとめて見せる
- 項目: × 確認が納品の直前に集中する／× 修正のたびに組み直しになる／× 判断の根拠が担当者の頭にだけ残る
- 注記: 例：最終日に指摘が10件まとめて届く

【OK（右・アクセント塗り）】
- KICKER: OK ／ 推奨
- 見出し: 工程ごとに、小さく見せる
- 項目: ✓ 確認が工程の中に入る／✓ 修正は差分の再生成で済む／✓ 判断の根拠が記録として残る
- 注記: 例：工程ごとに10分の確認で通る
```

### 注意点
- 必ずNGを左・OKを右に置く（視線の流れ＝改善の流れ）
- 項目数は左右で揃える（2〜4行）。1項目は1行（18字以内）に収め、入らなければ言い切りに削る
- 塗りは右パネルの1つだけ。NG側にアクセント色の塗り・枠・文字を使わない（対比が濁る）
- 記号は × と ✓ の文字だけ。丸アイコン・絵文字・バッジにしない
- 左右のパネルは等高（flex stretch）で本文エリアを埋める。項目が少なくても文字を大きくして埋めない
