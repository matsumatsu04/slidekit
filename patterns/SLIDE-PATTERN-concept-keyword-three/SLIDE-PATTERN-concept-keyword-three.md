# SLIDE-PATTERN-concept-keyword-three

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** concept-keyword-three
**概要：** 短いキーワード（1〜4文字）×3を、1px の縦罫線（`--sk-line`）で区切って横に並べる概念提示。各列は「キーワード（28px・太字・アクセント色・字間.08em）→英字ラベル（10px・差し色）→説明（16px・2〜3行）」の型。カードにせず、塗りも使わない。
**適したシーン：** コンセプト・価値観・選ばれる理由を「3つの言葉」に凝縮して見せる場面。

## Structure（構造）

```yaml
layout: concept-keyword-three
content_area:            # 左右余白48px・見出しON時は上76px以降。3列の束は本文エリアの上下中央
  display: flex
  align-items: center

columns:
  count: 3               # 等幅・等高（列の中身は上ぞろえ）
  divider: 1px           # 列の間だけ var(--sk-line) の縦罫線（外側には引かない）
  each:
    padding: "24px 32px"
    text-align: center
    keyword: キーワード          # 28px / 700 / 字間 .08em / 行間 1.3 / アクセント色
    kicker:  "SPEED ／ 補足"    # 10px / 700 / 字間 .18em / 大文字 / 差し色（--sk-accent2）
    desc:    説明 2〜3行        # 16px / 400 / 行間 1.8 / インク色
  fill: none
```

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| キーワード | 各列の最上段（28px・太字） | 1〜4文字の短い言葉。アクセント色を使う唯一の場所 |
| 英字ラベル | キーワードの下（10px） | 英訳＋補足（`SPEED ／ 着手から公開まで`）。差し色（`--sk-accent2`） |
| 説明 | 英字ラベルの下（16px） | キーワードの意味を2〜3行で |
| 縦罫線 | 列と列の間（1px） | 列の区切り。唯一の装飾 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE-PATTERN-concept-keyword-three を使ってスライドを1枚生成してください。

【スライドタイトル】私たちが大切にする3つのこと
【列 1】キーワード: 速さ / ラベル: SPEED ／ 着手から公開まで / 説明: 初稿を2日で出し、確認と直しを短い周期で回す。
【列 2】キーワード: 品質 / ラベル: QUALITY ／ 人が最後に見る / 説明: 表記と導線は人が確認し、数字と固有名詞を確かめる。
【列 3】キーワード: 仕組み / ラベル: SYSTEM ／ 同じ型で繰り返す / 説明: 手順と確認表を残し、次の案件でも同じ品質で通す。
```

### 注意点
- キーワードは4文字以内に磨く（長いと迫力が消える）。5文字以上になるなら見出し型の three-column-icon-card を使う
- 説明は3行（39字以内）まで。入らなければ文字を小さくせず、文言を削る
- 塗り・カード枠・アイコンを足さない。アクセント色はキーワードだけ、差し色は英字ラベルだけ
- 2列・4列になる場合も等幅のまま横に並べる（4列は説明を2行に抑える）

## v2 での描き直し（2026-09-02）
- 40px・900のキーワードを 28px・700・字間.08em に落ち着かせ、太さを 400/700 の2つだけにした
- 英字ラベルをキーワードの上から下へ移し、差し色（`--sk-accent2`）の KICKER 型（10px・字間.18em）にした
- 説明を12pxから16px（インク色・行間1.8）に上げ、区切りを `--sk-line` の1px縦罫線・左右余白48pxに合わせ、プレースホルダを具体例にした
