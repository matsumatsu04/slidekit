# SLIDE-PATTERN-three-stage-circle-flow
このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリアを除いたコンテンツ領域のみを対象とし、スライド全体のテンプレートではありません。

## Overview

**パターン名：** three-stage-circle-flow
**概要：** 3段階の工程を、淡い地の等高カード（KICKER「STEP 1 ／ 補足」・見出し・細い罫線・本文2行・注記）3枚で横に並べ、カードの間を SVG の三角矢印でつなぐレイアウト。中央の1枚だけアクセント塗り。
**適したシーン：** サービス導入フロー説明、3段階プロセスの詳細、カスタマージャーニーの段階表示、ステップバイステップの説明

- **適用場面:** プロセス解説、導入手順、ロードマップ概要
- **情報密度:** 中（段階ごとに見出し＋本文2行＋例）
- **方向性:** 左から右への時系列的な流れの可視化

## Structure（構造）

コンテンツエリアの上下中央に、等幅・等高（280px）のステージカード3枚を横一列に置き、カードの間を SVG の三角矢印（幅12px）でつなぐ。カードの中身は v2 の型（KICKER／見出し／細い罫線／本文2行／注記）で揃え、中央の1枚だけアクセント塗りにする。

    structure:
      layout: three-stage-flow
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        gap: 8px                    # カードと矢印の間
        height: 280px               # 3枚は等高（本文エリアを埋める）
      cards:
        count: 3
        layout: horizontal-equal-width
        border_radius: 12px
        padding: "24px 20px 20px"
        card:
          elements:
            - kicker: "STEP n ／ 段階名"     # 10px / 700 / .18em。塗りカード内は白
            - heading                        # 18px / 700
            - rule                           # 1px（塗りカード内は白35%）
            - body: 2 lines                  # 16px / 400 / 行間1.8（1行12文字以内）
            - note: "例：〜"                 # 11.5px / muted。カード下端に寄せる
        surfaces:
          default: soft                      # 淡い地 + 1px 罫線
          center: accent_fill                # 中央の1枚だけ塗り（白文字）
          last_optional: outline             # 最終工程が「結果」のときだけ 1.5px のアクセント枠線
      arrows:
        type: svg-triangle
        width: 12px
        color: accent

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各カード左上 | `STEP 1 ／ 現状把握` のように番号＋段階名。塗りカード内は白 |
| 見出し | KICKER の下 | その段階でやることを体言で（8文字前後） |
| 細い罫線 | 見出しの下 | 見出しと本文の区切り（塗りカード内は白35%） |
| 本文 | 罫線の下 | 段階の説明を2行（1行12文字以内・改行位置を指定） |
| 注記 | カード最下 | 「例：〜」で目安を1行添える |
| 三角矢印 | カードの間 | 左から右への流れ（SVG・幅12px・アクセント色） |
| 塗りカード | 中央の1枚 | 主役の段階。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-stage-circle-flowのレイアウトで、導入の3段階（現状把握→設計・構築→運用・改善）を説明してください。中央の STEP 2 を主役として塗り、各カードは KICKER・見出し・本文2行（1行12文字以内）・「例：〜」の順で書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは中央の1枚だけ。主役が中央でない場合はその1枚を塗り、中央は淡い地に戻す（2枚以上塗らない）
- 最終工程が「公開・運用」のような結果にあたるときは、3枚目を `tc-card-last`（塗らず 1.5px のアクセント枠線）にしてよい
- 本文は1行12文字以内×2行。入らなければ文言を短くする（文字を小さくしない）
- 3段階固定。4段階は horizontal-timeline-cards、5段階以上は枚数を分ける
- 旧版の円ノード（点線枠＋アイコン）と文字の「→」は廃止。カード＋三角矢印だけで流れを示す

## v2 での描き直し（2026-09-02）
- 円形ノード（2px枠＋アイコン＋ステージ名）と文字の「→」を廃し、淡い地の等高カード3枚を SVG 三角矢印（幅12px）でつなぐ形にした
- 中央の1枚だけアクセント塗り（白文字）にし、「塗りは1枚に1つ」を守った（最終工程が結果のときの枠線形を任意で用意）
- カードの中身を「KICKER／見出し18px／細い罫線／本文16px×2行／注記11.5px」の型に揃え、3項目の箇条書きをやめた
