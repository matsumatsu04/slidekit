# SLIDE-PATTERN-three-column-icon-card

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** three-column-icon-card
**概要：** 3つの項目を等幅・等高のカードで横並びにし、各カードを「小さなアイコン→英字ラベル→見出し→細罫線→本文→例：」の型で組む3列カード。中央の1枚だけ塗りで主役にする
**適したシーン：** サービスの3つの柱・強み・メリット、3つのターゲット、3つの取り組み（中央を主役にしたいとき）

## Structure（構造）

コンテンツエリア（左右余白48px）を3等分した等高カード（gap 16px・角丸11px）で構成する。中身は左ぞろえで、上から「小さなアイコン（20px・丸地）」「英字ラベル（KICKER）」「見出し」「細罫線」「本文（2〜3行）」「例：の注記」の順に置く。3枚のうち中央だけを塗りカード（白文字）にして主役を示し、左右は白地＋細枠線にする。カード群は本文エリアの上下中央に置く。

    structure:
      layout: three-equal-columns
      cards:
        equal_height: true
        gap: 16
        emphasis: center (filled, 1 of 3)
      card:
        order:
          - icon (20px, in a small circle)
          - kicker (english label + japanese supplement)
          - heading (16-18px, bold)
          - thin-rule
          - body (16px, 2-3 lines)
          - note ("例：" 11.5px)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| アイコン | 各カード左上（40pxの丸地に20px） | 項目を一目で識別させる小さな目印。主張させない |
| 英字ラベル（KICKER） | アイコン下 | `Support ／ 伴走` のように英字＋日本語補足で項目の分類を示す |
| 見出し | ラベル下（太字） | 項目のキーワード（10字前後） |
| 細罫線 | 見出しと本文の間 | 見出しと本文の切り替え。塗りカード内は白の半透明線 |
| 本文 | 罫線下（2〜3行） | 項目の説明。1文か2文で言い切る |
| 注記（例：） | 本文下（小さく薄く） | 具体例を1行で添える |
| 塗りカード | 中央 | 3項目の主役。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-column-icon-cardのレイアウトで、3つの[テーマ]（[項目1]・[項目2]・[項目3]）を並べてください。各カードは英字ラベル・見出し・本文2行・「例：」の順で書き、主役にする項目を中央に置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- アイコンは Font Awesome Solid を20pxで使う。大きな図版にしない（主役は見出しと本文）
- 本文はカード幅（1行13字前後）で2〜3行に収まる長さにする。入らないときは文字を小さくせず、文言を短くする
- 塗りは中央の1枚だけ。他の2枚まで塗らない（強調が散る）
- 3列固定のパターン。2列または4列にしたい場合は別パターンを使用
