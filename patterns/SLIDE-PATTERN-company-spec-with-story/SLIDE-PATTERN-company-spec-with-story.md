# SLIDE-PATTERN-company-spec-with-story

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** company-spec-with-story
**概要：** 左55%にKICKER＋小見出しと会社概要テーブル（ラベル列は英字ラベル・横罫線のみ7〜8行）、右45%に1.5px枠のストーリーボックス1つ（KICKER→見出し→本文3〜4行→注記）を置く会社概要。スペックと信頼ストーリーを1枚にまとめる
**適したシーン：** 受託提案・営業資料の「会社概要」1枚。基本情報の網羅と、選ばれる理由の一言を同時に見せる場面

## Structure（構造）

コンテンツエリア（左右余白48px）を、左の概要列（幅55%）と右のストーリー列（残り全幅）に分ける（間隔32px）。2列は等高（stretch）・上ぞろえで、ブロック全体は本文エリアの上下中央に置く。

左列は上から「英字ラベル（KICKER・`COMPANY ／ 会社概要`）」「小見出し（18px・700）」「会社概要テーブル」。テーブルは横罫線のみ（上端と各行の下に1px・`--sk-line`）で、地色・縦罫線は付けない。ラベル列（幅148px）は英字ラベル（KICKER・`FOUNDED ／ 設立` のように英字＋日本語）、値は16px。行数は7〜8行。

右列はストーリーボックスを1つだけ置く（1.5px `--sk-line` 枠・角丸12px・padding24px）。中身は上から「6pxのアクセントドット＋KICKER `STORY ／ 沿革`」「見出し（18px・700）」「細罫線」「本文16px×3〜4行」、最下部に「注記11.5px・muted（上に細罫線）」を `margin-top:auto` で貼り付ける。アクセント塗りはこのドット1つだけで、円形シンボルは置かない。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 各列の先頭 | `COMPANY ／ 会社概要`・`STORY ／ 沿革` のようにブロックの性格を英字＋日本語で示す |
| 小見出し | 左列上部（18px・700） | テーブルが何の情報かを1行で言う（例「株式会社〇〇の基本情報」） |
| 会社概要テーブル | 左列 | 商号・事業・所在地・設立・代表者・資本金・従業員など基本情報7〜8行。横罫線だけで組む |
| ラベル列（KICKER） | テーブル左（幅148px） | `CAPITAL ／ 資本金` のように英字＋日本語。英字は短語にして1行に収める |
| 値 | テーブル右（16px） | 1行で収める。2行になる場合は事業内容など1項目までにする |
| ストーリーボックス | 右列（1.5px枠） | 選ばれる理由・創業の姿勢の置き場。左のテーブルと等高にして本文エリアを埋める |
| アクセントドット | KICKER の左（6px） | このスライド唯一のアクセント塗り。右列が主張の側であることを示す |
| 見出し＋本文 | ボックス内 | 18px/700の一言と、それを支える16px×3〜4行 |
| 注記 | ボックス最下部（11.5px） | 「例：〜」の補足。細罫線の下に置き、ボックスの下端に貼り付ける |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-company-spec-with-storyのレイアウトで、[会社名]の会社概要を表示してください。左に会社概要テーブル7行（ラベルは英字＋日本語）、右に沿革・姿勢のストーリーボックス（見出し1行＋本文3〜4行＋例の注記）を書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- テーブルは7〜8行が基準（6〜8行まで可変）。9行以上は文字を小さくせず、項目を削るか2枚に分ける
- ラベルは英字を短語（Name / Business / Address / Founded / CEO / Capital / Staff）に揃える。英字が長いとラベル列で折り返して行の高さが崩れる
- 値は16pxのまま1行で収める。長い事業内容は「Webサイトの制作と、公開後の運用支援」のように要約する
- 塗るのはKICKER横のドット1つだけ。テーブル側に地色・色文字を足さない（薄グレー地のラベル列は廃止した）
- ストーリーボックスは1つ。2つに割ると等高が崩れ、主張も散る。人物・実績を並べたいなら profile-bio や stats-grid-six に分ける

## v2 での描き直し（2026-09-04）

- Font Awesome の `<link>` と円形シンボル（アイコン＋短文2行）を廃止し、右列をストーリーボックス1つだけにした。ボックスは1.5px `--sk-line` 枠・角丸12pxで、中身を「KICKER → 見出し18px/700 → 細罫線 → 本文16px → 注記11.5px（下端に貼り付け）」の型に組み直した
- 会社概要テーブルのラベル列の薄グレー地を外し、横罫線だけの表にした。ラベルを英字ラベル（KICKER・英字＋日本語）、値を11px→16pxにし、小見出しは正方形マーカー14px太字→KICKER＋18px/700に変えた。プレースホルダも具体例（商号・事業・所在地など実際に書く粒度）にした
- アクセントを1つに絞った（KICKER横の6pxドットだけ。枠線もアクセント色→`--sk-line`）。左右余白を64px→48px、2列を等高・上ぞろえにして本文エリアの上下中央に置き、`.slide` の枠線を外した
