# SLIDE-PATTERN-company-spec-with-story

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** company-spec-with-story
**概要：** 左右2分割。左55%は正方形マーカー付き小見出し＋会社概要テーブル（ラベル列=薄グレー地・値列=白地・細罫8行前後）。右45%は上下2ブロックで、上=小見出し＋円形シンボルプレースホルダ＋短文2行、下=アクセント枠線ボックス（キャッチ太字1〜2行＋本文3行）。
**適したシーン：** 受託提案の「会社概要」1枚。商号・所在地などのスペックと、信頼につながるストーリーを同居させたい場面。

## Structure（構造）
- 左カラム（55%）
  - 小見出し（正方形マーカー＋太字） → 会社概要テーブル
  - テーブルは細罫8〜10行。左のラベル列は薄グレー地・右の値列は白地
- 右カラム（45%・上下2ブロック）
  - 上ブロック: 小見出し → 中央に円形シンボル（薄グレー地＋アイコン） → 短文2行
  - 下ブロック: 枠線ボックス（1.5pxアクセント枠） → キャッチ太字1〜2行＋本文3行

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 小見出し | 各カラム上端 | 正方形マーカー付きのブロック見出し |
| 会社概要テーブル | 左カラム | 商号・事業内容・所在地・設立などの基本情報8行前後 |
| 円形シンボル | 右上ブロック中央 | 会社の姿勢を象徴するアイコンのプレースホルダ |
| 短文 | シンボルの下 | シンボルに添える2行の説明 |
| 枠線ボックス | 右下ブロック | アクセント枠で囲んだ信頼ストーリーの置き場 |
| キャッチ＋本文 | 枠線ボックス内 | 太字の一言と、それを支える3行の本文 |

## Usage Guide（AIへの使い方）
- テーブルは8行が基準（6〜10行まで可変。行が減ったら上下センタリングで余白を均等にする）
- ラベルは2〜4文字の短語に揃える（商号・設立・拠点など）。値が2行になってもよい
- 枠線ボックスのキャッチは1〜2行で止める。強調はこの枠線1箇所に絞り、テーブル側に色を足さない
