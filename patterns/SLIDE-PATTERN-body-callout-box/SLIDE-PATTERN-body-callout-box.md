# SLIDE-PATTERN-body-callout-box

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** body-callout-box
**概要：** 本文の段落（16px・行間1.8・3〜4行）の下に、淡色地・角丸11pxのコールアウト箱を置く文章系レイアウト。箱は左辺に3pxのアクセント縦線（角丸なし）、中は「英字ラベル（POINT ／ 要点）→太字16pxの要点」。その下に「例：」の注記を添えられる。塗りはこの箱1つ。
**適したシーン：** 規約・前提・考え方の説明など文章が主体のページで、結論だけは確実に読ませたい場面

## Structure（構造）

コンテンツエリア（左右余白48px）の全幅に、上から「本文段落」「コールアウト箱」「注記（省略可）」を積み、束を本文エリアの上下中央に置く。箱は `--sk-soft` 地・角丸11pxで、左辺の内側に3px幅の直角バー（上下16px内側で止める）を立てる。箱の中は左ぞろえで KICKER → 太字の要点。

    structure:
      layout: single-column
      area: 本文エリア（上下中央）
      elements:
        - body: 本文 3〜4行             # 16px / 400 / 行間 1.8 / インク色
        - callout:                      # 唯一の塗り。var(--sk-soft)・角丸 11px・padding 20/24（左 28）
            bar: 3px × (高さ−32px)      # 左辺・var(--sk-accent)・角丸なし
            kicker: "Point ／ 要点"      # 10px / 700 / 字間 .18em / 大文字 / アクセント色
            text: 要点 1〜2行           # 16px / 700 / 行間 1.8
        - note: "例：〜"（省略可）       # 11.5px / muted 色
      fill: callout only

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 本文 | 上（3〜4行） | 背景・前提・文脈の説明。要点の重みが分かるだけの文脈を用意する |
| コールアウト箱 | 本文の下（淡色地・角丸） | このスライドの結論を本文から浮き上がらせる。1枚に1つ |
| 縦バー | 箱の左辺（3px・直角） | 箱の目印。`border-radius` は付けない |
| 英字ラベル（KICKER） | 箱の中・上段 | `Point ／ 要点` のように種別を小さく示す。アクセント色 |
| 要点 | 箱の中・ラベルの下（太字16px） | 結論を1〜2行で言い切る |
| 注記（例：） | 箱の下（11.5px・薄く） | 具体例・出典・例外を1行で添える。省略可 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-body-callout-boxのレイアウトで、本文「[3〜4行の説明]」、要点「[結論1文]」、例「[具体例1行]」のスライドを作成してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- コールアウト箱は1つだけ。2つ以上に増やすなら numbered-list-with-body へ
- 本文は4行以内（1行50字前後）。長い場合は2枚に分ける（文字を小さくして詰めない）
- 要点は太字16px・1〜2行。箱の中に本文の続きを書かない
- 縦バーは直角のまま。バーに角丸を付けたり、箱の左辺を `border-left` で丸めたりしない
- 塗りは箱の `--sk-soft` だけ。バーと英字ラベル以外にアクセント色を使わない
