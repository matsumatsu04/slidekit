# SLIDE-PATTERN-toc-section-cards

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
目次は共通見出し（`sk-head`）を付けない種類のスライドですが、このパターンは見出しON（Bの縦バー・「本日の流れ」等）でも崩れないよう本文エリアを `.content-area`（見出しON時は上76px）で組んでいます。

## Overview
**パターン名：** toc-section-cards
**概要：** 英字KICKER「CONTENTS ／ 目次」の下に、`--sk-soft` 地の章カードを3枚横並び（等幅・等高・gap 16px・角丸11px・padding 24px）にするカード型目次。カードの中身は「KICKER（01 ／ SECTION）→ 章名（18px・700）→ 細罫線 → 1行説明（16px）→ 頁の注記（11.5px・muted）」の型で上ぞろえ。現在章（1枚目）だけアクセント塗り＋白文字にし、塗りはその1枚だけ。
**適したシーン：** 章ごとの内容を一言添えて予告したい目次。ワークショップ・研修資料の冒頭。章の切り替わりで再掲し、塗るカードを移して現在地を示す使い方もできる。

## Structure（構造）
```yaml
layout: toc-section-cards
content-area:                      # left/right 48px・全高の上下中央（見出しON時は top 76px）・縦積み
  kicker: "Contents ／ 目次"        # 10px / 700 / 字間 .18em / 大文字 / アクセント色。下に 24px
  grid: 3列                         # 等幅・等高（grid・gap 16px）
    card:                           # soft 地・角丸 11px・padding 24px・min-height 216px・中身は上ぞろえ
      kicker: "01 ／ SECTION"       # 10px / 700 / 字間 .18em / 大文字 / アクセント色
      name:   章名                  # 18px / 700 / 行間 1.5 / インク色。上に 12px。1行（全角12文字程度）
      rule:   全幅 × 1px            # var(--sk-line)。上下 16px
      desc:   1行説明               # 16px / 400 / 行間 1.8 / インク色。全角13文字程度
      note:   "p.3 〜 p.8"          # 11.5px / 400 / muted 色。上に 12px（省略可）
    current:                        # 1枚目だけ
      background: var(--sk-accent)  # 白文字。KICKERも白、罫線は rgba(255,255,255,.35)、説明 .85・注記 .7
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER（Contents ／ 目次） | カード群の左上 | 目次であることを示す小さな英字ラベル。見出しOFFのときの唯一の見出し |
| 章カード | 3列・等幅・等高 | `--sk-soft` 地の角丸カード。1章＝1枚 |
| カードのKICKER | カード上段 | 「01 ／ SECTION」。番号と種別を英字ラベルで示す |
| 章名 | KICKERの下 | 章タイトル。18px・700で1行に収める |
| 細罫線 | 章名と説明の間 | 1pxの `--sk-line`。見出しと本文の切り替え（塗りカードの中は白35%） |
| 1行説明 | 罫線の下 | その章で得られることを1行で |
| 頁の注記 | 説明の下 | 「p.3 〜 p.8」。11.5px・muted。省略可 |
| 現在章のカード | 1枚目 | アクセント塗り＋白文字。このスライドで唯一の塗り |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-toc-section-cards を使って目次を1枚生成してください。
【KICKER】Contents ／ 目次
【カード】
01 制作フローの詰まり／時間を取られる工程を見る／p.3 〜 p.8　← 現在（塗り）
02 AIと人の役割分担／判断の主体を先に決める／p.9 〜 p.15
03 現場に入れる手順／小さな案件で試して広げる／p.16 〜 p.22
```
### 注意点
- 章は3つが基本。4章なら章名を全角8文字以内に詰める。5章以上は agenda-toc / toc-two-column へ
- 章名は1行（全角12文字程度）、説明は1行（全角13文字程度）に収める。2行になっても等高で揃うが、文字を小さくして詰めない
- 塗るのは現在章の1枚だけ。他のカードは soft 地のまま（上辺ライン・影・バッジを足さない）
- 再掲時は `tsc-cur` を進行中の章へ移す。初出の目次で現在地を示さない場合は、1枚目を塗るか、全カードを soft 地にしてもよい
- カードの中身は上ぞろえ（中央ぞろえにしない）。頁の注記が不要なら外してよい

## v2 での描き直し（2026-09-03）
- 「CONTENTS＋本日の流れの見出し行＋上辺3pxラインの白カード4枚（淡色30px番号・14px章名・11px説明）」から、soft地・角丸11pxの章カード3枚（等幅・等高）に描き直し、現在章だけアクセント塗り＋白文字にした（塗りは1枚）
- カードの中身を v2 の型「KICKER（01 ／ SECTION）→ 章名18px/700 → 細罫線 → 1行説明16px → 頁の注記11.5px」で上ぞろえに揃え、見出し行は `sk-head`（見出しON）と英字KICKERに分けた
- 太さを400/700の2つに絞り、`palt`・`line-break:strict`・左右48px・`.content-area`（見出しON時は上76px）の組みに揃えた
