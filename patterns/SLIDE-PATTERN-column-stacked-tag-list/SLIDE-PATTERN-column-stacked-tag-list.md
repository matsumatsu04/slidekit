# SLIDE-PATTERN-column-stacked-tag-list

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** column-stacked-tag-list
**概要：** コンテンツエリアを3列に等分し、各列を「英字ラベル（KICKER）→列見出し（18px・700）→細罫線→タグの縦積み」の型で組むレイアウト。タグは14px・淡い地・角丸6pxで、文字幅に合わせて左寄せに並べる（縦8px間隔）。列の間は1pxの縦罫線。塗りは「列の中の1タグだけ」か「無し」。列ごとに項目数が違ってもよい。
**適したシーン：** カテゴリ別の項目一覧、部門別のタスク・担当一覧、分類ごとの用語整理、列数に対して項目数が偏るリスト

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、等幅・等高の列3本を置き、列の間に1pxの縦罫線を挟む（列の内側余白は24px・両端は0）。中身は上ぞろえ。束の下に注記1行。

    structure:
      layout: column-stacked-tag-list
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        align_items: stretch        # 3列は等高。中身は上ぞろえ
        divider: "1px var(--sk-line)"   # 列の間の縦罫線
      column:
        padding: "0 24px"           # 両端の列は外側0
        elements:
          - kicker: "英字ラベル ／ 補足"   # 10px / 700 / .18em（例: PLAN ／ 企画）
          - heading                        # 18px / 700
          - rule                           # 1px var(--sk-line)。上12px・下16px
          - tags:                          # 14px・淡い地・角丸6px・padding 4px 12px・左寄せ・縦8px間隔
              count: variable per column   # 例: 4 / 5 / 3
        emphasis: 0 or 1 tag (accent_fill, white text)   # 列の中の1タグだけ塗るか、塗らない
      note: "例：〜"                 # 11.5px / muted。束の下に1行

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各列左上 | `PLAN ／ 企画` のようにカテゴリを英字＋日本語で。アクセント色 |
| 列見出し | KICKER の下 | その列の内容を一言で（8文字前後・18px・700） |
| 細罫線 | 見出しの下 | 見出しとタグの区切り（`--sk-line`） |
| タグ | 罫線の下・縦積み | 個別の項目を短い文字で（10字以内）。淡い地・角丸6px・文字幅に合わせて左寄せ |
| 塗りタグ | 列の中の1つ（任意） | 今の工程・主役の項目。アクセント塗り・白文字。1枚で1つまで |
| 縦罫線 | 列の間 | 1pxの罫線色。カテゴリの切り替えを示す |
| 注記 | 束の下 | 「例：〜」で塗りの意味や条件を1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-column-stacked-tag-listのレイアウトで、3列それぞれに KICKER・列見出し・タグ（[項目リスト]）を入れてください。列ごとの項目数は揃えなくて構いません。今の工程にあたる1タグだけ塗りにし、束の下に「例：〜」を1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 列数は3列基本（最大4列）。5列以上は1列が狭くなりタグが折り返す
- 1列あたりの項目数は2〜6個。極端に多い列は上位カテゴリで束ねる
- タグの文字は短く（10字以内）。1タグは1行。長文は入れない
- 塗りは列の中の1タグだけか無し。列ごとに1つずつ塗らない
- 列ごとに項目数が違うのは想定どおりの見た目。空欄で埋めて揃えない（列の高さは flex stretch で揃う）
