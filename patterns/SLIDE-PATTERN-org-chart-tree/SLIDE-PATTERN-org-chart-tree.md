# SLIDE-PATTERN-org-chart-tree

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** org-chart-tree
**概要：** 最上段に頂点ノード1個、その下に2段目3個、さらに各2段目の下に3段目2個ずつ（計6個）を置く、上から下への3段組織図。ノードは淡い地・角丸8pxで「役職の英字ラベル（KICKER）＋名前（16px・700）」の型。頂点だけアクセント塗り・白文字にする（塗りは1枚に1つ）。接続線は1pxの罫線色の直角線だけで、端点をノードの上辺・下辺の中心で止める。
**適したシーン：** 組織図・体制図の説明、役割分担の階層表示、プロジェクト体制の提示

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に 864×288px のステージを置き、ノードを絶対配置する。行の高さは64px固定、段の間は48px。接続線は1枚の SVG で引き、幹線は「最初の接続点の中心」から「最後の接続点の中心」まで。白い矩形で線を消さない。

    structure:
      layout: top-down-org-tree
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      stage: 864x288               # ノードは絶対配置。行高64px・段間48px
      node_common:
        border_radius: 8px
        height: 64px                # 固定（名前が長くても高さを変えない＝線の端点がずれない）
        elements:
          - kicker: "役職の英字 ／ 日本語"   # 10px / 700 / .18em（塗りノード内は白）
          - name                            # 16px / 700 / 1行
      level-1:
        nodes: 1 (width 200px, accent_fill, white text)   # 塗りはここだけ
      level-2:
        nodes: 3 (width 200px, soft)         # 各ブランチ幅272px・ブランチ間24px の中央
      level-3:
        nodes: 6 (width 132px, soft, 2 per branch, gap 8px)
      connector:
        type: right-angle lines only         # 縦の幹線 → 横の母線 → 縦の枝
        stroke: 1px var(--sk-line)
        endpoints: node edge centers         # 下辺の中心から出て、上辺の中心で止まる
      constraint: total nodes <= 10 (1 + 3 + 6)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 頂点ノード | 最上段中央 | 組織・プロジェクトの代表。アクセント塗り・白文字（1枚で塗るのはここだけ） |
| 2段目ノード | 中段・3個 | 部門長・リーダー。淡い地 |
| 3段目ノード | 下段・各2個 | 担当者。淡い地・幅132px |
| KICKER | 各ノード上段 | `SALES ／ 営業部長` のように役職を英字＋日本語で。アクセント色（塗りノード内は白） |
| 名前 | KICKER の下 | 氏名を16px・700で1行（5文字前後）。肩書や説明は入れない |
| 接続線 | 段の間 | 1pxの罫線色。縦横の直角線のみ。端点はノード辺の中心 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-org-chart-treeのレイアウトで、頂点に[代表の役職と氏名]、2段目に[部門長3名]、各部門の下に[担当2名ずつ]を置いてください。各ノードは KICKER（役職の英字 ／ 日本語）＋氏名の順で書き、塗りは頂点だけにしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- **ノード数は最大10個**（頂点1＋2段目3＋3段目6）。増やすときは3段目を省くか、部門ごとに枚数を分ける
- **接続線は1pxの直角線のみ**。斜め線・曲線・矢印は使わない。線を太くしない
- 3段目を減らす（1名の部門がある）ときも、線はそのノードの上辺中心で止める。空いた位置に線を残さない
- 名前は1行に収める（幅132pxのノードで5文字前後）。役職の補足は KICKER 側に書く
- 塗りは頂点だけ。部門を強調したいときも2段目を塗らず、KICKER の文言で示す

## v2 での描き直し（2026-09-03）
- 2px枠のネストリスト（`li::before/::after` で線を描き、両端のはみ出しを打ち消す方式）をやめ、ノードを 864×288 のステージに絶対配置し、接続線を1枚の SVG（1px・罫線色）で端点までの長さだけ引く形にした
- ノードを淡い地・角丸8pxの「役職KICKER＋名前16px/700」の型に揃え、頂点だけアクセント塗り・白文字にした（塗りは1枚に1つ）
- 行の高さを64px固定にして、名前の長さで線の端点がずれないようにした。左右余白48px・字間.06em・インク色に揃えた
