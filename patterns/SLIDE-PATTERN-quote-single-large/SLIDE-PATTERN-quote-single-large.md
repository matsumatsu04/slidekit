# SLIDE-PATTERN-quote-single-large

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** quote-single-large
**概要：** 引用文1つを主役にする白地のスライド。左右120pxの余白を取り、上から「引用符（`--sk-line` 色・64px・400・装飾）」「引用文（24px・400・字間.08em・行間1.8・2〜3行）」「細罫線（全幅・1px）」「出典（英字ラベル `Voice ／ 受講生の声` → 名前16px → 注記）」を左ぞろえで積む。引用符は本文に重ねず上段に置く。塗り・写真枠・図形は使わない。
**適したシーン：** 顧客の声・推薦コメント・受講生の感想を「1つだけ深く」見せる場面。導入事例の冒頭。

## Structure（構造）

コンテンツエリア（左右余白120px・見出しON時は上76px以降）の上下中央に、引用符→引用文→罫線→出典を左ぞろえで積む。

    structure:
      layout: content-area-centered (vertical)
      margin: 120px 左右
      align: left
      elements:
        - mark: "“"                       # 64px / 400 / serif / var(--sk-line)。高さ40pxの上段（本文に重ねない）
        - quote: 引用文 2〜3行            # 24px / 400 / 字間 .08em / 行間 1.8 / インク色
        - rule: 全幅 × 1px               # var(--sk-line)。上32px・下20px
        - kicker: "Voice ／ 受講生の声"    # 10px / 700 / 字間 .18em / 大文字 / アクセント色
        - name: 発言者 1行                # 16px / 400 / インク色
        - note: "例：〜"（省略可）         # 11.5px / muted 色
      fill: none

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 引用符 | 引用文の上（淡色・64px） | 引用であることを示す装飾。`--sk-line` 色で本文に重ねない |
| 引用文 | 中央（24px・400・2〜3行） | このスライドの主役。最も印象的な一文〜二文を選ぶ |
| 細罫線 | 引用文と出典の間（全幅・1px） | 引用と出典の切り替え |
| 英字ラベル（KICKER） | 罫線の下 | 声の種別を小さく示す（`Voice ／ 受講生の声`）。アクセント色 |
| 名前 | ラベルの下（16px） | 発言者。属性・肩書を（ ）で添える |
| 注記 | 名前の下（11.5px・muted・省略可） | 許諾・出典・条件を1行で |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-quote-single-largeのレイアウトで、引用文「[2〜3行]」、ラベル「Voice ／ [種別]」、発言者「[名前（属性）]」のスライドを作成してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 引用文は2〜3行（1行26字以内）。`<br>` は文の切れ目で入れ、行末に1〜2文字だけ残る折り返しを作らない
- 引用文は400（太字にしない）。大きさと余白で読ませる。アクセント色の文字や塗りで強調しない
- 発言者の実名・社名・数値は本人の許諾を確認してから書く。未確認なら「受講生Aさん」のように伏せる
- 複数の声を並べたい場合は testimonial-quote-grid を使う

## v2 での描き直し（2026-09-03）
- 110pxの特大引用符（`--sk-soft`）を本文の上に重ねる構成をやめ、`--sk-line` 色・64px・400の引用符を本文に重ねない上段に置いた
- 引用文を24px太字・行間1.9から24px・400・字間.08em・行間1.8に変え、円形写真＋氏名を「細罫線→英字ラベル→名前16px→注記」の出典型に置き換えた（Font Awesome 依存を外した）
- 絶対座標の配置を `.content-area`（左右120px・上下中央）の縦積みにし、プレースホルダを型が伝わる具体例にした
