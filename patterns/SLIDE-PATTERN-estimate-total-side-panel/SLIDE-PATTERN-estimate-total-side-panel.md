# SLIDE-PATTERN-estimate-total-side-panel

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** estimate-total-side-panel
**概要：** 左に明細表（列見出しはKICKER・行は横の細い罫線だけ・項目16px太字＋内容＋右ぞろえの金額・4〜5行・合計行なし）、右に幅280pxの合計パネル（アクセント塗り・白文字・角丸11px）を等高で並べる。パネルの中身は KICKER `TOTAL ／ 合計` → 金額28px＋単位 → 白35%の細罫線 → 条件3行（税区分・有効期限・支払）→「例：」の注記。合計と条件をパネルの「顔」で先に見せ、明細は表で読ませる。塗りは右パネルだけ。
**適したシーン：** 見積・料金の提示で合計金額と取引条件を最初に見せて合意を取りたい場面。内訳4〜5件の概算見積、提案書の金額ページ。

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、左＝明細表（可変幅）、右＝合計パネル（幅280px）を gap 16px・等高（312px）で並べる。表は本物の `<table>` で、列見出しはKICKER型（塗らない・下罫線だけ）、データ行は高さ48px・横罫線だけ、合計行は持たない（合計は右パネルに置く）。表の下端に「例：〜」の注記。右パネルはアクセント塗り（白文字）で、KICKER→金額28px＋単位→白35%の罫線→条件3行（ラベルと値を左右に振る・16px・白80%）→注記の型。

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 列見出し | 表の最上行 | `Item ／ 項目` のようにKICKER型で列の意味を示す。塗らない |
| 明細行 | 表の中段（4〜5行） | 項目名（太字）／内容／金額（右ぞろえ）。細い罫線だけで区切る |
| 注記 | 表の下端 | 「例：〜」で追加費用の目安を1行 |
| 合計パネル | 右（幅280px） | 唯一の塗り。合計と取引条件をまとめた「顔」 |
| 金額 | パネルのKICKER下 | 結論の合計金額（28px・太字・白）。単位に税区分を添える |
| 条件3行 | 白35%の罫線の下 | 税区分・有効期限・支払条件。ラベルと値を左右に振る（16px・白80%） |
| パネル注記 | パネル下端 | 「例：」で初回の支払額など具体を1行 |

## Usage Guide（AIへの使い方）

プロンプト例：

> 「SLIDE-PATTERN-estimate-total-side-panelのレイアウトで見積スライドを作成してください。明細は『サイト設計｜ページ構成・ワイヤーフレーム｜¥120,000』『デザイン｜TOP＋下層4ページ｜¥280,000』『実装｜ノーコード構築・フォーム設置｜¥200,000』『写真撮影｜半日・20カット納品｜¥60,000』『ディレクション｜進行管理・公開前の確認｜¥40,000』の5行、合計 ¥700,000（税別）。右のパネルには税区分・有効期限・支払条件を3行で書いてください。デザインはSLIDE.mdに従ってください。」

注意点：
- 塗りは右の合計パネルだけ。旧版の「左33%の全高パネル」「番号バッジ付きの内訳カード2列」は廃止した。内訳は罫線だけの表にする
- 表に合計行を置かない（合計は右パネルの1箇所だけ。金額の二重表示を避ける）。パネルの合計は表の金額の合計と必ず一致させる
- 明細は4〜5行。3行以下なら price-total-highlight、6行以上なら estimate-amount-table を使う
- 内容セルは14文字以内、条件の値は10文字以内で1行に収める（文字は小さくしない）
- 白文字はパネルの上だけ。表側の文字はインク色のまま
