# SLIDE-PATTERN-estimate-total-side-panel

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** estimate-total-side-panel
**概要：** 左33%を全高のアクセント色縦パネルにして、見積ラベル（英字併記）＋このスライド最大の白い合計金額＋細い白罫で区切った取引条件3行（税区分・有効期限・支払条件）を置く。右67%は白地に、内訳を薄グレー地・枠線なし・角丸のカード（正方形番号バッジ＋項目名太字＋作業内容1行＋右端に金額右揃え）で2列に並べ、右下に注記1行を添える。明細表の格子を作らず、合計と条件を「顔」として固定し、内訳は読み物カードにする。
**適したシーン：** 見積・料金の提示で、合計金額と取引条件を最初に見せて合意を取りたい場面。内訳2〜6件の概算見積、提案書の金額ページ。

## Structure（構造）

```yaml
content-area:
  layout: two-zone (左パネルは全高・フルブリード)
  zones:
    - side-panel:                  # 左33%・アクセント色の塗り・縦センタリング
        - estimate-label:          # 「お見積り」等のラベル（小・白）
        - en-label:                # 字間広めの英字（ESTIMATE 等・任意）
        - total-amount:            # 合計金額。白・このスライド最大
        - terms: 3                 # 細い白罫で区切る条件行
            - term-label:          # 税区分・有効期限・支払条件（小）
            - term-value:          # 値（太字・白）
    - breakdown:                   # 右67%・白地・縦センタリング
        - cards: 2列 × 2〜3行      # 薄グレー地・枠線なし・角丸カード
            - number-badge:        # 小さな正方形の番号バッジ
            - item-name:           # 項目名（太字）
            - item-amount:         # 金額（右端・右揃え・太字）
            - item-desc:           # 作業内容1行（グレー小）
        - note:                    # 右下に注記1行
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| side-panel | 左33%・全高 | 合計と取引条件をまとめた「顔」。唯一の塗り面 |
| total-amount | パネル中央上寄り | 結論の合計金額。スライドで最大の文字にする |
| terms | パネル下部 | 税区分・有効期限・支払条件。細い白罫だけで区切る |
| card | 右ゾーンに2列 | 内訳1件。面と余白で区切り、表の檻を作らない |
| number-badge | カード左上 | 内訳の通し番号。小さな正方形で行頭を揃える |
| item-amount | カード右端・右揃え | 個別金額。桁の頭を揃えて比較しやすくする |
| item-desc | 項目名の下 | 何をするかの1行説明。金額の根拠を添える |
| note | 右ゾーン右下 | 別途費用・前提条件などの補足1行 |

## Usage Guide（AIへの使い方）

プロンプト例：
「estimate-total-side-panel パターンで見積スライドを作成。合計800,000円（税別）、有効期限は発行から1ヶ月、支払は着手50%・納品50%。内訳は『デザイン 300,000円』『実装 350,000円』『ディレクション 100,000円』『保守初期設定 50,000円』の4件」

注意点：
- 内訳は2〜6件。1〜3件なら1列に、4〜6件なら2列にする（列が変わってもカードの作りは同じ）。7件を超える明細は estimate-amount-table を使う
- 合計金額はパネル内で最大＝スライド全体でも最大にする。内訳カードの金額を合計より大きくしない
- パネルの合計と内訳の合計は必ず一致させる
- 白文字はパネルの上のみ。カード側の文字は本文色のまま（塗り面はパネル1箇所）
- 取引条件は3行が基準（2〜4行）。長文の条件は右下の注記に逃がす
- 合計だけを1枚で大きく見せたい（内訳カードが不要な）場合は price-total-highlight を使う
