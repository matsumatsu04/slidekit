# SLIDE-PATTERN-section-photo-overlay-left

このファイルはコンテンツエリアのレイアウト定義です。背景に画像アセット（`assets/covers/`）を使い、テキストはHTMLとして画像の上に載せます。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い）。
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません（暗い写真の頁では白抜きにする）。

## Overview
**パターン名：** section-photo-overlay-left
**概要：** 実写写真をフルブリード背景にし、暗色オーバーレイ（rgba(15,18,24,.45)）をかけた上に、左80pxの文字ブロックを上下中央で置く中扉。ブロックは「英字KICKER『SECTION 03』（10px・白82%）→ 章タイトル（32px・700・白・1〜2行）→ 64px×1pxの白罫線 → 補足1行（16px・白85%）」の縦積み。面は写真とオーバーレイの2層だけで、装飾は罫線1本に絞る。
**適したシーン：** 高級感・ブランド訴求のデッキの章区切り。写真素材の表紙と組で使い、表紙〜中扉のトーンを揃える。

## Structure（構造）
```yaml
layout: section-photo-overlay-left
background:                        # 画像背景系。色ティントの対象外（画像は差し替えのみ）
  photo:   url(/assets/covers/cover-bg-photo-architecture.jpg)   # center/cover・全面
  overlay: rgba(15,18,24,.45)                                    # 写真に合わせた固有色。白文字の可読性を作る
text-block:                        # left 80px・top 50% の上下中央・max-width 640px・左ぞろえ
  kicker: "SECTION 03"             # 10px / 700 / 字間 .2em / 大文字 / 行間 1 / rgba(255,255,255,.82)
  title:  章タイトル                # 32px / 700 / 字間 .06em / 行間 1.35 / #FFFFFF。1〜2行。上に 20px
  rule:   64px × 1px               # rgba(255,255,255,.4)。上 24px・下 20px。唯一の装飾
  sub:    補足1行                   # 16px / 400 / 行間 1.8 / rgba(255,255,255,.85)。省略可
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景写真 | 全面 | 実写素材（`/assets/covers/cover-bg-photo-architecture.jpg`）。他の写真アセットに差し替え可 |
| 暗色オーバーレイ | 全面 | 白文字の可読性を確保する暗幕。写真の明るさに応じて .35〜.55 で調整してよい |
| KICKER | 文字ブロック最上段 | 章番号を英字ラベルで示す（`SECTION 03`）。白82%で本文より一段落とす |
| 章タイトル | KICKERの下 | 章の内容を1〜2行で言い切る。32px・700・白 |
| 白罫線 | タイトルと補足の間 | 64px×1px・白40%。このスライドで唯一の装飾 |
| 補足 | 罫線の下 | この章で扱うことを1行で補う（省略時は罫線も外してよい） |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-photo-overlay-left を使って中扉を1枚生成してください。
【KICKER】SECTION 03
【章タイトル】導入前に決めておく／判断基準と承認の体制
【補足】誰が何を承認するかを先に決め、後戻りが起きる工程を減らす
```
### 注意点
- 章番号は英字KICKERで持つ（`SECTION 03`）。大きな数字を別に置かない（大きさは章タイトルで作る）
- 章タイトルは32pxで2行まで（1行あたり全角12文字程度）。2行にするときは `<br>` を意味の切れ目に入れる。標語調にしない
- 文字はすべて白（暗い写真の上に #333 系を載せない）。KICKER・補足は半透明白で階調を付ける
- 背景写真は16:9で「文字なし・全体やや暗め」「左半分が静か」な素材を使う（`assets/covers/` に置いて差し替える）
- 写真の左側が明るい素材に替えたときは、オーバーレイを .55 まで濃くしてから使う
- 背景に画像を焼き込むため、ギャラリーの色ティント（パレット）はこのパターンに乗らない。パレットを見せたい章区切りは section-divider / section-band-middle を使う
- 画像を使わない同構図が要るときは section-left-number-line（白地・番号の行）へ

## v2 での描き直し（2026-09-04）
- 4px の白縦バーを外し、装飾を「タイトル下の 64px×1px の白罫線」1本に絞った（v2「装飾は細い罫線1つまで」）
- 章番号を 15px の見出し扱いから 10px・字間 .2em の英字KICKER（白82%）に、章タイトルを 36px から 32px/700・行間1.35 に組み替え、補足1行（16px・白85%）を足した
- 文字ブロックの起点を左72pxから左80pxに揃え、太さを 400/700 の2つに絞って中扉4種（P099・P106〜P108）で組みを共通化した
