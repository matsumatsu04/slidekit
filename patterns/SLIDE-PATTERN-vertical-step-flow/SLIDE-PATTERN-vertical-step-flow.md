# SLIDE-PATTERN-vertical-step-flow

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** vertical-step-flow
**概要：** 4つのステップを縦に積み、左の番号（24px・アクセント色）を細い幹線でつなぎ、右に見出し・本文・注記を置く縦フロー。最後の番号だけ 1.5px の丸枠で囲む（塗りなし）。
**適したシーン：** 選考フロー・申込フロー・業務プロセス・手順書など、順番通りに進む流れを示す場面

## Structure（構造）

コンテンツエリア（左右余白120px＝幅720px）の上下中央に、高さ固定（96px）の行を4つ積む。各行は左の番号（40px角）と右のテキスト（見出し→本文→注記）の2列。番号の中心を通る幹線（1px・罫線色）を、最初の番号の中心から最後の番号の中心まで引く。最後の行だけ番号を丸枠で囲み、見出しをアクセント色にする。塗りは使わない。

    structure:
      layout: vertical-flow
      content_area:
        padding: "24px 120px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      steps: 4                      # 標準。5つのときは行高を84pxにして注記を省く
      row:
        height: 96px                # 固定（幹線の端点を番号の中心で止めるため）
        gap: 24px                   # 番号列とテキスト列の間
        left:
          number: "01"              # 24px / 400 / アクセント色。40px角・白地（幹線の上に載る）
          last: circle-outline      # 最後だけ 1.5px のアクセント色の丸枠（塗らない）
        right:
          elements:
            - heading               # 18px / 700（番号と垂直中心を合わせる）
            - body: 1 line          # 16px / 400 / 行間1.8（24文字以内）
            - note: "例：〜"        # 11.5px / muted
      trunk:
        type: vertical-line
        width: 1px
        color: line                 # var(--sk-line)。塗り・矢印なし
        from: first number center
        to: last number center

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 番号 | 各行左（40px角） | `01`〜`04`。24px・細め・アクセント色。幹線の上に載るので地は白 |
| 幹線 | 番号列の中心 | 最初の番号の中心から最後の番号の中心までの1px線。順序を示す |
| 見出し | 番号の右・行の上端 | そのステップでやること（12文字前後） |
| 本文 | 見出しの下 | 内容を1行で（24文字以内） |
| 注記 | 本文の下 | 「例：〜」で目安・所要・条件を1行添える |
| 丸枠の番号 | 最後の行 | 到達点・最終ステップを塗らずに区別する（見出しもアクセント色） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-vertical-step-flowのレイアウトで、[フロー名]の4ステップを縦に並べて説明してください。各行は見出し・本文1行（24文字以内）・「例：〜」の順で書き、最後のステップは丸枠の番号にしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 4ステップが標準。5ステップは行高を84pxにして注記を省く（本文は1行のまま）。6以上は枚数を分ける
- 塗りは使わない。最終ステップの区別は丸枠＋アクセント色の見出しだけで行う
- 本文は1行に収める。入らないときは文字を小さくせず、文言を短くする
- 幹線は番号の中心で止める（行の高さを固定にしてあるので、行数を変えるときは `bottom` の値＝行高−20px を保つ）
- 旧版の「ラベル塗りセル＋枠線セル＋▼矢印」は廃止。番号と幹線だけで流れを示す
