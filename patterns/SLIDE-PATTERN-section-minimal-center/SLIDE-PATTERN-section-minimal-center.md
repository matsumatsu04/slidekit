# SLIDE-PATTERN-section-minimal-center

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い）。
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません（全面塗りの頁では白抜きにする）。

## Overview
**パターン名：** section-minimal-center
**概要：** 全面をアクセント色で塗り、白文字で章を切り替える最小構成の中扉。中央に「英字KICKER（半透明白）→ 章タイトル → 48×1px の白線 → 説明1行（半透明白）」を縦に積み、全体を上下中央に置く。塗りは全面の1つだけ、装飾は白線1本だけ。
**適したシーン：** 落ち着いた・上質なトーンのデッキの章区切り。表紙が淡い地なので、中扉は塗りで反転させる（デザインの規律 v2・6）。

## Structure（構造）
```yaml
layout: section-minimal-center
background: var(--sk-accent)      # 全面塗り。文字はすべて白（グレー版のフォールバック地は #555555）
wrap:                             # left/right 48px・全高の上下中央・中央ぞろえ・縦積み
  kicker: "SECTION 01"            # 10px / 700 / 字間 .2em / 大文字 / rgba(255,255,255,.7)
  title:  章タイトル               # 30px / 700 / 字間 .08em / 行間 1.5 / 白。max-width 760px・1〜2行。上に 24px
  rule:   48px × 1px              # rgba(255,255,255,.7)。上下 28px。唯一の装飾
  sub:    説明1行                  # 16px / 400 / 行間 1.8 / rgba(255,255,255,.85)。max-width 760px
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 中央上 | 「SECTION 01」のように章番号を英字ラベルで示す（半透明白・字間広め） |
| 章タイトル | KICKERの下 | 章の内容を1〜2行で言い切る。標語調にしない |
| 白線 | タイトルと説明の間 | 48×1px の細い白線。タイトルと説明の切り替え |
| 説明 | 白線の下 | この章で扱うことを1行で補う（省略可。省略時は白線も外してよい） |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-minimal-center を使って中扉を1枚生成してください。
【KICKER】SECTION 01
【章タイトル】制作の現場で起きている詰まり
【説明】工程ごとに、どこで手が止まるかを先に見る
```
### 注意点
- 要素を足さない（ミニマルさが価値）。現在地を見せたい場合は section-tag-progress へ
- 章タイトルは30pxで2行まで（1行あたり全角15文字程度）。2行にするときは `<br>` を意味の切れ目に入れる
- 文字はすべて白（濃色地に #333 系を載せない）。KICKER と説明は半透明白で階調を付ける
- アクセント色の塗りはこの1枚で全面に使うため、他の塗り・差し色・影は足さない
- 背景画像レイヤー（`slides[].bg`）は OFF にする（全面塗り）

## v2 での描き直し（2026-09-02）
- 白地に「0 3・短い太線・黒い章タイトル」を置く旧構成から、全面アクセント塗り＋白文字の中扉に描き直した（表紙の淡い地と反転させる）
- 章番号を英字KICKER「SECTION 01」（10px・.2em・半透明白）に変え、章タイトル 30px/700/.08em → 白線 48×1px → 説明 16px の型にした
- 太さを 400/700 の2つに絞り、`palt`・`line-break:strict`・左右48px・上下中央の組みに揃えた
