# SLIDE-PATTERN-section-soft-3d-number-row

このファイルはコンテンツエリアのレイアウト定義です。背景に画像アセット（`assets/covers/`）を使い、テキストはHTMLとして画像の上に載せます。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い）。
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。

## Overview
**パターン名：** section-soft-3d-number-row
**概要：** 半透明3Dオブジェクトが右半分に浮く淡色背景の左に、「章番号｜文字ブロック」の横並びの行を上下中央で置く中扉（この行の構図がこのパターンの識別子）。章番号は96px・400・#8F9AAB、右の文字ブロックは「英字KICKER『SECTION』（10px・accent2）→ 章タイトル（32px・700・インク色）→ 64px×1pxの罫線 → 補足1行（16px・muted）」の縦積み。行は左80pxから始め、max-width 560px で右の3Dオブジェクト群を避ける。
**適したシーン：** IT/SaaS・テック系デッキの章区切り。同じ背景の表紙 cover-soft-3d-left と組で使う。

## Structure（構造）
```yaml
layout: section-soft-3d-number-row
background:                        # 画像背景系。色ティントの対象外（画像は差し替えのみ）
  image: url(/assets/covers/cover-bg-soft-3d.jpg)   # center/cover・全面
row:                               # left 80px・top 50% の上下中央・max-width 560px・display:flex・align:center・gap 32px
  number: "04"                     # 96px / 400 / 字間 .02em / 行間 1 / #8F9AAB（背景に合わせた固有色）
  block:                           # 縦積み・左ぞろえ
    kicker: "SECTION"              # 10px / 700 / 字間 .2em / 大文字 / 行間 1 / var(--sk-accent2)
    title:  章タイトル              # 32px / 700 / 字間 .06em / 行間 1.35 / var(--sk-ink)。1〜2行。上に 14px
    rule:   64px × 1px             # #8F9AAB。上 20px・下 16px。唯一の装飾
    sub:    補足1行                 # 16px / 400 / 行間 1.8 / var(--sk-muted)。省略可
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景 | 全面 | 半透明3Dオブジェクトの淡色素材（`/assets/covers/cover-bg-soft-3d.jpg`）。他アセットに差し替え可 |
| 章番号 | 行の先頭 | 2桁ゼロ埋めの細字（400）・96px。塗り・囲みにせず、大きさと細さで章の切り替えを示す |
| KICKER | 文字ブロック最上段 | `SECTION` の英字ラベル。番号は左の数字が持つので、ここには番号を重ねない |
| 章タイトル | KICKERの下 | 章の内容を1〜2行で言い切る。32px・700・インク色 |
| 罫線 | タイトルと補足の間 | 64px×1px・#8F9AAB。番号と同じ色で行の中をつなぐ唯一の装飾 |
| 補足 | 罫線の下 | この章で扱うことを1行で補う（省略時は罫線も外してよい） |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-soft-3d-number-row を使って中扉を1枚生成してください。
【章番号】04
【KICKER】SECTION
【章タイトル】運用に移したあとの／見直しの周期
【補足】月1回の見直しで手順を直す
```
### 注意点
- 行全体を左半分（max-width 560px）に収める。右の3Dオブジェクト群に文字を被せない
- 章番号は太字にしない（400のまま。太くすると番号が主役になり、タイトルが読まれなくなる）
- 章タイトルは番号の右に入る幅（約420px）で2行まで。1行あたり全角9〜10文字を目安に `<br>` を意味の切れ目に入れる
- 補足は1行・短め（全角15文字程度）。入らなければ文言を短くする（文字を小さくしない）
- #8F9AAB は背景に合わせた固有色。背景を別の画像に差し替えたときは、その画像の中間色に合わせて置き換える
- 背景に画像を焼き込むため、ギャラリーの色ティント（パレット）が乗るのは KICKER の accent2 だけ
- 白地ミニマルの同構図は section-left-number-line。画像背景で世界観を持たせたいときにこちらを使う

## v2 での描き直し（2026-09-04）
- 章番号を 110px・太字から 96px・400 に落とし（太さは 400/700 の2つに統一）、行の構図（番号｜文字ブロック）はそのまま残した
- 章タイトルを 30px から 32px/700・行間1.35・インク色にし、タイトル下の 3px 濃色線を 64px×1px の #8F9AAB 罫線に変えて、上に英字KICKER・下に補足1行（16px・muted）を足した
- 行の起点を左72pxから左80pxに揃え、中扉4種（P099・P106〜P108）で文字の組みを共通化した
