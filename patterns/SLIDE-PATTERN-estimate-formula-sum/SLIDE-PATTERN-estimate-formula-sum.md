# SLIDE-PATTERN-estimate-formula-sum

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** estimate-formula-sum
**概要：** 上段に内訳の角丸白カード（下線付き項目ラベル＋課金単位＋特大金額＋含まれる内容1行）を2〜4枚横並びにし、カード間の垂直中央に円形の＋演算子、最後に＝を挟んで右端に濃色反転の合計カード（合計ラベル＋白特大金額＋税注記）を置く。中段に注記2行、下段に薄グレー地の「ご利用イメージ」帯（規模別の条件と総額のミニ表を等幅3列）を敷く。罫線の格子を使わず、面と余白と式で金額の構造を見せる。
**適したシーン：** 見積・料金提示で「なぜその金額か」を足し算の構造ごと見せたい場面。Web制作や受託の概算提示、提案書の金額サマリーページ。

## Structure（構造）

```yaml
content-area:
  layout: vertical-stack (縦センタリング)
  sections:
    - formula-row:                 # 上段 約55%
        sequence: [item-card, op(+), item-card, op(+), item-card, op(=), total-card]
        item-card:                 # 2〜4枚可変・等幅・角丸白カード
          - item-label:            # 下線付きの項目ラベル（小）
          - unit-label:            # 課金単位（一式・月額など・小）
          - amount:                # 特大金額＋小さめの円
          - included:              # 含まれる内容1行（グレー小）
        op:                        # 円形のアクセント色演算子。カード列の垂直中央
        total-card:                # アクセント色の反転カード（式の答え）
          - total-label
          - total-amount:          # このスライド最大の金額（白）
          - tax-note:              # 税注記（小）
    - notes:                       # 中段。※注記2行（小・左揃え・グレー)
    - usage-band:                  # 下段 約25%。薄グレー地の全幅ボックス
        - band-head:               # 「ご利用イメージ」など帯の見出し（小）
        - sim-cells: 3             # 等幅横並び・間に細い縦罫のみ
            - condition:           # 上行=規模・条件（グレー小）
            - sim-total:           # 下行=総額のみ（太字・アクセント色）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| item-card | 上段に横並び（2〜4枚） | 内訳1件を1枚のカードで見せる。表の行ではなく面で区切る |
| item-label | カード上部 | 項目名。短い下線で見出し化する |
| amount | カード中央 | 個別金額。数字を主役にし単位は小さく添える |
| op（＋・＝） | カードの隙間の垂直中央 | 内訳が合計に足し上がる関係を式で示す |
| total-card | 式の右端 | 結論＝合計金額。唯一の塗り面にして最初に目が行くようにする |
| notes | 式の下 | 税・支払条件・前提などの補足2行 |
| usage-band | 下段全幅 | 規模別の総額シミュレーション。「自分の場合いくらか」に先回りする |
| sim-cell | 帯の中に等幅3列 | 条件1行＋総額1行のミニ2行表。区切りは細い縦罫のみ |

## Usage Guide（AIへの使い方）

プロンプト例：
「estimate-formula-sum パターンで見積スライドを作成。内訳は『デザイン 一式 300,000円』『実装 一式 400,000円』『保守 月額 30,000円』、合計730,000円（税別）。ご利用イメージは5ページ・10ページ・15ページの3パターン」

注意点：
- 内訳カードは2〜4枚。5件を超える明細はこのパターンに詰め込まず、estimate-total-side-panel（カード2列）か estimate-amount-table（明細テーブル）を使う
- concept-formula-three-box との使い分け：あちらは「A×B=C」という概念の式（アイコン枠＋ラベルのみ）。こちらは金額・課金単位・税注記・合計・規模別シミュレーション帯を持つ見積特化の1枚。金額を扱うならこちら
- 合計カードの金額をこのスライドで最大にする（項目カードの金額より一回り大きく）。式の答えが結論
- 演算子は＋と＝のみ。×や−を混ぜる構造（掛け算・値引き）はこのパターンでは表現しない
- ご利用イメージ帯の列は2〜4列まで可変。不要なら帯ごと省いてよい（式と注記だけでも成立する）
