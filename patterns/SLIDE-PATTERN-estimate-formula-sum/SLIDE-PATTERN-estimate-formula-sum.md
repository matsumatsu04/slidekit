# SLIDE-PATTERN-estimate-formula-sum

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** estimate-formula-sum
**概要：** 上段に内訳カード3枚（1.5pxの罫線枠・角丸10px。KICKER `DESIGN ／ 一式` → 項目名16px/700 → 細罫線 → 金額20px/700 tabular-nums → 「例：」注記）を横に並べ、カードの間に「＋」（24px・muted・テキスト。図形にしない）、最後に「＝」を挟んで右端に合計カード（アクセント塗り・白文字・角丸10px。KICKER `TOTAL` → 見出し16px → 細罫線 → 金額28px/700 → 注記）を置く。4枚は等高（168px）・上ぞろえで、金額は細罫線の下に寄せる。下段に規模別シミュレーション（KICKER → 3列。各列は見出し16px/700 → 金額16px → 注記11.5px。上下の横罫線だけで区切り、縦線・地色は使わない）。塗りは合計カードの1つだけ。
**適したシーン：** 見積・料金提示で「なぜその金額か」を足し算の構造ごと見せたい場面。Web制作や受託の概算提示、提案書の金額サマリーページ。

## Structure（構造）

コンテンツエリア（左右余白48px）に、上段の式の行（高さ168px）と下段のシミュレーション（上段の24px下）を縦に並べ、まとめて上下中央にする。式の行は「内訳カード168px ×3 ＋ 演算子40px ×3 ＋ 合計カード240px ＝ 864px」で幅を使い切る。

    structure:
      layout: formula-row / simulation-row
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      formula_row:
        height: 168px               # 4枚は等高・上ぞろえ
        sequence: [item-card, op(＋), item-card, op(＋), item-card, op(＝), total-card]
        item_card:                  # 幅168px・2〜4枚
          surface: none             # 1.5px var(--sk-line) の枠・角丸10px・padding 20px
          elements:
            - kicker: "DESIGN ／ 一式"           # 10px / 700 / .18em / アクセント色
            - name: "項目名（16px / 700・6文字以内）"
            - rule: "1px var(--sk-line)（margin-top:auto で金額をカード下部に寄せる）"
            - amount: "¥300,000（20px / 700 / tabular-nums）"
            - note: "例：〜（11.5px muted・12文字以内）"
        operator:
          width: 40px
          glyph: "＋ または ＝（24px / 400 / muted のテキスト）を垂直中央に"
        total_card:                 # 幅240px
          surface: accent_fill      # 唯一の塗り（白文字）・角丸10px・padding 20px 24px

            - kicker: "TOTAL ／ 合計"（白）

            - rule: "rgba(255,255,255,.35)"
            - amount: "¥740,000（28px / 700 / 白）"
            - note: "例：〜（白 85%）"
      simulation:                   # 下段
        kicker: "SIMULATION ／ 規模別の目安"
        row: 3 columns（等幅）, border-top / border-bottom 1px var(--sk-line) のみ

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 内訳カード | 上段に横並び（2〜4枚） | 内訳1件を1枚のカードで見せる。罫線枠だけの軽いカード |
| KICKER | 各カード左上 | `DESIGN ／ 一式` のように英字＋課金単位。合計カードでは白 |
| 項目名 | KICKER の下 | 内訳の名前（16px・太字） |
| 細罫線＋金額 | カード下部 | 個別金額（20px・太字・tabular-nums）。罫線で名前と分ける |
| 注記 | 金額の下 | 「例：」で含まれる内容を1行 |
| ＋／＝ | カードの隙間の垂直中央 | 内訳が合計に足し上がる関係を式で示す（文字1つ・muted） |
| 合計カード | 式の右端 | 結論＝合計金額（28px）。1枚で塗るのはここだけ |
| シミュレーション | 下段全幅 | 規模別の総額の目安。「自分の場合いくらか」に先回りする。横罫線だけで区切る |

## Usage Guide（AIへの使い方）

プロンプト例：

> 「SLIDE-PATTERN-estimate-formula-sumのレイアウトで見積スライドを作成してください。内訳は『デザイン 一式 ¥300,000』『実装 一式 ¥360,000』『進行管理 一式 ¥80,000』、合計 ¥740,000（税別）。規模別の目安は5ページ・10ページ・15ページの3列。デザインはSLIDE.mdに従ってください。」

注意点：
- 塗りは合計カードの1つだけ。旧版の「円形の演算子」「薄グレー地の帯」「白カード＋下線付きラベル」は廃止した。演算子はテキスト、内訳カードは罫線枠、シミュレーションは横罫線だけにする
- 内訳カードは2〜4枚。5件を超える明細はこのパターンに詰め込まず、estimate-total-side-panel か estimate-amount-table を使う
- 合計カードの金額（28px）をこのスライドで最大にする。内訳の金額は20px、シミュレーションの金額は16pxで、大きさの順を崩さない
- 演算子は＋と＝のみ。×や−を混ぜる構造（掛け算・値引き）はこのパターンでは表現しない
- 内訳に月額の項目を混ぜない（合計が「初期費用」なら足す項目も初期費用だけにする）。月額は注記に書く
- シミュレーションの列は2〜4列まで可変。不要なら下段ごと省いてよい（式だけでも成立する）
- concept-formula-three-box との使い分け：あちらは「A×B=C」という概念の式。金額を扱うならこちら

## v2 での描き直し（2026-09-04）
- 白カード＋下線付きラベルの内訳と円形のアクセント色演算子をやめ、1.5px罫線枠の内訳カード（KICKER→項目名16px/700→細罫線→金額20px/700 tabular-nums→例：）と、24px・mutedのテキスト「＋」「＝」に描き直した
- 塗りを合計カード（アクセント塗り・白文字・金額28px/700）の1つに絞り、4枚を等高168px・上ぞろえ（金額はカード下部にそろえる）にした
- 薄グレー地の「ご利用イメージ」帯と縦罫線を、KICKER＋3列（見出し16px/700・金額16px・注記11.5px）を上下の横罫線だけで区切る型にし、文字を v2 の表（KICKER 10px・本文16px・注記11.5px・太さ400/700・インク色）にそろえた
