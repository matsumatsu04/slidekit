# SLIDE-PATTERN-numbered-row-full-width

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** numbered-row-full-width
**概要：** 番号（24px・細め）・見出し・本文＋「例：」の3列を1行にした全幅の行を、細い罫線で区切って縦に積むリスト。塗りを使わず、罫線と番号だけで整える
**適したシーン：** 手順・ステップ紹介、事業領域・サービス一覧など、3〜4項目を番号付きで等価に並べたいとき（各行に具体例を添えたいとき）

## Structure（構造）

コンテンツエリア（左右余白48px）の全幅に、3列（番号64px｜見出し224px｜本文＝残り）の行を縦に積む。最上段に英字の列見出し（KICKER）を置き、各行は下辺の細い罫線で区切る。行の中は上ぞろえで、番号・見出し・本文の1行目の高さを合わせ、本文の下に「例：」の注記を添える。塗りや帯は使わない。行の束は本文エリアの上下中央に置く。

    structure:
      layout: stacked-rows
      row_count: 4
      columns: [number 64px, heading 224px, body flex]
      header: english column labels (kicker), thin rule below
      row:
        separator: thin rule (bottom)
        left: number (24px, regular)
        center: heading (16-18px, bold)
        right: body (16px, 1 line) + note ("例：" 11.5px)
      fill: none

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 列見出し（KICKER） | 最上段（`No.` `Step` `Detail`） | 列の意味を英字ラベルで示す。差し色を使う唯一の場所 |
| 番号 | 各行の左端（24px・細め） | 項目の順序。太くしない・囲まない |
| 見出し | 番号の右（太字） | 項目名・手順名（8字前後） |
| 本文 | 右の列（1行） | 項目の説明を1文で言い切る |
| 注記（例：） | 本文の下（小さく薄く） | 具体例を1行で添える |
| 細罫線 | 各行の下辺 | 行の区切り。帯や塗りで区切らない |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-numbered-row-full-widthのレイアウトで、[手順/サービス名]を4項目並べてください。各行は番号・見出し・本文1文・「例：」の順で書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 行数は3〜4行。本文は1行（34字以内）が基本。本文が2行になる行があるなら項目は3つまでにする（文字を小さくして詰めない）
- 各行の本文はできるだけ同程度の文字数にそろえると整然に見える
- 番号にバッジ・帯・矢印は付けない。順序を示すだけでよい
- 「今ここ」を示したい工程は、この行だけ番号と見出しをアクセント色にする程度にとどめる（行を塗らない）
