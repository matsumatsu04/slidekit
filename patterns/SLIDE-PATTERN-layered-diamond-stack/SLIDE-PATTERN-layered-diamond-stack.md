# SLIDE-PATTERN-layered-diamond-stack

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** layered-diamond-stack
**概要：** スライドを左右で地色分けし、左半分（薄グレー地）にテキストブロック3つ（小見出し＋本文、小見出し＋式の行、小見出し＋番号リスト）を縦積みする。右半分（白地）は横長のダイヤ（菱形）5枚を上=濃→下=淡の濃淡で少しずつ重ねて積層し、各ダイヤの右横にラベル、積層の左に「具体⇔抽象」の軸（丸バッジ＋細い縦線）を置く。右下に出典風キャプション1行。
**適したシーン：** 概念モデル・レイヤー構造の解説、フレームワーク紹介、抽象度の階層を見せる説明。

## Structure（構造）
- 左半分（幅約48%・薄グレー地・全高）: テキストブロック3つ縦積み（上下中央・均等間隔）
  1. 小見出し＋本文2〜3行（一部強調スパン可）
  2. 小見出し＋式の行（グレーピル＋「＋」＋グレーピル＋「＝」＋アクセント地×白字ピル）
  3. 小見出し＋番号リスト2項
- 右半分（白地）
  - 上部中央にタイトル
  - 中央にダイヤ5枚の縦積層（上=濃→下=淡の5段階濃淡。少しずつ重なる。各ダイヤの右横にラベル）
  - 積層の左に軸（上端バッジ・下端バッジ＋間の細い縦線。線はバッジ間だけを結ぶ）
  - 右下に出典風キャプション1行

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| テキストブロック × 3 | 左半分 | 図解の前提・関係式・補足の説明 |
| 式の行 | 左半分の2ブロック目 | 「A＋B＝C」の関係をピルで示す（結果ピルのみアクセント） |
| ダイヤ積層 × 5 | 右半分中央 | 概念のレイヤー構造。上ほど濃く重要度・抽象度の軸に対応 |
| レイヤーラベル × 5 | 各ダイヤの右横 | 各層の名前（ダイヤの上に文字を載せない） |
| 軸バッジ＋縦線 | 積層の左 | 上下方向の意味（具体⇔抽象など）を示す |
| キャプション | 右下 | 出典・参考モデルの注記 |

## Usage Guide（AIへの使い方）
- ダイヤの重なりの上に文字を置かない（ラベルは必ず右横の外側）
- 層の数は5枚基準（4〜5枚）。減らす場合も濃→淡の順は保つ
- 軸の縦線は上下バッジの間だけを結ぶ（積層の全高に伸ばさない・バッジとの間に隙間を作らない）
- 左のアクセントピルと本文の強調スパンで、アクセントの使用は合計1〜2箇所に抑える
- 台形の積層（三角形）でよければ pyramid-tier-callout を検討する。本パターンは「ダイヤの重なり＋左右の地色分け＋説明3ブロック」が特徴
