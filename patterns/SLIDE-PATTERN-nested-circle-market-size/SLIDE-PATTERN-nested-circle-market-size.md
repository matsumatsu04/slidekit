# SLIDE-PATTERN-nested-circle-market-size

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** nested-circle-market-size
**概要：** 左に大・中・小の円を中心のx座標をそろえ、下端（底辺）を一致させて重ねた市場規模図を置く。最外の円（TAM）は白地に1.5pxの罫線枠、中間（SAM）は淡い地（`--sk-soft`）、最内（SOM）だけアクセント塗り・白文字にする（塗りは1枚に1つ）。各円の帯の中心に英字ラベル（`TAM` / `SAM` / `SOM`）を置く。右に引き出しラベル3組（KICKER `TAM ／ 市場全体` → 数値24px/700 → 説明16px）を等間隔（線の高さ 40 / 160 / 280）に並べ、各ラベルの高さで円周と交わる点から水平の引き出し線（1px・罫線色）を引く。
**適したシーン：** 市場規模（TAM/SAM/SOM相当）の説明、対象範囲の絞り込みの提示、全体と部分集合の規模比較

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 最外の円（TAM） | ステージ左・最背面 | 最も広い範囲（市場全体）。白地に1.5pxの罫線枠 |
| 中間の円（SAM） | 最外の内側・下端ぞろえ | 絞り込んだ範囲（獲得可能な市場）。淡い地 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-nested-circle-market-sizeのレイアウトで、TAM「[市場全体]」・SAM「[獲得可能な市場]」・SOM「[自社の獲得目標]」に、それぞれの概算金額と1行の説明を入れてください。塗りは SOM だけにしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 円は3つ固定（大・中・小）。4段階以上に分けたい場合はこのパターンでは表現しない
- 円の面積比は視覚的な演出で、統計比率どおりではない。注記に「概算」「目安」と書く
- 数値は「約1,200億円」のように丸めた概数で書く（桁の多い実数を並べない）。説明は1行（20文字以内）
- 塗りは SOM の1つだけ。TAM・SAM を濃淡で塗り分けない（旧版の「大→小で徐々に濃くする」は廃止）
- 引き出し線は水平1本のみ。斜め線・矢印・点は付けない。線はラベルの高さで円周に当たる点から始める
