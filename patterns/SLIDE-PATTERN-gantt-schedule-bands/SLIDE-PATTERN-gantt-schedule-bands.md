# SLIDE-PATTERN-gantt-schedule-bands

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** gantt-schedule-bands
**概要：** 制作工程のスケジュールを示すシンプルなガント。上に目盛り行（`W1`〜`W8` の KICKER・accent2）、左に工程名の列（幅160px・16px太字・5行）、各行に高さ16pxの横帯を置く。帯は `--sk-soft` 地で、「今の工程」1本だけアクセント塗り。縦の目盛り線（1px・`--sk-line`）と横罫線（行の区切り）で表を組み、承認・公開などの節目は SVG のダイヤ（12px・1.5pxのアクセント枠・白地）で示す。罫線・帯・ダイヤは幅864×高さ316の SVG 1枚に座標計算で描き、文字（目盛り・工程名・注記）は HTML で重ねる。
**適したシーン：** Web制作の提案・納品資料での制作スケジュール提示、プロジェクト工程表、納期の合意形成

## Structure（構造）

コンテンツエリア（左右48px＝幅864px）の上下中央に「チャート（864×316）→ 注記」を縦に積む。チャートは工程名列160px＋8列×88px、目盛り行32px＋工程5行×56px のグリッドで、帯の x・幅は「160＋88×開始列」「88×列数」で求める。

    structure:
      layout: gantt-grid
      content_area:
        side_margin: 48px
        vertical_align: center             # 見出しON時は上76px以降の上下中央
      chart:
        size: 864 × 316
        columns: [name 160px, 8 × 88px]     # W1〜W8
        rows: [scale 32px, 5 × 56px]        # 工程は4〜6行
        svg (1枚):
          rules_h: y = 32 + 56n              # 目盛り行の下と各行の下（1px / var(--sk-line)）
          rules_v: x = 160 + 88k             # 列の境界（k=0..8・目盛り行の下から最終行の下まで）
          bands:
            height: 16px                     # 行の中心（行の上端+20）
            x: 160 + 88 × start_col          # 始点・終点は列の境界にそろえる
            width: 88 × span
            surface: soft
            now: accent fill                 # 今の工程1本だけ塗り
          milestones:
            shape: diamond 12px              # 1.5px アクセント枠・白地
            position: 帯の終点 or 列の起点

          milestone_labels: 11.5px / muted   # ダイヤの右8px

        style: "例：〜"                      # 11.5px / muted

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 目盛り行 | 最上段・8列 | `W1`〜`W8` の KICKER（accent2）。週／月など全列で書式をそろえる |
| 工程名 | 各行左端（160px・16px太字） | 要件定義／デザイン／実装／テスト／公開などの工程 |
| 横帯 | 各行の中心（高さ16px） | 工程の期間。始点・終点は列の境界にそろえる。1行に1本 |
| 塗りの帯 | 5行のうち1本 | 今の工程（今ここ）。1枚に塗りは1つだけ |
| ダイヤ | 帯の終点や列の起点（12px） | 承認・公開などの節目。右に11.5pxの注記を添える |
| 縦の目盛り線 | 列の境界（1px） | 期間の区切り。目盛り行の下から最終行の下まで |
| 横罫線 | 目盛り行の下・各行の下（1px） | 行の区切り |
| 注記 | チャートの下 | 「例：〜」で塗りとダイヤの意味を1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-gantt-schedule-bands のレイアウトで、[要件定義／デザイン／実装／テスト／公開] の5工程を、[8週間] の目盛りでスケジュール表にしてください。各工程の期間は [W◯〜W◯] で、今の工程は [実装] です。節目（承認・公開日）にはダイヤを置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 工程は4〜6行、目盛りは8列まで。それ以上細かい場合は工程を統合する（詳細WBSはこのスライドの役割ではない）
- 帯は1行に1本・始点と終点は列の境界にそろえる（0.5週などの中途半端な位置にしない）。帯の x・幅は「160＋88×開始列」「88×列数」で計算する
- 塗りは今の工程1本だけ。他の帯は淡い地。強調したい工程が無ければ最初の工程を塗る
- ダイヤは2つまで（承認・公開など）。依存矢印・分割帯は使わない（崩れる原因になる）
- 行数を変えるときは SVG の高さ（32＋56×行数＋4）と横罫線・縦線の y も一緒に直す
