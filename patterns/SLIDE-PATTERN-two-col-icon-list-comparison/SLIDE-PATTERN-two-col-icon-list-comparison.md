# SLIDE-PATTERN-two-col-icon-list-comparison

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** two-col-icon-list-comparison
**概要：** 左＝現状（塗りなし）、右＝導入後（淡い地・角丸11px）の等高2列に、アイコン付きの項目3つを縦に並べる比較レイアウト。各列は「KICKER／列見出し18px／細罫線／アイコン24px円＋本文16px×3／注記」の同じ型で組み、左右の間に SVG の三角矢印（幅12px）を置いて「現状 → 導入後」の向きを示す。塗りは右列の淡い地1つだけ。
**適したシーン：** 原因と対策の比較、現状と施策の対応、AとBの観点比較など、2つの観点からそれぞれ複数の要素を並べて示したいスライド。

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、等幅・等高（280px）の列2本を置き、間の40px幅の列に三角矢印を置く。左列は塗りなし（本文は左余白48pxから始まる）、右列だけ淡い地・角丸11pxで囲む。中身は左右とも同じ型で上ぞろえ。

    structure:
      layout: two-equal-columns
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        height: 280px               # 2列は等高。中身は上ぞろえ
      column_common:
        elements:
          - kicker: "英字ラベル ／ 補足"   # 10px / 700 / .18em（例: BEFORE ／ 現状）
          - heading                        # 18px / 700
          - rule                           # 1px var(--sk-line)
          - items:                         # アイコン（24pxの丸地＋14pxの線画SVG・グレー）＋本文16px。縦に12px間隔
              count: 3
          - note: "例：〜"                 # 11.5px / muted。列の下端に寄せる
      left:
        surface: none                      # 塗りなし。padding "24px 28px 24px 0"
        icon_ground: soft                  # アイコンの丸地は淡い地
      connector:
        width: 40px
        shape: svg-triangle                # 幅12px・アクセント色
      right:
        surface: soft                      # 淡い地・角丸11px（1枚で塗るのはここだけ）
        padding: "24px 28px"
        icon_ground: white                 # 淡い地の上なので丸地は白

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各列左上 | `BEFORE ／ 現状`・`AFTER ／ 導入後` のように英字＋日本語補足。アクセント色 |
| 列見出し | KICKER の下 | その側の要点を1文で（12文字前後・18px・700） |
| 細罫線 | 見出しの下 | 見出しと項目の区切り（`--sk-line`） |
| アイコン | 各項目の左 | 24pxの丸地（左＝淡い地／右＝白）に14pxの線画SVG。グレーで主張させない。SVGが無ければ ● でよい |
| 本文 | アイコンの右 | 項目の説明を1行（16px・18字以内） |
| 注記 | 列の最下 | 「例：〜」で数字・条件を1行添える（11.5px） |
| 三角矢印 | 中央 | 左から右への変化（SVG・幅12px・アクセント色） |
| 淡い地 | 右列 | 推す側・後の状態。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-two-col-icon-list-comparisonのレイアウトで、左に[現状]・右に[導入後]をアイコン付きの項目3つずつで比較してください。各列は KICKER・列見出し・項目3つ（1行ずつ）・「例：〜」の順で書き、右列を推す側として淡い地にしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは右列の淡い地1つだけ。左列に枠や地を付けない。アクセント塗りは使わない（矢印とKICKERの色だけ）
- 左右の項目数は揃える（3つ基本・最大4つ）。1項目は1行（18字以内）に収め、入らなければ文言を削る（文字を小さくしない）
- アイコンは左右で同じ絵柄を同じ順に使う（同じ観点の前後だと伝わる）。Font Awesome 等の外部CSSは読み込まない
- 対等な対比（推す側が無い）なら右列の地も外してよい。塗りパネルの対比は two-column-split-boxes を使う
