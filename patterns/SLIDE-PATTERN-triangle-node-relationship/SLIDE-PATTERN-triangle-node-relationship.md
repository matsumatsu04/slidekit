このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** triangle-node-relationship
**概要：** 左に3者の三角関係図、右に3者の説明を置く2カラム構成。関係図は円ノード3つ（直径80px・1.5pxの罫線色の枠・中に英字KICKER＋名前16px/700）を三角形の頂点（上1・下2）に置き、1pxの罫線色の直線3本で結ぶ。頂点の1つ（主役）だけアクセント塗り・白文字にする（塗りは1枚に1つ）。各辺の中点に関係ラベル（11.5px・muted）を置き、線はラベルの両側で止める（線を2本に分ける。白い矩形で消さない）。右は3者の説明（KICKER→1行16px）を罫線で区切って縦に積み、末尾に「例：」の注記。
**適したシーン：** 3者・3要素間の相互関係の説明、三位一体の構造、3つの立場・視点のバランスの提示

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 上ノード（主役） | 三角形の頂点（上） | 関係の中心に置く立場。アクセント塗り・白文字（1枚で塗るのはここだけ） |
| 左下ノード・右下ノード | 三角形の頂点（下2つ） | 残り2つの立場。白地・1.5px罫線枠 |
| KICKER／名前 | 各円の中 | 英字ラベル（`USER` など）＋名前（16px・700・3文字前後） |
| 接続線（3辺） | ノードの間 | 3者が互いに関係し合うことを示す。1px罫線色・端点は円の縁 |
| 関係ラベル | 各辺の中点 | その2者の間で何が行き来するか（11.5px・muted・5文字前後）。線はラベルの両側で止まる |
| 説明の行 | 右カラム・3行 | KICKER（`USER ／ 利用者`）＋1行の説明（16px）。罫線で区切る |
| 注記 | 右カラム末尾 | 「例：」で3者の関係が崩れたときの帰結などを1行 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-triangle-node-relationshipのレイアウトで、上ノード（主役）に「[要素A]」、左下に「[要素B]」、右下に「[要素C]」、各辺に[2者の関係を表す語]、右の説明に3者それぞれの1行説明を入れてください。塗りは上ノードだけにしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- ノードは3つ固定。4つ以上を扱いたい場合はこのパターンでは表現せず、カード（four-card-2x2）や表（comparison-matrix-table）に置き換える
- 円の中の名前は3文字前後（直径80pxに収める）。長い名称は右の説明側に書く
- 関係ラベルは5文字前後。長いと線の切れ目より広がり、線に重なる
- 主役（塗り）は「誰を中心に考えるか」で決める。塗りが上位という意味ではないので、対等に見せたいときは説明の順序で補う
- 旧版にあった「三角形の中央の統合ラベル」は持たない。3者の交点に言いたいことがあるときは、右カラム末尾の注記か見出しのメッセージラインで書く
