# SLIDE-PATTERN-four-step-card-flow

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** four-step-card-flow
**概要：** 上にリード文（16px・1行）、中央にタイムライン（SVG 1枚：線1本＋ドット4つ・12px・1つ目だけアクセント塗り・他は1.5px枠）、下に4枚のカード（等幅204px・等高・1.5px枠・塗りなし）を置くフロー。カードの中身は「KICKER `STEP 01` → 見出し18px太字 → 細罫線 → 本文16px（2〜3行）」の型。ドットの x はカードの中心（102/322/542/762px）に固定座標で合わせ、線は1つ目のドット中心から4つ目のドット中心までだけ引く。
**適したシーン：** 商品開発・プロジェクト・業務フローなど4段階のプロセスを、リード文で前置きしてから示すスライド。各ステップに名前と2〜3行の説明を持たせたい手順説明

## Structure（構造）

コンテンツエリア（左右48px＝幅864px）の上下中央に「リード文 → タイムライン → カード列」を縦に積む。カードは grid（4列×204px・gap 16px）で幅を固定し、タイムラインの SVG（864×12）の座標をそれに合わせる。

    structure:
      layout: four-step-card-flow
      content_area:
        side_margin: 48px
        vertical_align: center          # 見出しON時は上76px以降の上下中央
      lead:
        font: 16px / 400 / 行間1.8      # 1行（50字以内）
      timeline:
        type: svg (864×12, 1枚)
        line: x=102→762, 1.5px, accent   # 1つ目のドット中心から4つ目のドット中心まで
        dots:
          x: [102, 322, 542, 762]        # 各カードの中心
          size: 12px
          first: accent fill             # 塗りは1つだけ
          others: 1.5px accent outline, white
        margin: "20px 0 16px"
      cards:
        columns: 4 × 204px
        gap: 16px
        height: 216px                    # 等高
        surface: white + 1.5px line border, radius 11px   # 塗りなし
        padding: "20px 16px"
        align: top
        card:
          - kicker: "STEP 01"            # 10px / 700 / .18em / accent
          - heading                      # 18px / 700（6字以内）
          - rule                         # 1px / var(--sk-line)
          - body                         # 16px / 400 / 行間1.8 / 2〜3行（27字以内）

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| リード文 | 最上段（16px・1行） | このフローの前提や進め方を1文で示す |
| タイムライン線 | リード文の下（SVG・1.5px） | 4ステップの時系列のつながり。1つ目と4つ目のドット中心の間だけ引く |
| ドット | 線上・各カードの中心（12px） | ステップの接続点。1つ目だけアクセント塗り（今ここ／起点）、他は1.5px枠 |
| KICKER | 各カード左上 | `STEP 01` のように番号を英字で示す |
| 見出し | KICKER の下（18px・700） | ステップ名（6字以内） |
| 細罫線 | 見出しの下 | 見出しと本文の切り替え |
| 本文 | 罫線の下（16px・2〜3行） | ステップでやることを1文で（27字以内） |
| カード枠 | 4枚とも | 1.5pxの罫線色の枠・塗りなし。カード同士は等幅・等高 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-four-step-card-flowのレイアウトで、[プロセス名]を4ステップで説明してください。リード文を1文（50字以内）、各カードはSTEP番号・ステップ名（6字以内）・本文1文（27字以内）で書いてください。1つ目のドットを塗ってください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- カードは4枚固定。3枚なら three-col-numbered-card、5枚以上は枚数を分ける
- 塗りは1つ目のドットだけ。カードは塗らない（「今ここ」を変えるときは塗るドットを移す）
- 本文は27字以内（カード幅204pxで3行）。入らなければ文言を短くする（文字を小さくしない）
- ドットの x とカードの中心は固定座標（102/322/542/762）で一致させてある。カード幅を変えるときは SVG の座標も一緒に直す
- 旧版の「点線囲みのリード文・26px太字の番号・箇条書き（›）・カード上のドット（白枠）」は廃止

## v2 での描き直し（2026-09-04）
- 旧実装（`.slide` ルートが無く body を960×540にしていた・全てインラインstyle）を、他のパターンと同じ骨格（`<div class="slide">` ルート＋ `sk-head` ブロック＋ `.content-area`）とクラス指定に揃えた
- 横線とドット4つを div の絶対配置＋白枠で重ねていたのをやめ、SVG 1枚（線は1つ目〜4つ目のドット中心まで・ドット12px・1つ目だけ塗り・他は1.5px枠）にして、カード幅を204px固定にしてドットの x をカード中心に一致させた
- カードの中身を「26px太字の番号＋12px見出し＋10px箇条書き」から「KICKER `STEP 01` → 見出し18px/700 → 細罫線 → 本文16px」の型に揃え、リード文を点線囲み11pxから素の16pxにした
