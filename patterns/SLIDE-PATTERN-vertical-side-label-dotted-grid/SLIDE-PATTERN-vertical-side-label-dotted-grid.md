# SLIDE-PATTERN-vertical-side-label-dotted-grid

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** vertical-side-label-dotted-grid
**概要：** 本文エリア内の左端10〜12%に濃色帯（右上・右下だけ大きい角丸）を敷き、英字ラベルを縦組み（writing-mode）・白抜き・字間広めで置く。残りの領域に点線ボーダーの角丸ボックスを3列×2行並べ、各ボックスは太字の項目名＋スラッシュ区切りの列挙（小さめ文字3〜4行）で構成する。
**適したシーン：** 提供内容・サポート範囲・対応領域など、項目数の多い一覧。箇条書きの羅列を上品なグリッドに整理したい場面。

## Structure（構造）
- 左端: 濃色帯（本文エリア内・幅10〜12%・右上と右下が大きい角丸・左辺はスライド左端に接する）
  - 帯の中に英字ラベルを縦組み（白抜き・字間広め・垂直中央）
- 残り: 点線ボーダーの角丸ボックス 3列×2行（等幅・等間隔）
  - 各ボックス: 太字項目名 → スラッシュ区切りの列挙（3〜4行）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 濃色帯 | 本文エリア左端 | セクション全体の英字ラベルを背負う縦帯 |
| 縦組み英字ラベル | 帯の中央 | このスライドのテーマを一語で示す飾り文字 |
| 角丸ボックス | 右側に3列×2行 | 一覧の1カテゴリ分の器（点線ボーダー） |
| 項目名 | 各ボックス上段 | カテゴリ名（太字） |
| スラッシュ列挙 | 項目名の下 | 具体項目を「A ／ B ／ C」形式で圧縮して列挙 |

## Usage Guide（AIへの使い方）
- 帯は見出し（sk-h）と重ならないよう本文エリア内に収める（スライド上端まで伸ばさない）
- 縦組みの英字ラベルは1単語（6〜10文字）にする。長い語は入れない
- ボックスは6個が基準（4〜6個。減る場合も列数は3のまま行を減らし、上下センタリングを保つ）
- 列挙は1ボックスあたり4〜6項目・3〜4行まで。あふれる場合はボックスを分ける
