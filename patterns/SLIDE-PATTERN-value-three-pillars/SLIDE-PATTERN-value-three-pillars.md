# SLIDE-PATTERN-value-three-pillars

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** value-three-pillars
**概要：** 価値の3本柱を、淡いティント地（`--sk-soft`）の等幅・等高カード3枚で横に並べる。各カードの中身は「PILLAR n ／ 補足（英字ラベル）→見出し（18px・太字）→細い罫線→本文2行→例：の注記」の型。中央の1枚だけアクセント色で塗り（白文字）、主役の柱にする。上に主張の1文は置かない（リード文はビルダーの `.sk-msg` に任せる）。
**適したシーン：** 会社紹介・採用資料のミッション/ビジョン/バリュー。サービスの3つの価値・約束・方針を並べて見せる場面。

## Structure（構造）

```yaml
layout: value-three-pillars
content_area:            # 左右余白48px・見出しON時は上76px以降。カード列は本文エリアの上下中央
  display: flex
  align-items: center

cards:
  count: 3               # 横並び・等幅・等高（高さ336px固定）・gap 16px
  each:
    background: var(--sk-soft)     # 中央の1枚だけ var(--sk-accent) 塗り＋白文字
    border-radius: 12px
    padding: 24px
    align: 上ぞろえ（中身は上から積み、下は空けてよい）
    kicker:  "PILLAR n ／ 補足"   # 10px / 700 / 字間 .18em / 大文字 / アクセント色（塗りカード内は白）
    heading: 見出し             # 18px / 700 / 行間 1.5 / 1行
    rule:    1px               # var(--sk-line)（塗りカード内は白35%）
    body:    本文 2行           # 16px / 400 / 行間 1.8
    note:    "例：〜"           # 11.5px / muted（塗りカード内は白85%）
```

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 各カード最上段 | `PILLAR 1 ／ 設計` のように番号と補足を英字＋短語で示す |
| 見出し | KICKER の下（18px・太字） | 柱を言い切りで書く（8〜10字・1行） |
| 細い罫線 | 見出しと本文の間 | 見出しと本文の切り替え。塗りカード内は白の半透明線 |
| 本文 | 罫線の下（2行） | 柱の中身を具体に書く（24〜26字） |
| 注記 | 本文の下（`例：`） | 具体例・数字の取り方を1行で |
| 塗りカード | 中央の1枚 | 主役の柱。左右は淡い地。1枚のスライドで塗りは1つ |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE-PATTERN-value-three-pillars を使ってスライドを1枚生成してください。

【スライドタイトル】私たちの3つの柱
【柱 1（左・淡い地）】KICKER: PILLAR 1 ／ 設計 / 見出し: 目的から逆算する / 本文: 誰に何をしてほしいかを先に決め、構成と導線を組む。 / 注記: 例：問い合わせまでの導線を1本に絞る
【柱 2（中央・塗り＝主役）】KICKER: PILLAR 2 ／ 制作 / 見出し: AIと人で分担する / 本文: 下書きと量産はAIに、判断と仕上げは人が受け持つ。 / 注記: 例：初稿は2日、仕上げに1日
【柱 3（右・淡い地）】KICKER: PILLAR 3 ／ 運用 / 見出し: 公開後も数字で直す / 本文: 反応を毎月見て、効いていない箇所から順に直す。 / 注記: 例：月1回の見直しで1箇所ずつ
```

### 注意点
- 見出しは1行（10字以内）、本文は2行（26字以内）。入らなければ文字を小さくせず、言い切りに削る
- 塗りは中央の1枚だけ。3枚とも塗らない・3枚とも淡い地にしない（主役の柱を中央に置く）
- ラベルは MISSION / VISION / VALUE のように柱の名前でもよい（`MISSION ／ 使命` の形）
- カードは等高。中身が少なくても高さを縮めない（下の空きは塗り面が吸収する）
- 2〜4本になる場合もカードは等幅・等高のまま横に並べる。5本以上は別パターンを検討する

## v2 での描き直し（2026-09-02）
- 「枠付きチップ＋21pxの文言」を3段に縦積みする構成を、淡い地（`--sk-soft`）の等幅・等高カード3枚横並びに描き直し、中央の1枚だけアクセント塗りにした（塗りは1枚に1つ）
- カードの中身を v2 の型（KICKER→見出し18px→細い罫線→本文2行→例：）にし、文字を 16px 基準・`palt`・インク色にそろえた
- 左右余白を110pxから48pxに、gap 16px・角丸12pxに合わせ、プレースホルダを型が伝わる具体例にした
