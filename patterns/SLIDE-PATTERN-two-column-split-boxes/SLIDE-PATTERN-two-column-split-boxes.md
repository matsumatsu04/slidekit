## Overview

**パターン名：** two-column-split-boxes
**概要：** 左＝淡い地、右＝アクセント塗り（白文字）の等高パネル2枚を横に並べ、中央に白丸のコネクタ（vs）を置く対比レイアウト。各パネルは「KICKER／見出し／細い罫線／本文3行／注記」の同じ型で組む。
**適したシーン：** 2つの選択肢・方式の対比、導入前後の比較、2つのターゲット・市場の対比、2つのメリット・特徴の並列説明

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、等幅・等高（280px）のパネル2枚を置き、間の48px幅の列に白丸のコネクタを置く。左パネルは淡い地、右パネルはアクセント塗り（白文字）で対比する（塗りは1枚に1つ）。パネルの中身は左右とも同じ型。

    structure:
      layout: two-equal-columns
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        height: 280px               # 2パネルは等高
      panel_common:
        border_radius: 12px
        padding: "24px 28px"
        elements:
          - kicker: "英字ラベル ／ 補足"   # 10px / 700 / .18em（右パネル内は白）
          - heading                        # 18px / 700
          - rule                           # 1px（右パネル内は白35%）
          - body: 3 lines                  # 16px / 400 / 行間1.8（1行20文字×3行以内）
          - note: "例：〜"                 # 11.5px / muted。パネル下端に寄せる
      left:
        surface: soft                      # 淡い地 + 1px 罫線
      connector:
        width: 48px
        shape: white-circle                # 40px・白地・1px 罫線色の枠
        label: "vs"                        # 14px / 700 / アクセント色（「→」「×」等に差し替え可）
      right:
        surface: accent_fill               # アクセント塗り・白文字（1枚で塗るのはここだけ）

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各パネル左上 | `OPTION A ／ 自社で更新` のように英字＋日本語補足。左はアクセント色、右（塗り）は白 |
| 見出し | KICKER の下 | その側の要点を1文で（12文字前後） |
| 細い罫線 | 見出しの下 | 見出しと本文の区切り（右パネル内は白35%） |
| 本文 | 罫線の下 | 詳細説明を3行以内（1行20文字） |
| 注記 | パネル最下 | 「例：〜」で数字・条件を1行添える |
| コネクタ | 中央 | 2要素の関係（vs=対比、→=変化）。白丸に細枠、文字はアクセント色 |
| 塗りパネル | 右 | 推す側・後の状態。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-two-column-split-boxesのレイアウトで、[左テーマ]と[右テーマ]を対比してください。右を推す側として塗り、各パネルは KICKER・見出し・本文3行以内・「例：〜」の順で書き、中央のコネクタは「vs」にしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは右パネルの1つだけ。左パネルやコネクタに別の塗りを足さない。推す側が無い（対等な）対比なら右も淡い地にしてよい
- 左右の本文は同じ行数（3行以内）に揃える。入らないときは文字を小さくせず、文言を短くする
- コネクタの文字は「vs」「→」「×」の1〜2文字。長い語は入れない
- 工程の箱やチップまで置きたい対比は before-after-two-col を使う（こちらは本文中心の対比）

## v2 での描き直し（2026-09-02）
