# SLIDE-PATTERN-sitemap-indent-list

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** sitemap-indent-list
**概要：** サイト構成（サイトマップ）を「字下げしたリスト」で表す。**第1階層はトップページだけ**（淡い地・角丸6pxの帯）。第2階層（サービス・会社概要・お問い合わせ等）を1段（32px）字下げ、第3階層をさらに1段（64px）字下げして縦に積む。各行は高さ40px固定で「階層KICKER（`L1`／`L2`／`L3`・幅40px）→ ページ名（16px）→ 右端の補足（11.5px・muted）」の型。行間は字下げ位置から引く1pxの細罫線。親子関係は、親の行の下端から子の最後の行の中心までの縦罫線（1px・親のKICKERの文字の下）で示す。ページ数が多いときは2列（左＝L1→L2、右＝下層を持つL2→L3の続き）に分ける。
**適したシーン：** Web制作の提案・納品資料でのサイト構成説明、ページ構成の合意形成、見積の前提となるページ一覧の提示

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、2列（gap 48px・上ぞろえ）のリストと、その下に「例：」の注記を置く。行は高さ40px固定なので、縦罫線の位置は行番号から決まる（親の下端 = 行番号×40、子の最後の行の中心 = 行番号×40＋20）。

    structure:
      layout: indented-list (2 columns)
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      columns: 2 (gap 48px, top-aligned)
        left:  L1 (1 row) → L2 (3-6 rows)
        right: L2 (下層を持つページ) → L3 (2-4 rows) を必要なだけ繰り返す
      row:
        height: 40px                 # 固定
        indent: { L1: 0, L2: 32px, L3: 64px }
        elements: [kicker "L1|L2|L3" (width 40px), page-name 16px, supplement 11.5px muted (right)]
        divider: 1px var(--sk-line) at the bottom, starting at the indent
      top_row:
        fill: soft, border-radius 6px, name 700   # 塗り（淡い地）はこの行だけ
      guide:
        type: vertical 1px var(--sk-line)
        x: 親の字下げ + 18px（親KICKERの文字の下）
        from: 親の行の下端
        to: 子の最後の行の中心
      note: "例：〜"（11.5px muted・列の下）
      constraint: 1列あたり7行まで。超えるならスライドを分ける

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| トップ行（L1） | 左列の先頭・淡い地の帯 | サイトの入口。第1階層はこの1行だけ。ページ名は700 |
| 第2階層の行（L2） | 左列・トップの下に32px字下げ | サービス・会社概要・お問い合わせ等。右列では下層を持つページを再掲して展開の起点にする |
| 第3階層の行（L3） | 右列・L2の下に64px字下げ | 各L2の下層ページ |
| 階層KICKER | 各行の左・幅40px | `L1`／`L2`／`L3`。アクセント色。字下げと合わせて階層を二重に示す |
| 補足（右端） | 各行の右端 | ページ数・機能（「下層3ページ」「フォーム」）を11.5px muted で。不要な行は空欄 |
| 細罫線 | 各行の下 | 行の区切り。字下げ位置から引くので、罫線の始点でも階層が読める |
| 縦罫線 | 親KICKERの下 | 親の行の下端から子の最後の行の中心まで。斜め線・水平の枝線は付けない |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-sitemap-indent-list のレイアウトで、トップページの下に [ページ1]・[ページ2]・[ページ3]… を第2階層として並べ、下層があるページは右列で第3階層まで展開してください。各行に補足（ページ数・機能）を入れてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- **第1階層はトップページだけ。** サービス・会社概要を第1階層に並べない（階層＝ルートからの深さ）
- 1列7行まで（左＝L1＋L2 6行、右＝L2＋L3 で7行）。超える場合は行を統合するか、スライドを分ける
- 第3階層が無いサイトは左列だけ（1列）で組んでよい。その場合は列幅を全幅にせず、左右余白を均等にする
- ツリー図（箱と線）で描きたいときは sitemap-tree-3level を使う
- 縦罫線の長さは「親の下端 → 子の最後の行の中心」。行数を変えたら高さを行番号から計算し直す（行高40px）
- 補足は全行で書式を揃える（「下層nページ」「一覧＋詳細」など）

- 各行を「階層KICKER（L1/L2/L3・幅40px）＋ページ名16px＋右端の補足11.5px muted」の型に揃え、行間は字下げ位置から引く1pxの細罫線にした。塗りはトップ行の淡い地（角丸6px）だけ
- 親子関係は縦罫線（1px・親の行の下端から子の最後の行の中心まで）だけで示し、水平コネクタ・2px線・純黒文字をやめて左右余白48px・字間.06em・インク色に揃えた
