## Overview

**パターン名：** grouped-pill-badge-cluster
**概要：** 3つのグループを縦に積み、各グループは左に英字ラベル（KICKER・幅120px）、右にピル（タグ）を折り返して並べるレイアウト。ピルは14px・1.5pxの罫線色の枠線・角丸999pxで、全体で1つだけアクセント塗り・白文字にして主役を示す。グループの間は細い罫線で区切る。グループごとに項目数が違ってもよい。
**適したシーン：** スキル・キーワード・対応領域の列挙、対応範囲の提示、3カテゴリでの用語整理、募集要項の「必須／歓迎」条件の提示

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、グループ3つを縦に積む。各グループは「左：KICKER（幅120px・ピル1行目の縦中央に合わせる）／右：ピルの折り返し（gap 8px）」の横並びで、グループ間に1pxの罫線と上下20pxの余白を置く。束の下に注記1行。

      content_area:
        padding: "24px 48px"

        count: 3                    # 縦積み。間は 1px var(--sk-line) ＋ 上下20px
        group:
          kicker:
            width: 120px            # "DESIGN ／ 設計" 10px / 700 / .18em。上11px でピル1行目の中央に合わせる

            type: flex-wrap

**注意点：**
- ピルの文字は短く（8字以内）。長い文は折り返しが崩れる
- 塗りは全体で1つまで。主役が無ければ塗らない。グループごとに1つずつ塗らない
- 1グループの推奨個数は4〜8個。2行を超えるグループがあるときは column-stacked-tag-list（列型）へ切り替える
- グループは3つ基本（2〜4）。5つ以上は枚数を分ける
- KICKER の幅120pxに収まる語にする（英字7文字＋日本語2文字が目安）
