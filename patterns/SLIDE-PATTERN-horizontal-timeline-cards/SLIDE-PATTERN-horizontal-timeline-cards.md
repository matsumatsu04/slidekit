# SLIDE-PATTERN-horizontal-timeline-cards

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** horizontal-timeline-cards
**概要：** 淡い地のステップカード（KICKER「STEP 1」・見出し・細い罫線・2行の説明・注記）を SVG の三角矢印でつなぐ横並びの工程レイアウト。「今ここ」の1枚だけアクセント塗り、最後の1枚だけ 1.5px のアクセント枠線。
**適したシーン：** プロセスの4ステップ説明、時系列の流れを示す説明、段階的な導入手順の説明

## Structure（構造）

コンテンツエリアの上下中央に、等幅・等高のステップカード4枚を横一列に置き、カードの間を SVG の三角矢印（幅12px）でつなぐ。カードの中身は v2 の型（KICKER／見出し／細い罫線／本文2行／注記）で揃える。

    structure:
      layout: timeline-cards
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        gap: 8px                    # カードと矢印の間
        align_items: stretch        # 4枚は等高
      cards:
        count: 4
        layout: horizontal-equal-width
        border_radius: 12px
        padding: "20px 16px"
        card:
          elements:
            - kicker: "STEP n ／ 補足"      # 10px / 700 / .18em。塗りカード内は白
            - heading                        # 18px / 700
            - rule                           # 1px（塗りカード内は白35%）
            - body: 2 lines                  # 16px / 400 / 行間1.8（1行9文字以内）
            - note: "例：〜"                 # 11.5px / muted。カード下端に寄せる
        surfaces:
          default: soft                      # 淡い地 + 1px 罫線
          current: accent_fill               # 「今ここ」の1枚だけ塗り（白文字）
          last: outline                      # 最終工程は塗らず 1.5px のアクセント枠線
      arrows:
        type: svg-triangle
        width: 12px
        color: accent

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各カード左上 | `STEP 1`〜`STEP 4`。補足を添えるときは `STEP 3 ／ 今ここ` の形 |
| 見出し | KICKER の下 | そのステップの主内容（2〜4文字の体言） |
| 細い罫線 | 見出しの下 | 見出しと本文の区切り（塗りカード内は白35%） |
| 本文 | 罫線の下 | ステップの説明を2行（1行9文字以内・改行位置を指定） |
| 注記 | カード最下 | 「例：〜」で目安を1行添える |
| 三角矢印 | カードの間 | 左から右への流れ（SVG・幅12px・アクセント色） |
| 塗りカード | 4枚のうち1枚 | 「今ここ」「主役」の工程を示す。1枚に1つだけ |
| 枠線カード | 最後の1枚 | 「運用」「公開」など最終・結果の工程を別扱いにする |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-horizontal-timeline-cardsのレイアウトで、4ステップの導入手順（試作→限定導入→確認必須→運用）を説明してください。STEP 3 を「今ここ」として塗り、STEP 4 は最終工程として枠線にしてください。各カードの本文は2行（1行9文字以内）、注記に「例：〜」を1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは1枚だけ。「今ここ」が無い工程説明なら、主役の1枚（要になる工程）を塗る
- 最後の1枚は塗らず枠線。最終工程が無い（途中で終わる）場合は既定の淡い地でよい
- 本文は1行9文字以内×2行。入らなければ文言を短くする（文字を小さくしない）
- 4ステップ固定。3ステップは three-step 系のパターン、5ステップ以上は枚数を分ける
- 旧版の「上部タイムライン（点線＋ドット）」は廃止。カード間の三角矢印だけで流れを示す

## v2 での描き直し（2026-09-02）
- 上部の点線タイムライン＋ドット＋大きな番号を廃し、カード間の SVG 三角矢印（幅12px）だけで流れを示すようにした
- カードを淡い地（soft）に変え、「今ここ」の1枚だけアクセント塗り・最後の1枚だけ 1.5px 枠線の3種にした（塗りは1枚に1つ）
- カードの中身を「KICKER／見出し18px／細い罫線／本文16px×2行／注記11.5px」の型に揃え、箇条書きをやめた
