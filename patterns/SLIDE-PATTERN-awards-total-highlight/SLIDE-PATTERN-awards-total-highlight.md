# SLIDE-PATTERN-awards-total-highlight

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** awards-total-highlight
**概要：** 非対称の3ゾーン。左40%に主要実績リスト4行（左に正方形アイコン枠・右に実績名太字＋年・対象の小文字2列）、中央30%に小見出し＋文字バッジのクラスタ3×3（角丸チップ）、右30%に薄グレー地の縦長カード（メダル風アイコン＋TOTALラベル＋特大数値）を置く。
**適したシーン：** 受賞・認定・掲載・登録などの安心材料。「主要は詳しく・残りはまとめて・合計は数字で」の三層で信頼を積み上げる場面。

## Structure（構造）
- 左ゾーン（40%・右辺に細罫）: 主要実績リスト4行
  - 各行: 正方形アイコン枠 → 実績名（太字）＋年・対象の2列小文字。行間に細罫
- 中央ゾーン（30%）: 小見出し → 文字バッジ3×3グリッド（角丸チップ・短い英字）
- 右ゾーン（30%）: 薄グレー地の縦長カード
  - 上からメダル風アイコン → TOTALラベル → 特大数値 → 補足キャプション（すべて中央揃え）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| アイコン枠 | 左ゾーン各行の左 | 実績の種類（受賞・認定・掲載）を示す正方形枠 |
| 実績名 | アイコン枠の右 | 主要実績の名称（太字） |
| 年・対象 | 実績名の下 | 取得年と対象・部門を並べる小文字2列 |
| 小見出し | 中央ゾーン上端 | バッジ群のくくりを示す1行 |
| 文字バッジ | 中央ゾーン3×3 | その他の実績を短い文字チップで圧縮列挙 |
| 縦長カード | 右ゾーン全高 | 合計数を主役にする薄グレー地の面 |
| 特大数値 | カード中央 | 実績の合計件数（45+ など） |

## Usage Guide（AIへの使い方）
- 主要実績は4行が基準（3〜5行）。実績名は1行に収める
- バッジは3×3が基準（6〜9個）。1バッジは英字なら10文字前後、和文なら6文字前後まで
- 特大数値は1個だけ。カード内に数値を2つ以上置かない
- 実在の賞・認定名を入れる場合は事実確認を済ませてから使う（ダミーのまま公開しない）
