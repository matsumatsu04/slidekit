**概要：** 縦3行のリスト。各行は左に番号の丸（48px・1.5pxのアクセント枠・01/02/03）、右に見出し（18px・太字）と本文（16px・2行）を置く。行の区切りは横1pxの罫線だけで、行全体の塗り・枠・アイコンは置かない。番号の丸は主役の1つだけアクセント塗り（白文字）にする。

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-icon-left-text-list-detailedのレイアウトで、[テーマ]の3つの[特長/提供内容]を並べてください。各行は見出し1行（15字前後）と本文2行（60字前後）で書き、主役にする項目の番号を塗ってください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは番号の丸1つだけ。行全体を塗ったり枠で囲んだりしない（行の区切りは横罫線）
- 本文は2行（60字前後）。3行以上になるなら文言を削るか、枚数を分ける（文字を小さくしない）
- アイコン（Font Awesome 等）は使わない。左の丸には番号だけを入れる
- 項目は3つが基準。4つ以上は行が薄くなるので two-col 系や card 系のパターンを検討する
