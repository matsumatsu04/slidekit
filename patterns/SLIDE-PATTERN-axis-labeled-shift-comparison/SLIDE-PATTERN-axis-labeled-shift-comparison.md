# SLIDE-PATTERN-axis-labeled-shift-comparison

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** axis-labeled-shift-comparison
**概要：** 左に「従来（BEFORE）」パネル（塗りなし・罫線のみ）、右に「これから（AFTER）」パネル（淡いアクセント地）を等幅・等高で並べ、中央にSVGの三角矢印を置く新旧対比レイアウト。各パネルは同じ3つの軸（KICKER。速さ・費用・担当など）で行対応し、行の高さを揃えて左右を見比べられるようにする。
**適したシーン：** 方針転換・サービス刷新のビフォーアフター、旧手法と新手法を同じ観点で比べる構造比較

## Structure（構造）

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| パネルKICKER | 各パネル左上 | `BEFORE ／ 従来` のように英字＋日本語補足 |
| 見出し | パネルKICKERの下 | その側の運用・状態を1文で（12〜16文字前後） |
| 細い罫線 | 見出しの下 | 見出しと軸の行の区切り |
| 軸KICKER | 各行の先頭 | `SPEED ／ 更新の速さ` のように観点を英字＋日本語で。左右パネルで同じ観点・同じ高さに揃える |
| 本文 | 軸KICKERの下 | その観点での状態を1〜2行で |
| 中央の矢印 | パネルの間 | 従来→これからへの転換を示す。三角矢印はSVG12px |
| 塗りパネル | 右 | これから側。1枚のスライドで塗り（淡いティント）はここだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-axis-labeled-shift-comparisonのレイアウトで、[従来の運用]と[これからの運用]を対比してください。3つの軸（[観点1][観点2][観点3]）を左右で揃え、右パネルだけ淡い地にして、中央に矢印を置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは右パネルの淡い地だけ。左パネルは塗りなし（1px罫線のみ）にする。濃いアクセント塗りはどちらにも使わない
- 軸は**3つ固定**（行の高さ96px×3で構成）。増減する場合は行の高さを再設計する
- 左右の軸KICKERは同じ観点・同じ順番にする（行がずれると対比として読めなくなる）
- 本文は1〜2行に収める（1行20文字前後）。入らないときは文字を小さくせず、文言を短くする
- 矢印の中に文字は入れない（転換の意味は見出しと軸の内容で示す）

## v2 での描き直し（2026-09-02）
- 左端の丸形軸バッジ列＋各パネル内の白カード3枚（グリッドで行対応）という二重構造を、パネル自体が「KICKER→見出し→細罫線→軸の行×3」を持つ1枚構成に整理した（白カードを廃止し、行は罫線区切りのみ）
- パネル上部のピル型ラベルを、パネルKICKER（10px・英字＋日本語）に置き換えた。中央の右向き矢印はSVGの三角矢印（幅12px）に統一した
- 左パネルを「塗りなし・1px罫線」、右パネルを `var(--sk-soft)` の淡い地に変更し、塗りを1枚のスライドで右パネルだけに限定した（濃いグレー地・淡アクセント地の二重塗りを廃止）
