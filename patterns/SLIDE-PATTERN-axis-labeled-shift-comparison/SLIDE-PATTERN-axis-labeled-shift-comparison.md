# SLIDE-PATTERN-axis-labeled-shift-comparison

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** axis-labeled-shift-comparison
**概要：** 左端に丸形の軸ラベル（比較の観点）を3つ縦に並べ、その右に旧方式（グレー地）と新方式（淡アクセント地）の大パネル2枚を置く。各パネル内の白カード3枚は行ごとに対応し、軸ラベルと水平位置が揃う（3行の対比表をカードで表現）。パネル間は右向き矢印。
**適したシーン：** 方針転換・サービス刷新のビフォーアフター、旧手法と新手法を同じ観点で比べる構造比較。

## Structure（構造）
- 左端: 軸ラベル列（丸バッジ × 3、縦に等間隔。各バッジに2〜4字の観点ラベル）
- 中央〜右: 大パネル2枚（左=旧方式・薄グレー地、右=新方式・ごく薄いアクセント地。角丸12px）
  - 各パネル上部中央にピル型ラベル（パネル上辺に少し食い込む。左=中間グレー地×白字、右=アクセント地×白字）
  - 各パネル内に白カード3枚が縦積み（角丸8px・1行テキスト中央揃え）
  - 左右のカードは行ごとに対応し、左端の軸バッジと水平位置が揃う（グリッドで行を共有）
- パネルの間: 右向き矢印（アクセント色）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 軸バッジ × 3 | 左端の列 | 比較の観点（行の見出し）。カードの行と水平に揃う |
| 旧方式パネル | 中央 | グレー地で「これまで」を示す枠 |
| 新方式パネル | 右 | 淡アクセント地で「これから」を示す枠 |
| ピル型ラベル × 2 | 各パネル上辺 | パネルの名前（従来の◯◯／新しい◯◯） |
| 白カード × 6 | 各パネル内に3枚ずつ | 観点ごとの内容。左右で行対応 |
| 右向き矢印 | パネルの間 | 旧→新への転換を示す |

## Usage Guide（AIへの使い方）
- 軸バッジのラベルは2〜4字の短い観点語にする（起点・対象・要素 など）
- 左右のカードは必ず同じ行数（3行基準・2〜4行）にし、行ごとに同じ観点を書く
- アクセント色の強調スパンは右パネルのカード内 1〜2箇所まで。左（旧）側には使わない
- 上部のメッセージはメッセージライン（sk-msg）と併用するとよい（パターン自体に大見出しは持たない）
- 似た構図に ok-ng-comparison（2パネル対比）があるが、こちらは「行の観点を軸ラベルで共有する対比表」が本質
