# SLIDE-PATTERN-testimonial-quote-grid

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** testimonial-quote-grid
**概要：** 受講生・お客様の声を2行×2列＝4枚の等高カードで並べるレイアウト。各カードは「引用符（装飾）→引用文2〜3行→細罫線→英字ラベル＋名前」の型で、1枚だけ塗りで主役にする
**適したシーン：** 導入事例・受講生の声の一覧提示、複数の推薦コメントをまとめて見せたい場面、信頼性訴求のセクション

## Structure（構造）

コンテンツエリア（左右余白48px）を2行×2列＝4枚の等高カード（gap 16px・角丸11px・淡い地）に分割する。各カードは左ぞろえ・上ぞろえに「引用符（装飾。罫線色・本文に重ねない上段）」「引用文（16px・2〜3行）」「細い罫線」「英字ラベル（`VOICE ／ 立場`）」「名前（16px・太字）」の順で組む。引用文の余りは罫線の上に吸収し、出典は4枚とも下端でそろう。4枚のうち1枚を塗りカード（白文字）にして主役を示す。写真・顔アイコンは置かない。カード群は本文エリアの上下中央に置く。

    structure:
      layout: two-column-two-row-grid
      cards:
        columns: 2
        rows: 2
        equal_height: true
        gap: 16
        ground: soft (no border, no shadow)
        emphasis: one filled card (1 of 4)
      card:
        order:
          - quote-mark (decoration, line color, top row only)
          - quote-text (16px, 2-3 lines, top-aligned, grows)
          - rule (1px, line color)
          - kicker (VOICE ／ 立場)
          - name (16px, bold)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 引用符 | 各カード上段（高さ24pxの行） | 「これは声である」ことを示す装飾。罫線色で薄く置き、本文に重ねない。塗りカード内は白の半透明 |
| 引用文 | 引用符の下（2〜3行） | 変化・感想を語る本人の言葉。要約せず短く切る（44字以内で2行、60字以内で3行） |
| 細罫線 | 引用文と出典の間 | 本文と発言者を区切る。塗りカード内は `rgba(255,255,255,.35)` |
| 英字ラベル（KICKER） | 罫線の下 | `Voice ／ 受講生`・`Voice ／ お客様` のように立場を示す |
| 名前 | ラベルの下（太字） | 発言者。実名を出さないときは「受講生Aさん（属性）」の形にする |
| 塗りカード | 4枚のうち1枚 | 主役の声。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-testimonial-quote-gridのレイアウトで、[受講生・お客様]の声4件を2行×2列のカードに並べてください。各カードは引用文（2〜3行）・英字ラベル（`Voice ／ 立場`）・名前の順で書き、主役にする声を1つ指定してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 引用文は2〜3行（60字以内）。長い声は要約せず、いちばん効いた一文を切り出す
- 名前・社名・数字は本人の許諾を確認したものだけ載せる。未確認なら「受講生Aさん」の形で属性だけ書く
- 塗りは1枚だけ。すべてを同じ扱いにしたいときは塗りを外し、4枚とも淡い地にしてよい
- 4件固定のパターン。1件を大きく見せるなら引用を主役にした本文パターンへ、6件以上は枚数を分ける（文字を小さくして詰めない）
- 引用符は装飾。本文と同じ色にしたり大きくしたりして読ませない
