# SLIDE-PATTERN-section-tag-progress

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い）。

## Overview
**パターン名：** section-tag-progress
**概要：** 上部に全章のタグを横一列に並べる（`--sk-soft` 地の小さなピル・英字ラベル型。現在の章だけアクセント塗り＋白文字）。左の上下中央に「章番号（40px・400・アクセント色）→ 章タイトル（28px・700）→ 説明1行」を縦に積む。地は白、塗りは現在地タグの1つだけ。
**適したシーン：** 長尺デッキの章区切り。読み手に全体の中の現在地を示しながら章を切り替えたい場面。

## Structure（構造）
```yaml
layout: section-tag-progress
tags:                              # left/right 48px・top 48px・横一列・gap 8px・左ぞろえ
  tag: "01 現状"                    # 高さ 26px・角丸 13px・soft 地・10px / 700 / 字間 .18em / 大文字 / muted 色。内容幅
  current: "03 方針"                # アクセント塗り＋白文字（この1つだけ塗る）
block:                             # left/right 48px・全高の上下中央・左ぞろえ・縦積み
  number: "03"                     # 40px / 400 / 字間 .04em / アクセント色
  title:  章タイトル                # 28px / 700 / 字間 .06em / 行間 1.5 / インク色。max-width 760px・1〜2行。上に 16px
  sub:    説明1行                   # 16px / 400 / muted 色。上に 12px（省略可）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 章タグ列 | 上部・左ぞろえ | 全章を「番号＋短い章名」の小さなピルで並べ、現在の章だけ塗る。ナビなので主張させない（muted 色） |
| 章番号 | 左中央 | 40px の細字（400）・アクセント色。塗らずに色と大きさで現在地を示す |
| 章タイトル | 番号の下 | 章の内容を1〜2行で言い切る。標語調にしない |
| 説明 | タイトルの下 | この章で扱うことを1行で補う（省略可） |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-tag-progress を使って中扉を1枚生成してください。
【章タグ】01 現状／02 課題／03 方針／04 手順／05 体制（現在＝03）
【章番号】03
【章タイトル】AIに任せる工程と、人が決める工程
【説明】判断の主体を工程ごとに決めてから、道具を選ぶ
```
### 注意点
- 章数は4〜6個。タグの章名は2〜4文字に短縮する（7個以上や長い章名は一列に収まらない）
- current タグは章の進行に合わせて移動する。塗るのは current の1つだけ（他のタグは soft 地のまま）
- 章番号は塗り・囲みにしない。40px の細字とアクセント色で足りる
- 章タイトルは28pxで2行まで（1行あたり全角20文字程度）

## v2 での描き直し（2026-09-02）
- タグを「等幅に引き伸ばした11pxグレー文字」から、内容幅の小さなピル（soft 地・10px・字間.18em・muted 色、現在章だけアクセント塗り＋白文字）に変えた
- 章番号を「淡色の64px太字」から「40px・400・アクセント色」に、章タイトルを34pxから28px/700に落とし、説明を16px muted で1行に揃えた
- 文字の組みを v2 の表に合わせ（`palt`・`line-break:strict`・インク色・太さ400/700のみ）、左右余白を48pxに揃えた
