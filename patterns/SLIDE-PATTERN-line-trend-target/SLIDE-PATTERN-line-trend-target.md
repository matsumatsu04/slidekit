# SLIDE-PATTERN-line-trend-target

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** line-trend-target
**概要：** 左に折れ線グラフ（SVG 1枚・座標は静的計算）、右に説明を置く2カラム。折れ線は2pxのアクセント色、目標ラインは1pxの破線（muted）＋KICKER。途中の点は白地に1.5pxアクセント枠の8pxドット、終点だけ12pxのアクセント塗りドット＋数値（24px/700・tabular-nums）にして、「目標にどこまで迫ったか」を1点で示す。
**適したシーン：** 達成率・継続率・進捗などの推移報告。目標との距離感を1枚で伝えたい場面。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 軸線・目盛り値 | グラフの左・下 | 値の読み取り基準（1pxの罫線色＋KICKERの目盛り値） |
| 目標ライン | グラフ上部・水平 | 破線で「越えるべき水準」を示す。KICKERで目標値を添える |
| 折れ線 | グラフ中央 | 推移そのもの。2pxのアクセント色（線はアクセント色でよい） |
| 途中の点 | 折れ線上 | 各期の実績。白地＋アクセント枠で、終点より弱く見せる |
| 終点ドット＋数値 | 折れ線の右端 | 結論の1点。このスライドで唯一のアクセント塗り |
| 期ラベル | グラフ下部 | 月・四半期などの期（16px） |
| 説明（右カラム） | グラフの右 | KICKER → 見出し → 罫線 → 本文 → 例：注記 の型で、数字の意味を書く |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-line-trend-targetのレイアウトで、4月〜10月の達成率（52/58/61/67/72/78/82%）と目標90%の推移を描いてください。右の説明は KICKER: RESULT ／ 直近の到達点 / 見出し: 目標90%まで、残り8pt / 本文: 〜 / 注記: 例：達成率＝受注件数÷目標件数。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 点は6〜8個。`polyline` の座標と各 `circle` の座標は同じ値を使い、ずらさない（`<script>` は使えないので静的に計算して書く）
- 値→y座標の換算式をコメントに残す（例: `y = 252 − 2.24 × 値`）。数値だけ変えて座標を変え忘れない
- アクセント色で塗るのは終点ドット1つだけ。途中の点は白地＋1.5px枠のまま増やさない
- 下降トレンド（解約率など）で使う場合は、目標ラインを下に置き直し、終点の数値も下側に添える
- 目標ラインと折れ線が交差する（目標達成済み）場合は、KICKERを「TARGET ／ 達成済み」に変えて重なりを避ける
