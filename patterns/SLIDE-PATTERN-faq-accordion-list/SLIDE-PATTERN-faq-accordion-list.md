# SLIDE-PATTERN-faq-accordion-list

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** faq-accordion-list
**概要：** Webのアコーディオンを模した静的なFAQ一覧。4行の各行は「左に英字ラベル（`Q.01`・48px幅）→質問（16px・太字）→右端に開閉マーク（SVG三角・幅12px・muted）」の3カラム。1行目だけ「展開した状態」として質問の下に回答（16px・muted）を表示し、その行だけ `--sk-soft` 地（角丸11px）にする。閉じた行は1pxの細罫線で区切る。塗りは展開行だけ。
**適したシーン：** 質問数が4〜5問で、1画面に一覧で収めたい場面。説明会・営業資料の巻末FAQ。

## Structure（構造）

コンテンツエリア（左右余白48px・見出しON時は上76px以降）の上下中央に、Q.01〜Q.04の行を縦に積む。

    structure:
      layout: single-column-list
      items: 4
      row:
        columns: "48px 1fr 12px"        # ラベル / 質問（＋回答） / 開閉マーク
        column_gap: 16px
        padding: "20px 24px"
        align: start                    # 上ぞろえ
        rule: top 1px                   # var(--sk-line)。1行目と、展開行の直後の行は無し
      open_row:                         # 1行目だけ
        surface: var(--sk-soft)         # 角丸 11px（唯一の塗り）
        mark: 上向き三角
        order: [kicker, question, answer]
      closed_rows:
        surface: none
        mark: 下向き三角
        order: [kicker, question]
      cells:
        kicker:   "Q.01"                # 10px / 700 / .18em / 大文字 / アクセント色。質問行に合わせて上7px
        question: 質問 1行              # 16px / 700 / 行間 1.5 / インク色
        answer:   回答 1〜2行           # 16px / 400 / 行間 1.8 / muted 色。上8px
        mark:     SVG三角 12×8px        # fill var(--sk-muted)。質問行の中心に合わせて上8px

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（Q.01） | 各行の左（48px幅） | 質問の番号。アクセント色の文字で、丸バッジ・塗りにしない |
| 質問 | ラベルの右（16px・太字・1行） | 疑問形で短く（20字以内） |
| 開閉マーク | 各行の右端（SVG三角・12px・muted） | アコーディオンの見立て。展開行は上向き、閉じた行は下向き |
| 回答 | 展開行の質問の下（16px・muted） | 1行目だけ表示。結論から1〜2行で |
| 淡い地 | 展開行だけ（角丸11px） | 「開いている」状態を示す。塗りはここだけ |
| 細罫線 | 閉じた行の上 | 行と行の区切り（1px・`--sk-line`） |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-faq-accordion-listのレイアウトで、4つの質問を縦に並べ、1問目だけ回答を展開してください。各行は `Q.01`・質問（20字以内の疑問形）で書き、1問目の回答は1〜2行で結論から。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 質問は4問が基準（5問まで可）。展開するのは1行目だけ（2行以上開くと一覧の意味が薄れる）
- 回答は2行以内（1行40字前後）。行末に1〜2文字だけ残る折り返しは文言を削って避ける。長い回答は faq-single-column へ
- 三角は幅12pxのSVGだけ。＋／−記号やアイコンフォントに置き換えない
- 淡い地は展開行だけ。閉じた行に枠線・地色・バッジを足さない
- 静的な見立てなので、`<script>` での開閉は付けない（ギャラリー規約）

## v2 での描き直し（2026-09-03）
- 4問すべてを枠囲み＋Q丸バッジ（アクセント塗り）＋淡色帯にしていた構成を、「`Q.01`（英字ラベル・10px）→質問16px太字→右端のSVG三角」の3カラム行に変え、塗りを展開行（1行目）の淡い地だけにした
- 回答を全行表示（12px）から1行目だけの展開表示（16px・muted）に変え、閉じた行は1pxの細罫線で区切る構成にした
- 左右余白を96pxから48pxにそろえ、文字を v2 の組み（インク色・palt・禁則・太さ400/700）に合わせ、プレースホルダを具体例にした
