# SLIDE-PATTERN-team-members-grid

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** team-members-grid
**概要：** 円形写真プレースホルダ72px→氏名→役職の英字ラベル→一言2行のメンバーを4列×2行の等幅・等高グリッドに並べるチーム紹介。セルは枠なしで、行の間に横罫線1本。塗りは置かない
**適したシーン：** 会社紹介・採用資料のチーム紹介、講座の講師陣紹介。4〜8名の顔ぶれ提示。

## Structure（構造）
コンテンツエリア（左右余白48px）に、4列×2行の等幅・等高グリッド（列間16px）を置く。セルに枠や地色は付けず、1行目と2行目の間に全幅の横罫線（1px・`--sk-line`）を1本引く（上下20pxの余白）。各セルは中央ぞろえ・上ぞろえで「円形写真枠（72px・淡い地のプレースホルダ。中央に英字ラベル `PHOTO`）」「氏名（16px・太字）」「役職の英字ラベル（KICKER・`DESIGN ／ デザイン`）」「一言（16px・muted・同じ長さの2文を句点で2行に折る）」の順に組む。ブロック全体（高さ416px）は本文エリアの上下中央に置く。塗りは置かない。

    structure:
      layout: four-column-two-row-grid
      gap: 16 (column), rows separated by a full-width 1px rule (20px above/below)
      cell:
        frame: none
        align: center (horizontal), top (vertical)
        order:
          - photo (72px circle placeholder, soft ground, label "PHOTO")
          - name (16px, bold)
          - role (kicker: english label + japanese)
          - note (16px, muted, two equal-length sentences, balanced wrap breaks at 。)
      emphasis: none filled

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 円形写真枠 | セル上部（72px） | 実装時は `<img>` を円形クリップ（`object-fit:cover`）で差し込む。空のときは淡い地に英字ラベルだけ |
| 氏名 | 写真の下（16px・太字） | 姓と名の間に半角スペース |
| 役職（KICKER） | 氏名の下（10px・太字・アクセント色） | `CEO ／ 代表` のように英字＋日本語で担当を示す |
| 一言 | 最下（16px・muted・2行） | 「同じ長さの2文（各9字以内・句点で終える）」で書く。2行に均等に折る指定なので、2文の長さをそろえると句点の位置で折れる |
| 横罫線 | 1行目と2行目の間 | 行の区切り。ブロックの左端から右端まで1本 |

## Usage Guide（AIへの使い方）
> 「SLIDE-PATTERN-team-members-gridのレイアウトで、[チーム名]の8名を4列×2行で並べてください。各セルは氏名・役職の英字ラベル（`英字 ／ 日本語`）・一言（同じ長さの2文・各9字以内・句点で終える）の順で書いてください。デザインはSLIDE.mdに従ってください。」

- 4名以下なら1行にして罫線を外し、写真を96pxに拡大してよい
- 一言は「同じ長さの2文（各9字以内・句点で終える）」。例「設計と進行を担当。制作会社で十年目。」。長さをそろえないと語の途中で折れる。入らないときは文字を小さくせず、文言を短くする
- 写真が無い場合はプレースホルダのまま納品せず、写真を用意してから使う（アイコンや絵文字で代用しない）
- 塗り・カード枠は置かない。特定の1名を目立たせたいなら profile-bio で別スライドにする
- 2名なら profile-two-speakers を使う
