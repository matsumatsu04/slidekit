# SLIDE-PATTERN-three-col-icon-card-header-band

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** three-col-icon-card-header-band
**概要：** 淡い地（`--sk-soft`）の3列カード（等高304px・gap 16px・角丸11px・上ぞろえ）。色のヘッダーバンドの代わりにカード上辺に3pxのアクセント線を引き、六角形アイコンの代わりに KICKER（`01 ／ Attract` のように番号＋英字）を置く。中身は「KICKER → 見出し18px太字 → 細罫線 → 箇条書き16px（先頭に4pxの角ドット）→ CTA（最下部）」の型。CTA は1枚目だけアクセント塗り・白文字、他は白地＋1.5pxのアクセント枠。下に注記を1行添える。
**適したシーン：** 施策・取り組み・次のアクションを3つ並べ、各項目の目標をボタンで添えるスライド。重点施策を1つ際立たせたいとき

## Structure（構造）

コンテンツエリア（左右48px）の上下中央に「カード列 → 注記」を縦に積む。カードは grid（3等分・gap 16px・高さ304px）。カードの先頭に3pxのアクセント線、その下に内側の余白（上20px・左右24px・下24px）を取る。CTA は `margin-top:auto` でカードの最下部に固定し、項目数の差はカードの空きが吸収する。

    structure:
      layout: three-column-cards
      content_area:
        side_margin: 48px
        vertical_align: center          # 見出しON時は上76px以降の上下中央
      cards:
        columns: 3
        gap: 16px
        height: 304px                   # 等高
        surface: soft, radius 11px
        top_line: 3px accent            # 帯の代わり（面でなく線）
        padding: "20px 24px 24px"
        align: top
        card:
          - kicker: "01 ／ Attract"     # 10px / 700 / .18em / accent（番号＋英字）
          - heading                     # 18px / 700（10字以内）
          - rule                        # 1px / var(--sk-line)
          - bullets: 3 lines            # 16px / 400 / 行間1.8 / 先頭に4px角ドット（accent）/ 1行12字以内
          - cta (bottom)                # 14px / 700 / 角丸6px
        cta_surfaces:
          first: accent fill (white text)   # 塗りは1枚に1つ
          others: white + 1.5px accent outline
      note:
        style: "例：〜"                 # 11.5px / muted

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 上辺のアクセント線 | 各カードの上辺（3px） | カードの頭を示す線。旧版の色帯の置き換え（塗り面にしない） |
| KICKER | 各カード左上 | `01 ／ Attract` のように番号＋英字で施策の名前を示す（アイコンの置き換え） |
| 見出し | KICKER の下（18px・700） | 施策の主題（10字以内） |
| 細罫線 | 見出しの下 | 見出しと箇条書きの切り替え |
| 箇条書き | 罫線の下（16px・3行） | 取り組み内容。先頭は4pxの角ドット、1行12字以内 |
| CTA | カード最下部 | 各施策の目標を1行で。1枚目だけアクセント塗り（重点施策）、他は1.5pxの枠 |
| 注記 | カード列の下 | 「例：〜」で塗りの意味とCTAの書き方を1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-col-icon-card-header-bandのレイアウトで、[期間]の3つの重点施策を並べてください。各カードは KICKER（番号＋英字）・見出し（10字以内）・箇条書き3行（1行12字以内）・目標のボタン（1行）で書き、重点施策を1枚目に置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは1枚目のCTAだけ。カード本体・上辺の線・他のCTAは塗らない（帯に戻さない）
- 箇条書きは3行まで・1行12字以内。入らなければ文言を短くする（文字を小さくしない）
- CTA の文言は「目標 ／ 〜」の形で1行（13字以内）。数値を入れる場合も1行に収める
- アイコン（六角形・Font Awesome）は使わない。KICKER の番号＋英字で代える
- 旧版の「リード文（点線囲み）・色のヘッダーバンド・六角形アイコン・中央ぞろえ見出しの2px下線・10px箇条書き」は廃止
