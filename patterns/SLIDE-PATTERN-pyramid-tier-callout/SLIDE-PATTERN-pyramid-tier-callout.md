# SLIDE-PATTERN-pyramid-tier-callout

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** pyramid-tier-callout
**概要：** 左側に3段の台形を積んだピラミッド（上辺120px・底辺360px・高さ288px）を置き、段の中に「TIER 1」などの英字ラベル（KICKER）と段名（16px・700）を入れる。塗りは下から淡い地（soft）・罫線色（line）・頂点だけアクセント塗り・白文字（塗りは1枚に1つ）。段の間は白2pxの隙間。各段の右辺の中心から右へ1pxの引き出し線を伸ばし、同じ高さに置いた説明（見出し16px/700＋説明14px muted）とペアにする。引き出し線の端点は段の右辺と説明の左端で止める。
**適したシーン：** 階層構造・ランクの説明（上位層ほど希少・重要な構造）、顧客層のセグメント説明、成熟度・レベル分けの提示

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に 864×288px のステージを置く。左 360px にピラミッド（SVG）、右 384px（x=480〜864）に説明の行を段と同じ高さで絶対配置する。台形と引き出し線は1枚のSVGにまとめ、引き出し線を先に描いて台形で受ける（線の端点が段の右辺でぴたりと止まる）。

    structure:
      layout: pyramid-tier-callout (left pyramid / leader lines / right callouts)
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      stage: 864x288
      pyramid:
        svg: 3 trapezoids (top width 120, base 360, height 288), 2px white gap between tiers
        tiers:                       # y の範囲（上から）
          - tier-1: { y: 0-95,   fill: accent, text: white }   # 塗りはここだけ
          - tier-2: { y: 97-191, fill: line }
          - tier-3: { y: 193-288, fill: soft }
        label: { kicker: "TIER n", title: 16px/700 }           # 各段の中心に置く
      leader:
        stroke: 1px var(--sk-line)
        from: 各段の右辺（段の垂直中心の高さ）
        to: x=480（説明の左端）
      callout:
        rows: 3 (absolute, same y-range as each tier, vertically centered)
        elements: [title 16px/700, desc 14px muted]

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| ピラミッド（台形3枚） | ステージ左 360px | 階層構造・ランクを上から下へ視覚的に表す。頂点だけアクセント塗り |
| 段のラベル | 各段の中心 | KICKER `TIER 1` ＋ 段名（16px・700・3〜5文字）。頂点は白文字 |
| 引き出し線 | 段の右辺 → x=480 | どの段とどの説明が対応するかを結ぶ。1px 罫線色・水平のみ |
| 説明の行 | ステージ右・3行 | 見出し（16px・700）＋説明（14px・muted・1〜2行）。段と同じ高さに置く |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-pyramid-tier-calloutのレイアウトで、上から[第1層/第2層/第3層]の段名と、それぞれの説明に[見出しと説明文]を入れてください。段の中は TIER n ＋ 段名、右は見出し＋説明の順で書き、塗りは頂点だけにしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 段数は3段を基本とする。4段以上にすると各説明の行が窮屈になる
- 上段ほど「希少・重要・少数」、下段ほど「基礎・多数」を表すのが一般的な読み方。逆の意味で使う場合は誤解を招くため避ける
- **上下を反転させれば、そのままファネル（コンバージョン漏斗：上が広く下が狭い形）としても使える。** 見込み客数の絞り込みなど、逆の意味構造を表現したい場合は反転して使う（その場合も塗りは1段だけ）
- 段名は3〜5文字。説明は段ごとに分量を揃える（見出し1行＋説明1〜2行）
- 引き出し線は水平1本のみ。斜め線・矢印・点は付けない

## v2 での描き直し（2026-09-03）
- `clip-path` の台形3枚と div の接続線をやめ、台形3枚と引き出し線を1枚のSVGにまとめた。段の間は白2pxの隙間、塗りは下から soft・line・頂点だけアクセント（塗りは1枚に1つ）
- 段の中に KICKER（`TIER 1`）＋段名16px/700、右の説明を見出し16px/700＋説明14px muted の3行に揃え、左右余白48px・字間.06em・インク色にした
- 引き出し線は各段の右辺の中心から説明の左端（x=480）までを1px罫線色で引き、線を先に描いて台形で受けることで端点が段の右辺で止まるようにした
