# SLIDE-PATTERN-toc-current-highlight

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
目次は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・セクションと同じ扱い）。

## Overview
**パターン名：** toc-current-highlight
**概要：** 左カラムに小さな英字ラベル「contents」、右カラムに「2桁の章番号｜細い縦罫線｜項目名」の行を縦に並べる目次（toc-two-column と同じ構成）。現在の章の行だけ `--sk-soft` 地の帯（角丸8px）にし、番号をアクセント塗りの丸（白文字）に置き換えて「いまここ」を示す。塗りは現在地の丸1つだけ。
**適したシーン：** 章の切り替わりで目次を再掲し、現在地を示す場面。長尺デッキの迷子防止。

## Structure（構造）
```yaml
layout: toc-current-highlight
area: 全高（上下中央）
left_column:
  label: "contents"          # 15px / 700 / 字間 .3em / アクセント色。left:72px・垂直中央
right_column:
  left: 460px                # 行の左右 padding 16px を含む（番号の左端は 476px＝toc-two-column と同じ）
  items: 3〜6行（行高 44px・gap 16px・垂直中央）
  item:
    - number: 2桁ゼロ埋め   # 24px / 700 / アクセント色。幅 48px
    - vline: 1px × 22px      # var(--sk-line)。左右余白 12px / 20px
    - title: 項目名          # 16px / 400 / 字間 .2em / インク色。1行（折り返さない）
  current:                   # 現在の章の行だけ
    band: soft 地・角丸 8px   # var(--sk-soft)
    number: 36px の丸         # アクセント塗り・白文字・16px / 700
    title: 700               # 項目名だけ太字にする
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| contents ラベル | 左カラム・垂直中央 | 目次であることを示す小さな英字ラベル（小文字・字間広め） |
| 章番号 | 各行の左 | 2桁ゼロ埋めの番号。アクセント色の文字 |
| 縦罫線 | 番号と項目名の間 | 1px の細い罫線（`--sk-line`）。番号と項目名を区切る |
| 項目名 | 罫線の右 | 章タイトル。16px・字間 .2em で1行に収める |
| 現在地の帯 | 現在の章の行 | `--sk-soft` 地・角丸8px の帯。塗りではなく淡いティントで行を持ち上げる |
| 現在地の丸 | 現在の章の番号 | アクセント塗り＋白文字の36pxの丸。このスライドで唯一の塗り |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-toc-current-highlight を使って目次（再掲）を1枚生成してください。
【項目】
01 制作の現場で起きている詰まり
02 AIに任せる工程と人が決める工程
03 試作から現場へ入れる手順　← 現在
04 運用で見る数字と直し方
05 体制と役割の分け方
```
### 注意点
- 章の進行に合わせて `tch-cur` クラスを移動して使い回す。初出の目次には toc-two-column を使い、再掲時にこのパターンへ切り替える
- 項目は3〜6個。項目名は1行（全角16文字程度）に収める。長い場合は言い切りに削る（文字を小さくしない）
- 塗りは現在地の丸だけ。帯は soft 地のままにし、アクセント塗りの帯や NOW バッジは足さない（強調が散る）
- 項目数が減っても右カラムは上下中央のまま（上に張り付けない）

## v2 での描き直し（2026-09-02）
- 「AGENDA・グレー文字5行・現在章だけアクセント帯＋白文字＋NOWバッジ」から、toc-two-column と同じ「contents＋番号｜縦罫線｜項目名」構成に描き直した
- 現在地の強調を「soft 地の帯（角丸8px）＋番号のアクセント塗りの丸（白文字）＋項目名の太字」に変え、塗りを丸1つに絞った（帯の塗り・NOWバッジ・行間の区切り線を無くした）
- 文字の組みを v2 の表に合わせた（ラベル 15px/.3em、番号 24px/700、項目名 16px/.2em、`palt`・`line-break:strict`・インク色）
