## Overview

**パターン名：** comparison-matrix-table
**概要：** 複数の対象（行）を複数の比較軸（列）で見比べる本物の表。ヘッダ行だけアクセント塗り（白文字・10px・字間.18em）、左列はアクセント色の太字、行は高さ48px以上で細い罫線だけで区切る。
**適したシーン：** ターゲットセグメント比較、競合比較、プラン別機能比較、進め方の比較、顧客タイプ別分析

## Structure（構造）

コンテンツエリアの上下中央に `<table>` を置く。最上行がヘッダ（比較軸の名前）、最左列が比較対象の名前。塗りはヘッダ行だけで、データ行は細い罫線（`--sk-line`）で区切る。表の下に「例：〜」の注記を1行添える。

        element: "<table>"          # div の擬似表ではなく本物の表
        table_layout: fixed
        corner: "上2隅だけ 10px の角丸"
        header_row:
          surface: accent_fill      # 塗りはここだけ
          text: "白 / 10px / 700 / .18em / 大文字"
          height: 40px
          cells: [対象の見出し(140px), 比較軸 × 3]
        data_rows:
          count: 4                  # 4〜5行まで
          min_height: 48px          # 実測は 1行53px・2行82px
          divider: "1px の罫線（--sk-line）。縦罫線は引かない"
          left_cell: "対象名（アクセント色・700・16px）"
          data_cells: "本文 16px / 行間1.8 / 左揃え（12文字以内で1行）"
      note: "例：〜（11.5px・muted）を表の下 12px に置く"

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| ヘッダ行 | 最上行 | 比較軸の名称（例：初期コスト／修正の速さ／向いている案件）。唯一の塗り |
| 左列 | 最左列 | 比較対象の名称（例：自社で内製／外注／テンプレート／AI × 人）。アクセント色太字 |
| データセル | 各交差点 | 対応する比較内容（12文字以内で1行。2行までは許容） |
| 行罫線 | 各行の下 | 行の区切り。塗り・縞模様は使わない |
| 注記 | 表の下 | 「例：〜」で読み方・判断の目安を1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-comparison-matrix-tableのレイアウトで、[N]つの対象（行）を[M]つの比較軸（列）で比較してください。ヘッダ行だけ塗り、左列の対象名はアクセント色の太字にしてください。セルは12文字以内で1行、表の下に「例：〜」の注記を1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りはヘッダ行だけ。旧版の「推奨列のハイライト」は廃止した（強調したい対象は左列の並び順で先頭に置く）
- 列は「対象名＋比較軸3つ」が基本。4軸以上は文字が入らないので枚数を分ける
- 行は4〜5行まで。セルは12文字以内で1行に収める（2行になる場合は行高が伸びる。文字は小さくしない）
- ヘッダの文字は 10px の英字ラベル扱い。長い軸名は短い体言に言い換える
