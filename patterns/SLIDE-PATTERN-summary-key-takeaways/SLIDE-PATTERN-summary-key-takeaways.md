# SLIDE-PATTERN-summary-key-takeaways

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリア・ページ番号・装飾はデザインテーマ側の Frame で定義されるため、このファイルには含みません。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** summary-key-takeaways
**概要：** 持ち帰りの要点3つを、「番号（24px・400・アクセント色）＋見出し18px＋本文16px」の行として縦に積み、行を1pxの細罫線で区切る。上に `KEY TAKEAWAYS ／ 持ち帰り3点` の英字ラベル、最下部に3点を束ねる結論ピル（高さ34px・全角丸・アクセント塗り・字間.2em）。アクセント色の塗りはピルだけ。
**適したシーン：** セミナー・研修・提案の締め。今日の要点を3つに凝縮して持ち帰らせる場面

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 一覧の上 | `KEY TAKEAWAYS ／ 持ち帰り3点` のように英字＋補足で一覧の役割を示す。アクセント色 |
| 番号 | 各行の左（24px・400） | 順序を示すだけの細い数字。アクセント色の文字で、塗り・丸バッジにしない |
| 見出し | 番号の右・上段 | 持ち帰る要点を言い切りで（18px・700・1行・14〜22文字） |
| 本文 | 見出しの下 | 根拠や具体を1〜2行で（16px・400） |
| 細罫線 | 行の間 | 1px・`--sk-line`。行を区切る |
| 結論ピル | 最下部・中央 | 3点を束ねる1文。このスライドで唯一のアクセント色の塗り（12〜20文字） |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE-PATTERN-summary-key-takeaways を使ってまとめを1枚生成してください。

【スライドタイトル】本日の持ち帰り
【KICKER】KEY TAKEAWAYS ／ 持ち帰り3点
【1】見出し: 任せる範囲と確認する範囲を、先に線引きする / 本文: AIの出力を毎回ゼロから読み直さないために、着手前に1枚で決めておく。
【2】見出し: 小さく試して、崩れなければ次の工程へ広げる / 本文: ページ単位の試作から始めると、戻りが出ても直す範囲が小さく済む。
【3】見出し: 確認の手順を型にして、誰が見ても同じ品質で通す / 本文: 数字・固有名詞・リンクの3点を見る順番まで決めておけば、担当が変わってもぶれない。
【結論ピル】線引きしてから、小さく試す
```

### 注意点
- 要点は必ず3つ（2つ・4つのときは summary-three-points を検討）
- 見出しは1行（22文字以内）、本文は2行以内。入らなければ文字を小さくせず、言い切りに削る
- 塗りはピルだけ。番号を丸バッジにしたり、行に地色を敷いたりしない
- ピルは1文。長くなるなら本文に戻す（ピルを2段にしない）
- チェックリスト調の内容なら summary-three-points、CTAで締めるなら next-step-cta-band へ

## v2 での描き直し（2026-09-02）
- 「特大の淡色番号56px＋アクセント短線＋要点＋補足12px」の3カラム横並びを、番号（24px・400・アクセント色）＋見出し18px＋本文16pxの行を細罫線で区切る縦積みに変えた

- 文字をインク色・palt・禁則・太さ400/700に揃え、左右余白を48pxにし、プレースホルダを具体例にした
