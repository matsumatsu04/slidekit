## Overview

**パターン名：** four-card-2x2
**概要：** 4つの項目を2列×2行の等高カードに配置し、各カードを「英字ラベル→番号＋見出し→細罫線→本文→例：」の型で組むレイアウト。1枚だけ塗り、右下の最終項目だけ枠線で別扱いにする
**適したシーン：** 4つの特徴・メリット・前提条件の説明、2×2マトリクスの各象限の説明（1つを主役にしたいとき）

## Structure（構造）

コンテンツエリア（左右余白48px）を2列×2行の等高カード（gap 16px・角丸11px）に分割する。カードは淡い地で、中身は左ぞろえに「英字ラベル（KICKER）」「番号（24px・細め）＋見出し（同じ行）」「細罫線」「本文（2行）」「例：の注記」の順に置く。4枚のうち1枚を塗りカード（白文字）で主役にし、右下の1枚（最終項目）は白地＋1.5pxの枠線で別扱いにする。カード群は本文エリアの上下中央に置く。

    structure:
      layout: two-by-two-grid
      columns: 2
      rows: 2
      cards:
        equal_height: true
        gap: 16
        emphasis: one filled card (1 of 4)
        final: bottom-right card outlined (not filled)
      card:
        order:
          - kicker (english label + japanese supplement)
          - number (24px, regular) + heading (16-18px, bold) on one line
          - thin-rule
          - body (16px, 2 lines)
          - note ("例：" 11.5px)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 各カード最上段 | `Target ／ 対象` のように英字＋日本語補足で項目の分類を示す |
| 番号 | 見出しの左（24px・細め） | 01〜04の順序。太くしない |
| 見出し | 番号の右（太字） | カードのキーワード（10字前後） |
| 細罫線 | 見出しと本文の間 | 見出しと本文の切り替え。塗りカード内は白の半透明線 |
| 本文 | 罫線下（2行） | 見出しの説明。1文か2文で言い切る |
| 注記（例：） | 本文下（小さく薄く） | 具体例を1行で添える |
| 塗りカード | 4枚のうち1枚 | 主役の項目。1枚のスライドで塗りは1つだけ |
| 枠線カード | 右下 | 最終・結果にあたる項目を塗らずに区別する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-four-card-2x2のレイアウトで、4つの[テーマ]を2×2で説明してください。各カードは英字ラベル・番号＋見出し・本文2行・「例：」の順で書き、主役にする1枚と、最後の項目（右下）を指定してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 4カード固定のパターン。3項目や5項目には向かない
- 本文はカード幅（1行22字前後）で2行に収まる長さ（40字以内）にする。入らないときは文字を小さくせず、文言を短くする
- 塗りは1枚だけ。右下は塗らず枠線にする（最終項目の別扱い）。2枚以上塗らない
- 番号は装飾ではなく順序。順序のない4項目なら番号を省いてよい
