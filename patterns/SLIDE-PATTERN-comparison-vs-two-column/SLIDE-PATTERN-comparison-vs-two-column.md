# SLIDE-PATTERN-comparison-vs-two-column

## Overview
**パターン名：** comparison-vs-two-column
**概要：** 左＝一般（淡い地）・右＝自社（アクセント塗り・白文字）の等高パネル2枚を並べ、中央に白丸の「vs」を置く対決型比較。各パネルは「KICKER／案名18px／細い罫線／比較項目3行（ラベル10px＋値16px）／例：」の同じ型で組む。
**適したシーン：** 競合・従来手法との差別化提示。「他社と何が違うの？」への回答1枚。

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、等幅・等高（280px）のパネル2枚を置き、間の48px幅の列に白丸のコネクタ（vs）を置く。左パネルは淡い地（一般・従来）、右パネルはアクセント塗り（自社）で対比する（塗りは1枚に1つ）。パネルの中身は左右とも同じ型で、比較項目のラベルは左右で必ず同じにする。

    structure:

      content_area:

      row:
        display: flex
        height: 280px               # 2パネルは等高
      panel_common:
        border_radius: 12px
        padding: "24px 28px"
        elements:
          - kicker: "英字ラベル ／ 案の補足"      # 10px / 700 / .18em（右パネル内は白）
          - name: "案名 1文"                    # 18px / 700
          - rule                                # 1px（右パネル内は白35%）

      right:
        surface: accent_fill                    # アクセント塗り・白文字（自社。塗りはここだけ）

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各パネル左上 | `OTHERS ／ 一般的な制作会社`・`OURS ／ 月額制のWeb制作` のように英字＋日本語補足 |
| 案名 | KICKER の下 | その側のやり方を1文で（12文字前後・18px・太字） |
| 細い罫線 | 案名の下 | 案名と比較項目の区切り（右パネル内は白35%） |
| 比較項目 | 罫線の下（3行） | 左にラベル（`Price ／ 料金` など10pxのKICKER型）、右に値（16px）。ラベルは左右で同じ |
| 注記 | パネル最下 | 「例：〜」で具体的な場面を1行添える |
| コネクタ | 中央 | 「vs」の白丸に細枠。文字はアクセント色 |
| 塗りパネル | 右 | 自社・推す側。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

プロンプト例：

> 「SLIDE-PATTERN-comparison-vs-two-columnのレイアウトで、[一般的なやり方]と[自社のやり方]を比較してください。右を自社として塗り、比較項目は『料金』『納期』『更新』の3行で左右同じラベルにし、各パネルの最後に「例：〜」を1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 比較項目のラベルは左右で必ず同じにする（行の位置も揃える）
- 自社側の値は「◯◯できる」「◯◯に含む」など前向きな文言で書く。左は事実として淡々と書き、貶さない
- 値は12文字以内で1行。入らないときは文字を小さくせず、文言を短くする
- 塗りは右パネルだけ。コネクタや左パネルに別の塗りを足さない。比較軸が4つ以上なら comparison-matrix-table を使う
