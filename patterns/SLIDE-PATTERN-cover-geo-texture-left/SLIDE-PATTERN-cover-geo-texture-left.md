# SLIDE-PATTERN: cover-geo-texture-left

このファイルはスライドのレイアウトパターン定義書です。表紙は共通見出し（`sk-head`）を付けない種類のスライドで、
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。
背景は `assets/covers/` の画像アセットで、この表紙の家族だけに認められた例外です（色ティントの対象外）。

## Overview
**パターン名：** cover-geo-texture-left
**概要：** 紙質感の幾何学モチーフ（右上・右下・左下）が入った背景画像を全面に敷き、絵柄が薄い左側に文字ブロックを置く。文字は「英字KICKER → タイトル2行 → 64pxの細い区切り線 → 補足1行」の順に縦に組み、スライドの上下中央にそろえる。サブタイトルは置かない。
**適したシーン：** カルチャーデック、会社紹介、採用資料。上品で柔らかいトーンの表紙。

## Structure（構造）
```yaml
layout: cover-geo-texture-left
background:
  image: /assets/covers/cover-bg-geometric-paper.jpg
  fit: center / cover / no-repeat      # 差し替え・削除をしない（色ティント対象外）
text_block:                            # 左 80px から・width 520px・上下中央（top 50% + translateY(-50%)）
  kicker: 英字ラベル ／ 資料の種別       # 10px / 700 / 字間 .2em / 大文字 / var(--sk-ink)
  title:  タイトル                      # 40px / 700 / 字間 .06em / 行間 1.35 / 最大2行 / #1A1A1A
  rule:   区切り線                      # 幅 64px・高さ 1px・#AAAAAA（title から 28px 下）
  meta:   補足1行                       # 16px / 400 / 字間 .06em / #555555（社名 ／ 日付）
notes:
  - 左下の幾何モチーフは y≈395px から始まるので、文字ブロックの下端（≈373px）を下げない
  - 影・グラデーションのテキスト装飾は使わない
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景画像 | 全面（`/assets/covers/cover-bg-geometric-paper.jpg`） | 紙質感の幾何学モチーフ。左〜中央が余白なので、そこに文字を置く |
| KICKER | 文字ブロックの先頭 | 英字ラベル＋資料の種別（例：`Company Profile ／ 会社紹介`）。背景が明るい側なのでインク色 |
| タイトル | KICKER の下 | 資料タイトル。40px・700・最大2行。標語調にしない |
| 区切り線 | タイトルの下 | 幅64px・1px の細い線。タイトルと補足の間を切る |
| 補足1行 | 区切り線の下 | 社名・日付など（例：`Macminol ／ 2026.04`）。16px |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-cover-geo-texture-left を使って表紙を1枚生成してください。
【KICKER】Company Profile ／ 会社紹介
【タイトル】事業とチームの体制を／まとめた会社紹介
【補足】Macminol ／ 2026.04
```
### 注意点
- タイトルは40pxで最大2行（この幅で1行あたり全角12文字程度）。入らなければ言い切りに削る（文字を小さくしない）
- **サブタイトルは置かない**（2026-08-31 代表決定）。副題を出したいときは KICKER の後半に回す
- 補足は1行だけ。11.5px の注記は使わない
- 背景画像は差し替え・削除をしない。読みにくいときだけ、文字ブロックの `width` で折り返し位置を調整する
- 背景画像レイヤー（`slides[].bg`）は OFF にする（表紙が自前の背景画像を持つため）
- 同じ家族（画像背景の表紙）は cover-art-brush-left / cover-soft-3d-left / cover-blob-side-left / cover-curve-shape-left。文字の組みは5種で共通なので、背景の雰囲気だけで選ぶ

## v2 での描き直し（2026-09-04）
- タイトル40px/700・行間1.35・2行までに統一し、上に英字KICKER（10px・字間.2em・インク色）、下に幅64pxの細い区切り線を足した
- 「タイトル → 会社名 → 日付」の3段積みを、「KICKER → タイトル → 区切り線 → 補足1行」に組み替え、社名と日付を16pxの1行にまとめた
- 文字ブロックの起点を左72px→80pxに寄せ、スライドの上下中央にそろえた（背景画像・画像用の固有色はそのまま）
