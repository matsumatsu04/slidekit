# SLIDE-PATTERN: closing-art-brush-contact

このファイルはスライドのレイアウトパターン定義書です。締めは共通見出し（`sk-head`）を付けない種類のスライドで、
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。
背景は `assets/covers/` の画像アセットを使うため、ギャラリーの色ティントは適用されません。

## Overview
**パターン名：** closing-art-brush-contact
**概要：** 右側に水彩の筆致（画材モチーフ）が寄った画像を全面に敷き、左側に残る白い余白だけで文字を組む締め。左80pxから「英字KICKER → 見出し32px（1〜2行）→ 幅64pxの細い罫線 → 連絡先」を縦中央にそろえて積む。連絡先は「ラベル（KICKER 10px）｜値（16px）」の2列で、ラベルの左端どうし・値の左端どうしがそろう。半透明の白カードは使わず、素の白い地に直接組む。
**適したシーン：** プレゼンの最終スライド（連絡先・相談窓口の提示）。表紙 `cover-art-brush-left` と同じ背景で揃えると、表紙〜締めでトーンが通る。

## Structure（構造）
```yaml
layout: closing-art-brush-contact
background:
  image: assets/covers/cover-bg-handdrawn-art.jpg   # center/cover・全面。差し替え可（色ティント対象外）
  note: 右側に筆致、左側は白。文字は左の白い余白にだけ置く
wrap:                              # left 80px・width 340px・全高の上下中央・縦積み gap 20px
  kicker: "CONTACT"                # 10px / 700 / 字間 .2em / 大文字 / var(--sk-ink)
  message: 締めの見出し 1〜2行      # 32px / 700 / 字間 .06em / 行間 1.35 / var(--sk-ink)
  rule: 64×1px                     # var(--sk-muted)
  list:                            # grid 2列（auto 1fr）・列間 16px・行間 12px・ベースラインそろえ
    rows: 2〜3
    label: "MAIL / TEL / WEB"      # 10px / 700 / 字間 .2em / 大文字 / var(--sk-muted)
    value: 連絡先の値               # 16px / 400 / 字間 .06em / var(--sk-ink)
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景画像 | 全面 | 右に水彩の筆致が寄った素材。左の白い余白が文字の置き場になる。別アセットに差し替え可 |
| KICKER | 文字ブロック最上 | `CONTACT` など、締めであることを示す英字ラベル。明るい地なのでインク色 |
| 見出し | KICKERの下 | 「ご相談はいつでもお気軽に」等を32px・700で1〜2行。`<br>` は意味の切れ目で切る |
| 細い罫線 | 見出しの下 | 幅64px・1pxの区切り。見出しと連絡先を分ける |
| 連絡先ラベル | 各行の左列 | `MAIL` `TEL` `WEB` の英字ラベル（muted） |
| 連絡先の値 | 各行の右列 | メール・電話・URLを16pxで1行ずつ |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-closing-art-brush-contact を使って締めを1枚生成してください。
【KICKER】CONTACT
【見出し】ご相談はいつでも／お気軽に
【連絡先】MAIL: info@example.com ／ TEL: 03-0000-0000 ／ WEB: www.example.com
```
### 注意点
- 文字は左の白い余白（左80px・幅340px）に収める。右の筆致には重ねない
- 見出しは32pxで1〜2行、1行あたり全角8文字まで。入らなければ文言を短くする（文字を小さくしない）
- 連絡先は2〜3行。4行以上になるなら値を1つにまとめる（行を増やして詰めない）
- 連絡先の値はダミー。実在ドメイン・実在の電話番号は書かない（`example.com` は文書用の予約ドメイン）
- 半透明の白カードや影は足さない。背景の白い面をそのまま余白として使う
- QRコードを添えたい場合は右下ではなく罫線の下に置き、幅は96pxまでにする
- 背景に画像を敷くため、ギャラリーの色ティント（アクセント色の差し替え）は効かない

## v2 での描き直し（2026-09-04）
- 半透明白（`rgba(255,255,255,.92)`）の角丸連絡先カードを廃し、背景の白い面に直接組んだ。34pxのメッセージは32px・行間1.35にそろえ、左端を72pxから80pxにそろえた
- 純黒寄りの #1A1A1A / #333333 / #555555 / #DDDDDD をやめ、本文はインク色 `var(--sk-ink)`、ラベルは `var(--sk-muted)` に統一。太さは400と700の2つだけにした
- 見出しの上に KICKER 10px、下に幅64pxの細い罫線を入れ、連絡先を「ラベル（KICKER 10px）｜値（16px）」の2列グリッドにしてラベルと値の左端をそろえた（背景画像はそのまま維持）
