# SLIDE-PATTERN-comparison-table-with-highlight

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** comparison-table-with-highlight
**概要：** 複数のプラン・選択肢（列）を比較軸（行）で見比べ、推奨する1列だけを淡い地（`--sk-soft`・列全体）で浮かせる本物の表。ヘッダ行だけアクセント塗り（白文字・10px・字間.18em）、左列の比較軸はアクセント色の太字、セルは16px。
**適したシーン：** 料金プラン比較、サービスプラン説明、仕様比較、複数の選択肢から1つを推す提案

## Structure（構造）

コンテンツエリアの上下中央に `<table>` を置く。最上行がヘッダ（選択肢の名前）、最左列が比較軸の名前。塗りはヘッダ行だけで、データ行は細い罫線（`--sk-line`）で区切る。推奨する選択肢の列は、データ行のセルだけを `--sk-soft` 地にして列全体を浮かせる（角丸なし。ヘッダは他の列と同じ塗り）。推奨列のヘッダには白の細枠の小さなタグ（おすすめ）を添える。表の下に「例：〜」の注記を1行添える。

    structure:
      layout: comparison-table-with-recommended-column
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      table:
        element: "<table>"          # div の擬似表ではなく本物の表
        table_layout: fixed
        corner: "上2隅だけ 10px の角丸"
        header_row:
          surface: accent_fill      # 塗りはここだけ
          text: "白 / 10px / 700 / .18em / 大文字"
          height: 40px
          cells: [比較軸(160px), 選択肢 × 3（等幅）]
          recommended_tag: "白の1px枠の小タグ（塗らない）を推奨列のヘッダ名の右に置く"
        data_rows:
          count: 4                  # 4〜5行まで
          min_height: 48px          # 実測は 1行53px
          divider: "1px の罫線（--sk-line）。縦罫線・縞模様は引かない"
          axis_cell: "比較軸の名前（アクセント色・700・16px）"
          data_cells: "本文 16px / 行間1.8 / 左揃え（10文字以内で1行）"
          recommended_column: "データ行のセルだけ --sk-soft 地（列全体・角丸なし）"
      note: "例：〜（11.5px・muted）を表の下 12px に置き、選び方の目安を書く"

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| ヘッダ行 | 最上行 | 選択肢の名称（例：ライト／スタンダード／プレミアム）。唯一の塗り |
| おすすめタグ | 推奨列のヘッダ名の右 | 白の細枠の小タグ。列が淡い地になっている理由を示す |
| 左列 | 最左列 | 比較軸の名称（例：月額／対応範囲／修正回数／向いている人）。アクセント色太字 |
| 推奨列 | 中央など1列 | データ行のセルを `--sk-soft` 地にして列全体を浮かせる。文字は他の列と同じ |
| データセル | 各交差点 | 対応する比較内容（10文字以内で1行。2行までは許容） |
| 行罫線 | 各行の下 | 行の区切り。塗り・縞模様・外枠は使わない |
| 注記 | 表の下 | 「例：」で選び方の目安を1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-comparison-table-with-highlightのレイアウトで、[N]つの選択肢（列）を[M]つの比較軸（行）で比較し、[推奨する選択肢]の列だけを淡い地で浮かせてください。ヘッダ行だけ塗り、左列の比較軸はアクセント色の太字、セルは10文字以内で1行にし、表の下に「例：〜」の注記を1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 淡い地にする列は1つだけ。2列以上を浮かせない（推す対象が無い対等な比較は comparison-matrix-table を使う）
- 塗りはヘッダ行だけ。旧版の「価格セルの大きな色文字」「左列のグレー地」「全セル罫線」は廃止した。価格など強調したい値も他のセルと同じ16pxで書く
- 列は「比較軸＋選択肢3つ」が基本。4つ以上は文字が入らないので枚数を分ける
- 行は4〜5行まで。セルは10文字以内で1行に収める（文字は小さくしない）
- ヘッダの文字は 10px の英字ラベル扱い。長い選択肢名は短い体言に言い換える
