# SLIDE-PATTERN: cover-soft-3d-left

このファイルはスライドのレイアウトパターン定義書です。表紙は共通見出し（`sk-head`）を付けない種類のスライドで、
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。
背景は `assets/covers/` の画像アセットで、この表紙の家族だけに認められた例外です（色ティントの対象外）。

## Overview
**パターン名：** cover-soft-3d-left
**概要：** すりガラス質感の3Dオブジェクトが右側に浮かぶ淡い青灰色の背景画像を全面に敷き、絵柄が薄い左側に文字ブロックを置く。文字は「英字KICKER → タイトル2行 → 64pxの細い区切り線 → 補足1行」の順に縦に組み、スライドの上下中央にそろえる。タイトルと区切り線だけ、背景画像に合わせた固有色（`#2E4A6B` / `#8A8F98`）を使う。
**適したシーン：** IT/SaaSの会社紹介（Company Profile）・プロダクト資料の表紙。

## Structure（構造）
```yaml
layout: cover-soft-3d-left
background:
  image: /assets/covers/cover-bg-soft-3d.jpg
  fit: center / cover / no-repeat      # 差し替え・削除をしない（色ティント対象外）
text_block:                            # 左 80px から・width 500px・上下中央（top 50% + translateY(-50%)）
  kicker: 英字ラベル ／ 資料の種別       # 10px / 700 / 字間 .2em / 大文字 / var(--sk-ink)
  title:  タイトル                      # 40px / 700 / 字間 .06em / 行間 1.35 / 最大2行 / #2E4A6B（画像に合わせた固有色）
  rule:   区切り線                      # 幅 64px・高さ 1px・#8A8F98（title から 28px 下）
  meta:   補足1行                       # 16px / 400 / 字間 .06em / #555555（社名 ／ 最終更新日）
notes:
  - 3Dオブジェクトは x≈612px から始まるので、文字ブロックの右端（80+500=580px）を超えない
  - 旧版の「細身（weight normal）の大タイトル」は廃止。太さは 400 と 700 の2つだけ（v2）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景画像 | 全面（`/assets/covers/cover-bg-soft-3d.jpg`） | 半透明3Dオブジェクト。左〜中央が余白なので、そこに文字を置く |
| KICKER | 文字ブロックの先頭 | 英字ラベル＋資料の種別（例：`Service Overview ／ サービス紹介`）。背景が明るい側なのでインク色 |
| タイトル | KICKER の下 | 資料タイトル。40px・700・最大2行。色は画像に合わせた濃紺 `#2E4A6B` |
| 区切り線 | タイトルの下 | 幅64px・1px の細い線。色は画像に合わせた青灰 `#8A8F98` |
| 補足1行 | 区切り線の下 | 社名・最終更新日など（例：`Macminol ／ 最終更新 2026.04`）。16px |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-cover-soft-3d-left を使って表紙を1枚生成してください。
【KICKER】Service Overview ／ サービス紹介
【タイトル】プロダクトの機能と／導入までの進め方
【補足】Macminol ／ 最終更新 2026.04
```
### 注意点
- タイトルは40pxで最大2行（この幅で1行あたり全角11文字程度）。入らなければ言い切りに削る（文字を小さくしない）
- **サブタイトルは置かない**（2026-08-31 代表決定）。副題を出したいときは KICKER の後半に回す
- タイトル色 `#2E4A6B`・区切り線 `#8A8F98` は背景画像に合わせた固有色で、パレットに連動しない。濃色にそろえたいときは `#333333` に替えてよい
- 補足は1行だけ。11.5px の注記は使わない
- 背景画像レイヤー（`slides[].bg`）は OFF にする（表紙が自前の背景画像を持つため）
- 同じ家族（画像背景の表紙）は cover-geo-texture-left / cover-art-brush-left / cover-blob-side-left / cover-curve-shape-left。文字の組みは5種で共通なので、背景の雰囲気だけで選ぶ

## v2 での描き直し（2026-09-04）
- タイトルを44px・細身（weight normal）・字間.10em から 40px/700・字間.06em・行間1.35 に改め、上に英字KICKER、下に幅64pxの細い区切り線を足した
- 会社名を上に別置きする組みをやめ、社名と更新日を16pxの補足1行にまとめた
- 絶対配置の3段（top 150/225/330px）を、左80px・上下中央の1ブロックに置き換えた（背景画像と固有色 #2E4A6B / #8A8F98 はそのまま）
