# SLIDE-PATTERN-estimate-base-plus-options

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** estimate-base-plus-options
**概要：** 上段に「左＝基本プランのカード（`--sk-soft` 地・角丸11px。KICKER `BASE ／ 基本` → プラン名18px → 内容3行 → 細罫線 → 金額20px）／中央＝「＋」（24px・muted）／右＝オプション3枚の縦積み（1.5pxの罫線枠・角丸8px。KICKER `OPTION 1` → 名前16px、右端に「+¥」の金額）」を等高で並べ、下段に合計行（アクセント塗り・白文字・角丸8px。KICKER `TOTAL` → 金額20px）を置く。「決まっている費用」と「選べる費用」を構図そのもので分離し、塗りは合計行の1つだけにする。
**適したシーン：** 基本セット＋選択オプションという料金構造の提示。Web制作受託の見積、パッケージ＋追加メニューの料金ページ。

## Structure（構造）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 基本カード | 上段左 | 「決まっている費用」のかたまり。淡い地で1つの商品として見せる |
| KICKER | 各カード左上 | `BASE ／ 基本`・`OPTION 1 ／ 任意` のように英字＋日本語補足。合計行では白 |
| プラン名 | 基本カードのKICKER下 | 基本セットの名前（18px・太字） |
| 内容3行 | プラン名の下 | 基本セットに含まれるもの（16px・3行） |
| 細罫線＋金額 | 基本カード下端 | 基本料金（20px・太字・インク色）。ラベルに税区分を添える |
| ＋ | 中央の列 | 基本にオプションを足せる関係を式で示す（文字1つ・muted） |
| オプションカード | 上段右に3枚 | 「選べる費用」1件。罫線枠だけの軽いカードにして基本と重さを変える |
| 金額（+¥） | オプションカード右端 | 追加単価。「+」付きで上乗せであることを示す |
| 合計行 | 下段 | 基本＋オプション全件の総額。1枚で塗るのはここだけ |
| 注記 | 合計行の下 | 「例：」でオプションの選び方・前提を1行 |

## Usage Guide（AIへの使い方）

プロンプト例：

> 「SLIDE-PATTERN-estimate-base-plus-optionsのレイアウトで見積スライドを作成してください。基本プランは『コーポレートサイト制作（5ページ）』で内容3行、基本料金 ¥640,000。オプションは『下層ページの追加 +¥40,000』『写真撮影 +¥80,000』『英語ページの制作 +¥60,000』の3件、合計 ¥820,000（税別）。デザインはSLIDE.mdに従ってください。」

注意点：
- 塗りは合計行の1つだけ。旧版の「ヘッダー帯の塗り」「円形の＋」「淡アクセント地の合計行」「Font Awesomeの＋アイコン」は廃止した。基本カードは淡い地、オプションは罫線枠にとどめる
- 合計行の金額は「基本＋オプション全件」の総額。基本だけの合計は基本カードの金額欄に置く（2つの金額を混同しない）
- オプションは2〜4枚。5件以上は枚数を分けるか、オプションだけを line-item-table にする
- 内容3行は1行16文字以内、オプション名は14文字以内で1行に収める（文字は小さくしない）
- オプションが1件以下ならこのパターンは大げさ。estimate-total-side-panel か price-total-highlight を使う

## v2 での描き直し（2026-09-03）
- 「アクセント帯ヘッダー＋横罫の内訳行＋淡アクセント地の合計」の本体ボックスと、円形の＋・Font Awesomeの＋付きオプションレールをやめ、左＝淡い地の基本カード（KICKER→プラン名18px→内容3行→細罫線→金額20px）／中央＝文字の＋（24px・muted）／右＝1.5px罫線枠のオプションカード3枚（KICKER→名前16px＋金額右寄せ）の等高3列にした
- 塗りを下段の合計行（アクセント塗り・白文字・角丸8px・KICKER `TOTAL`＋金額20px/700）の1つに絞り、外部CSS（Font Awesome）の `<link>` を外した
- 文字を v2 の表に揃え（KICKER 10px・見出し18px・本文16px・注記11.5px・インク色・palt・禁則・太さ400/700のみ・`tabular-nums`）、左右余白48px・角丸11px/8px・gap 12〜16pxにした
