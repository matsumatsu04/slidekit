# SLIDE-PATTERN-estimate-base-plus-options

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** estimate-base-plus-options
**概要：** 左約62%に本体見積ボックス（上辺にアクセント色の帯ヘッダー＝白抜きラベル＋英字小、中に横罫のみで区切る内訳行4〜5行＝項目名太字｜一言説明｜金額右揃え、最下行だけ淡いアクセント地の合計行）を置き、中間の余白の垂直中央に円形の＋演算子を1個挟んで、右約30%にオプションレール（見出し＋細横罫で区切る行5〜6本＝行頭の小さな＋記号・オプション名・右端に単価、下端に補足1行）を並べる。「決まっている費用」と「選べる費用」を構図そのもので分離する。
**適したシーン：** 基本セット＋選択オプションという料金構造の提示。Web制作受託の見積、パッケージ＋追加メニューの料金ページ。

## Structure（構造）

```yaml
content-area:
  layout: two-zone + operator (垂直センタリング)
  zones:
    - base-box:                    # 左 約62%。角丸・細枠のボックス
        - header-band:             # 上辺のアクセント色帯
            - base-label:          # 白抜きラベル（基本一式 等）
            - en-label:            # 右端の英字小（BASE 等・任意）
        - item-rows: 4〜5          # 内訳行。横罫のみ・縦罫なし
            - item-name:           # 項目名（太字）
            - item-desc:           # 一言説明（グレー小）
            - item-amount:         # 金額（右揃え）
        - total-row:               # 最下行のみ淡アクセント地
            - total-label
            - total-amount:        # 太字・内訳行より大きめ
    - operator:                    # 中間余白の垂直中央に円形＋を1個
    - options-rail:                # 右 約30%。枠を持たないリスト
        - rail-head:               # 見出し（小・太字）
        - option-rows: 5〜6        # 細横罫で区切る
            - plus-mark:           # 行頭の小さな＋記号
            - option-name
            - option-price:        # 右端に単価（+00,000円 形式・小さめ）
        - rail-foot:               # 下端の補足1行（グレー）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| base-box | 左62% | 「決まっている費用」のかたまり。枠で1つの商品として見せる |
| header-band | ボックス上辺 | 基本セットの名前。唯一の濃い塗り面 |
| item-row | ボックス内に縦積み | 内訳1件。横罫のみで区切り、格子を作らない |
| total-row | ボックス最下行 | 基本一式の合計。淡いアクセント地で答えを示す |
| operator | 中間余白の垂直中央 | 基本にオプションを足せる関係を式で示す |
| options-rail | 右30% | 「選べる費用」の一覧。枠を持たない軽いリストにして本体と重さを変える |
| plus-mark | オプション行の行頭 | 追加できることを行単位で示す小さな＋ |
| option-price | オプション行の右端 | 追加単価。+付きの金額表記で「上乗せ」であることを示す |
| rail-foot | レール下端 | 「必要な分だけ追加できます」等の補足1行 |

## Usage Guide（AIへの使い方）

プロンプト例：
「estimate-base-plus-options パターンで見積スライドを作成。基本一式は『デザイン 200,000円』『実装 250,000円』『ディレクション 50,000円』の合計500,000円。オプションは『下層ページ追加 +30,000円』『アニメーション +50,000円』『多言語対応 +80,000円』など5件」

注意点：
- 内訳行とオプション行は独立に伸縮できる（内訳3〜6行・オプション3〜7行）。行数を変えても両ゾーンの垂直センタリングは保つ
- 塗りはヘッダー帯（濃）と合計行（淡）の2箇所だけ。内訳行・オプション行に地色を付けない
- 合計行の金額は基本一式のみの合計。オプションは含めない（含めた総額を見せたいときは estimate-formula-sum を使う）
- オプションの単価は +00,000円 の形式で統一し、基本側の金額より一回り小さくする
- オプションが2件以下ならこのパターンは大げさ。本体だけの estimate-total-side-panel か price-total-highlight を検討する
