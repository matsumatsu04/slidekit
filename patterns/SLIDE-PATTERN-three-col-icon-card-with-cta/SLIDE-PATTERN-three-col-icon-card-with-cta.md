## Overview

**パターン名：** three-col-icon-card-with-cta
**概要：** 淡い地の等高カード3枚（小さなアイコン→英字ラベル→見出し→本文→例：）の下に、全幅のCTA帯（アクセント塗り・白文字・角丸11px・高さ64px）を置く3列カード。塗りはCTA帯だけで、カードは3枚とも淡い地

## Structure（構造）

コンテンツエリア（左右余白48px）に、上段の3等分カード（等高288px・gap 16px・角丸11px・`--sk-soft` 地）と、下段の全幅CTA帯（高さ64px・角丸11px・アクセント塗り・白文字）を縦に積む（間隔24px）。カードの中身は左ぞろえ・上ぞろえで「小さなアイコン（20px・白の丸地40px）」「英字ラベル（KICKER）」「見出し（18px・太字）」「本文（16px・2〜3行）」「例：の注記」の順。CTA帯は左に誘導文（18px・太字）、右に1.5pxの白枠だけのボタン風ラベル。カード群＋帯の束を本文エリアの上下中央に置く。塗りはCTA帯の1つだけで、カードは3枚とも塗らない。

    structure:
      layout: three-equal-columns + full-width-band
      cards:
        equal_height: true (288px)
        gap: 16
        background: soft (all 3, no fill)
      card:
        order:
          - icon (20px, in a small white circle)
          - kicker (english label + japanese supplement)
          - heading (18px, bold)
          - body (16px, 2-3 lines)
          - note ("例：" 11.5px)
      band:
        margin_top: 24
        height: 64
        fill: accent (the only fill on this slide), white text
        left: message (18px, bold)
        right: outlined button-like label (1.5px white border)

## Elements（各要素の役割）

| アイコン | 各カード左上（40pxの白い丸地に20px） | 項目を一目で識別させる小さな目印。主張させない |
| 英字ラベル（KICKER） | アイコン下 | `Consult ／ 相談` のように英字＋日本語補足で項目の分類を示す。アクセント色 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-col-icon-card-with-ctaのレイアウトで、[サービス]の3つの[特徴/進め方]（[項目1]・[項目2]・[項目3]）を並べ、下のCTA帯で[相談/申込]へ誘導してください。各カードは英字ラベル・見出し・本文2行・「例：」の順で書き、帯には誘導文とボタン文言を入れてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りはCTA帯だけ。カードは3枚とも `--sk-soft` 地のままにし、中央を塗らない（帯と塗りが2つになる）
- ボタン風ラベルは白枠のまま塗らない。文言は「詳細はこちら」より「個別相談を予約する」のように行動をそのまま書く
- 誘導文は1行（24文字以内）。帯は高さ64px固定なので、補足は帯に入れず本文かカードの「例：」へ回す
- 本文はカード幅（1行13字前後）で2〜3行に収める。入らないときは文字を小さくせず、文言を短くする
- CTAを持たない3列カードは three-column-icon-card、まとめ＋CTAの締めスライドは next-step-cta-band を使う
