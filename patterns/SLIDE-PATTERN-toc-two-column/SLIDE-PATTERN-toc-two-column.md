# SLIDE-PATTERN-toc-two-column

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
目次は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・セクションと同じ扱い）。

## Overview
**パターン名：** toc-two-column
**概要：** 左カラムに小さな英字ラベル「contents」、右カラムに「2桁の章番号｜細い縦罫線｜項目名」の行を縦に並べる目次。全体を上下中央に置き、塗りは使わない。
**適したシーン：** 章が3〜6個の標準的なデッキの目次。表紙の直後に置いて、資料の流れを一目で示す。

## Structure（構造）
```yaml
layout: toc-two-column
area: 全高（上下中央）
left_column:
  label: "contents"          # 15px / 700 / 字間 .3em / アクセント色。left:72px・垂直中央
right_column:
  left: 476px
  items: 3〜6行（gap 32px・行高 28px・垂直中央）
  item:
    - number: 2桁ゼロ埋め   # 24px / 700 / アクセント色。幅 48px
    - vline: 1px × 22px      # var(--sk-line)。左右余白 12px / 20px
    - title: 項目名          # 16px / 400 / 字間 .2em / インク色。1行（折り返さない）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| contents ラベル | 左カラム・垂直中央 | 目次であることを示す小さな英字ラベル（小文字・字間広め） |
| 章番号 | 各行の左 | 2桁ゼロ埋めの番号。このスライドで唯一のアクセント色の主役 |
| 縦罫線 | 番号と項目名の間 | 1px の細い罫線（`--sk-line`）。番号と項目名を区切る |
| 項目名 | 罫線の右 | 章タイトル。16px・字間 .2em で1行に収める |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-toc-two-column を使って目次を1枚生成してください。
【項目】
01 人が全部つくる制作で詰まりやすい工程
02 AIに任せる工程と、人が決める工程
03 試作から段階的に現場へ入れる手順
```
### 注意点
- 項目は3〜6個。7個以上は行間が詰まるので、章を束ねるか toc-section-cards 等を検討する
- 項目名は1行（全角18文字程度）に収める。長い場合は言い切りに削る（文字を小さくしない）
- 項目数が減っても右カラムは上下中央のまま（上に張り付けない）
- ページ番号（p.n）は置かない。必要なら項目名の末尾に添えず、ビルダーのフッターに任せる
- 塗りは使わない。アクセント色は番号とラベルだけ（縦罫線は `--sk-line`）

## v2 での描き直し（2026-09-02）
- 旧「2カラム×3行・最大8項目・ページ番号付き」から、参考デッキ（AI PLAY GUILD）の「左ラベル＋右リスト」構成に描き直した
- 文字の組みを v2 の表に合わせた（ラベル 15px/.3em、番号 24px/700、項目名 16px/.2em、`palt`・`line-break:strict`・インク色）
- 罫線を下線から「番号と項目名の間の1px縦罫線（`--sk-line`）」に変え、塗り・下線・ページ番号を無くした
