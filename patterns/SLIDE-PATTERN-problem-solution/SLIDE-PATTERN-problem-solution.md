# SLIDE-PATTERN-problem-solution

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** problem-solution
**概要：** 「課題」を左の淡い地パネルに、「解決策」を右のアクセント塗りパネル（白文字）に示し、中央のSVG三角矢印でつなぐ2カラム。番号（01〜）＋本文の行を細罫線で区切り、同じ番号で課題と解決策の対応関係を伝える。
**適したシーン：** ソリューション提案・製品導入提案・課題解決の説明・プロジェクト計画の提示

## Elements（各要素の役割）

| 要素 | 役割 | 推奨文字数 |
|------|------|-----------|
| KICKER | `PROBLEM ／ 補足`・`SOLUTION ／ 補足`。左はアクセント色、右（塗り）は白 | 10〜16文字 |
| 見出し | 「課題」「解決策」。パネルの役割を1語で示す（18px・700） | 固定 |
| 番号 | `01`〜`03`。左右で同じ番号が対応する（16px・700） | 2桁 |
| 本文 | 課題は問題提起、解決策は打ち手を言い切る（16px） | 1項目 18〜36文字（2行まで） |
| 細罫線 | 各行の上。見出しと行、行と行を区切る | 固定 |
| 中央矢印 | 課題から解決策への流れ。SVGの三角（幅12px）だけ | 固定 |
| 注記 | 「例：〜」で具体を1行添える（11.5px） | 20〜30文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.mdのデザインシステムと、以下のSLIDE-PATTERN-problem-solutionパターンを使って
スライドを1枚生成してください。

【スライドタイトル】課題と解決策の整理

【課題（左・淡い地）】
- KICKER: PROBLEM ／ いま起きていること
- 01 顧客の情報が複数の台帳に分かれ、横断して見られない
- 02 営業と制作で優先順位がずれ、手戻りが出る
- 03 月次の報告づくりに数日かかり、判断が遅れる
- 注記: 例：同じ問い合わせが営業と制作で別々に記録されている

【解決策（右・アクセント塗り）】
- KICKER: SOLUTION ／ こう変える
- 01 台帳を1つに統合し、全員が同じ画面を見る
- 02 週1回の合同確認と共有ボードで順位を合わせる
- 03 報告を自動生成に切り替え、当日中に判断する
- 注記: 例：記録は1か所に寄せ、更新は担当者がその日のうちに行う
```

### 注意点
- 課題と解決策は同じ番号で対応関係を示す。項目数は左右で必ず揃える（推奨3項目）
- 本文は2行まで。入らないときは文字を小さくせず、言い切りに削る
- 課題は「〜が分かれている」「〜に時間がかかる」など問題提起、解決策は「〜に統合する」「〜に切り替える」など打ち手の表現に統一する
- 塗りは右パネルの1つだけ。番号を丸バッジにしない。矢印はSVGの三角だけ（文字の「▶」「→」を使わない）
- 左右のパネルは等高（flex stretch）で本文エリアを埋める。項目が少なくても文字を大きくして埋めない

## v2 での描き直し（2026-09-02）
- 帯ラベル＋枠線カラム＋文字の「▶」を、淡い地（課題）とアクセント塗り（解決策・白文字）の等高パネル＋SVG三角矢印に変えた（塗りは1枚に1つ）
- 番号の丸バッジをやめ、番号（16px・700）＋本文16pxの行を細罫線（左 `--sk-line`・右は白の半透明線）で区切る型にし、KICKER と注記を足した
- 文字を v2 の表に揃えた（インク色・palt・禁則・太さ400/700のみ）。角丸12px・左右余白48px
