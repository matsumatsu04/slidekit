# SLIDE-PATTERN-numbered-list-with-body

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** numbered-list-with-body
**概要：** 番号（24px・細め・アクセント色）の右に「見出し→本文→例：」を積んだ行を、細い罫線で区切って縦に3つ並べるリスト。バッジや塗りを使わず、番号と罫線だけで整える
**適したシーン：** 特徴・メリット・要素の列挙、優先度付きリスト、段階的な説明（各項目に1文の説明と具体例を添えたいとき）

## Structure（構造）

コンテンツエリア（左右余白48px）の全幅に、2列（番号64px｜本文＝残り）の行を縦に3つ積む。行は上辺・下辺の細い罫線で区切り、行の中は上ぞろえで番号と見出しの1行目の高さを合わせる。本文列は「見出し（18px・太字）→本文（16px・1行）→例：（11.5px・薄く）」の順。塗りや帯は使わず、行の束は本文エリアの上下中央に置く。

    structure:
      layout: stacked-rows
      row_count: 3
      columns: [number 64px, content flex]
      rows:
        separator: thin rule (top of list + bottom of each row)
        spacing: equal (padding 20px top/bottom)
      row:
        left: number (24px, regular, accent)
        right:
          - heading (18px, bold)
          - body (16px, 1 line)
          - note ("例：" 11.5px, muted)
      fill: none

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 番号 | 各行の左端（24px・細め・アクセント色） | 項目の順序。丸や角丸のバッジで囲まない・太くしない |
| 見出し | 番号の右・1行目（18px・太字） | 項目のキーワード（8〜10字） |
| 本文 | 見出しの下（16px・1行） | 見出しを1文で言い切る説明 |
| 注記（例：） | 本文の下（11.5px・薄く） | 具体例を1行で添える |
| 細罫線 | リストの上辺と各行の下辺 | 行の区切り。帯や塗りで区切らない |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-numbered-list-with-bodyのレイアウトで、[項目1]・[項目2]・[項目3]を並べてください。各行は見出し・本文1文・「例：」の順で書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 項目は3つが基本。本文が1行（40字以内）なら4項目まで入るが、4つ以上は numbered-row-full-width や four-card-2x2 も検討する
- 本文が2行になる項目があるなら3項目までにする（文字を小さくして詰めない）
- 番号は 01/02/03 の2桁ゼロ埋め。バッジ・丸地・帯は付けない
- 「今ここ」を示したい項目は、その行の番号と見出しをアクセント色にする程度にとどめる（行を塗らない）

## v2 での描き直し（2026-09-02）

- 番号のグレー塗り丸バッジ（48px）をやめ、24px・400・アクセント色の素の数字にした（塗りなし）
