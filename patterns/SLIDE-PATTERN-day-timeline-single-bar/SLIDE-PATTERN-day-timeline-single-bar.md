# SLIDE-PATTERN-day-timeline-single-bar

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** day-timeline-single-bar
**概要：** 1日の流れを、高さ40px・淡い地・角丸6pxの横バー1本で示す。バーは時間の長さに比例した幅の時間帯（3〜5区分）に分け、区切りは白1.5pxの縦罫線。バーの上に各時間帯の開始時刻（KICKER・10px）と右端に終了時刻、下に各時間帯の見出し（16px太字）＋1行の説明（14px・muted）を、開始時刻と左をそろえて置く。塗りは「今ここ」か要になる時間帯1つだけ。最下段に注記を1行添える。
**適したシーン：** 1日の勤務時間・稼働時間帯の説明、コアタイム制度の案内、営業時間・対応時間帯の提示

## Structure（構造）

コンテンツエリア（左右48px）の上下中央に「時刻の行 → バー → 見出しの行 → 注記」を縦に積む。3段とも同じ flex 比率（＝時間の長さ）で区分を並べるので、時刻・区切り・見出しの x 座標が揃う。

    structure:
      layout: day-timeline-single-bar
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      ratio: "flex = 時間の長さ（1h = 2）"   # 3段で同じ値を使う
      times:                        # 上段
        style: kicker               # 10px / 700 / .18em / muted
        position: 各区分の左端＝開始時刻。終了時刻は右端に絶対配置
      bar:                          # 中段
        height: 40px
        radius: 6px
        background: soft
        divider: 1.5px white vertical（幅に影響しない擬似要素）
        inside: 所要時間（11.5px・muted。塗り区分は白）
        surfaces:
          default: soft
          now: accent_fill          # 「今ここ」の1区分だけ塗り
      labels:                       # 下段
        align: left（開始時刻と揃える）
        elements:
          - heading                 # 16px / 700（4文字以内）
          - body: 1 line            # 14px / 400 / muted（1h の区分は5文字以内）
      note:
        style: "例：〜"             # 11.5px / muted

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 開始時刻（KICKER） | バーの上・各区分の左端 | `09:00` 形式。終了時刻だけ右端に置く |
| バー | 中央の横長バー1本（40px） | 1日の時間配分。区分の幅は時間の長さに比例 |
| 区切り | バー内の白1.5pxの縦罫線 | 区分の境界（幅に影響しない） |
| 所要時間 | 各区分の中央（11.5px） | `1h` `1.5h` など。塗り区分では白文字 |
| 見出し | バーの下（16px・700） | 時間帯の名前（準備・集中作業 等） |
| 説明 | 見出しの下（14px・muted） | 何をする時間かを1行で |
| 注記 | 最下段 | 「例：〜」で運用ルールや塗りの意味を1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-day-timeline-single-barのレイアウトで、[09:00〜17:30]を[準備1h・集中作業3h・休憩1h・打合せ2h・振り返り1.5h]で区切ってください。集中作業を「今ここ」として塗り、各区分の下に見出し（4文字以内）と説明1行を書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは1区分だけ。「今ここ」が無ければ、要になる時間帯（コアタイム等）を1つ選ぶ。全部を濃淡で塗り分けない
- 区分は3〜5個。多いと1h の区分に見出しが入らない
- 区分の幅は時間の長さに比例させる（見た目の均等割りにしない）。3段の flex 値を必ず同じにする
- 1h（幅約100px）の区分は見出し4文字・説明5文字以内。入らなければ文言を短くする（文字を小さくしない）
- 旧版の「バーの上に区分名・下に時刻・濃淡2種の塗り分け・64pxのバー」は廃止

## v2 での描き直し（2026-09-03）
- 64pxの枠付きバーと濃淡2種の塗り分けを、40px・淡い地・角丸6pxのバー1本＋白1.5pxの区切り＋「今ここ」1区分だけの塗りに変えた
- 時刻を上段の KICKER（開始時刻・終了時刻）に、区分名を下段の「見出し16px太字＋説明14px」に置き換え、3段を同じ flex 比率で左ぞろえに揃えた
- 左右余白を64pxから48pxにし、最下段の補足を注記（例：〜・11.5px）の型にした
