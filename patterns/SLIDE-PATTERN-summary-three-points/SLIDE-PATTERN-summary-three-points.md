# SLIDE-PATTERN-summary-three-points

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリア・ページ番号・装飾はデザインテーマ側の Frame で定義されるため、このファイルには含みません。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** summary-three-points
**概要：** 3つの要点を、淡いティント地（`--sk-soft`）のカード3枚に「KICKER→見出し→細い罫線→本文」の型で書き、その下にアクセント色で塗った結論ピル（1文）を置く。アクセント色の塗りはピルだけ。
**適したシーン：** プレゼンのまとめ・要点の整理・議論の結論提示・次のアクションへの導入

## Elements（各要素の役割）

| 要素 | 役割 | 推奨文字数 |
|------|------|-----------|
| KICKER | 「POINT 1 ／ 前提」のように番号と補足を英字＋短語で示す。見出しの上に小さく置く | 10〜14文字 |
| 見出し | 要点を言い切りで書く（標語調にしない） | 10〜13文字（1行） |
| 罫線 | 見出しと本文の区切り。`--sk-line` の1px | 固定 |
| 本文 | 見出しの根拠や具体を2〜3行で | 26〜40文字 |
| 結論ピル | 3点を束ねる1文。このスライドで唯一のアクセント色の塗り | 12〜20文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE-PATTERN-summary-three-points を使ってまとめを1枚生成してください。

【スライドタイトル】本日のまとめ
【ポイント 1】KICKER: POINT 1 ／ 前提 / 見出し: 判断の基準を先に決める / 本文: AIに任せる範囲と、人が最後に決める範囲を、着手前に線引きしておく。
【ポイント 2】KICKER: POINT 2 ／ 進め方 / 見出し: 小さく試して段階で広げる / 本文: ページ単位の試作から始め、崩れなければ次の工程へ広げていく。
【ポイント 3】KICKER: POINT 3 ／ 運用 / 見出し: 確認の手順を型にする / 本文: 見る順番と確認項目を決めておけば、誰が見ても同じ品質で通せる。
【結論ピル】線引きしてから、小さく試す
```

### 注意点
- 3つのポイントは重要度順または論理的な順序で並べる
- 見出しは1行（全角13文字程度）に収める。本文は3行まで。入らなければ文字を小さくせず、言い切りに削る
- 塗りはピルだけ。カードにアクセント色の塗りや枠線を足さない（強調は1枚に1つ）
- ピルは1文。長くなるなら本文に戻す（ピルを2段にしない）
- 2点・4点になる場合もカードは等幅・等高のまま横に並べ、上下中央に置く。5点以上は別パターンを検討する

## v2 での描き直し（2026-09-02）
- 縦積みのチェック付きリスト（✓アイコン＋見出し＋補足）を、`--sk-soft` 地のカード3枚横並び＋結論ピルの構成に描き直した
- カードの中身を v2 の型（KICKER→見出し→細い罫線→本文）にし、文字を 16px 基準・`palt`・インク色にそろえた
- アクセント色の塗りを結論ピル1つに限定し、絵文字のチェックマークとカード枠線を無くした
