## Overview

**パターン名：** circle-node-step-flow
**概要：** 番号入りの白い円ノード5つを1pxの幹線でつなぐ横フロー。ノードの下に KICKER「STEP n」・見出し16px・説明16px・注記を縦に置く。「今ここ」のノードだけアクセント塗り（白数字）、最後のノードだけ 1.5px のアクセント枠線。
**適したシーン：** プロセス・業務フローの段階説明、プロジェクト工程表、カスタマージャーニーの流れ、実装ステップの概要

## Structure（構造）

コンテンツエリアの上下中央に、等幅の列5つを横に並べる。各列は上から「円ノード（56px・白・1.5px 罫線色の枠・番号はアクセント色）→ KICKER → 見出し → 説明 → 注記」を中央ぞろえで積む。幹線（1px・罫線色）はノードの中心の高さに引き、端点は最初と最後のノードの中心で止める（各列の左半分・右半分に分けて引く実装。先頭列の左半分・末尾列の右半分は引かない）。「今ここ」の列だけノードを塗り、最後の列だけノードをアクセント枠線＋見出しをアクセント色にする。

    structure:
      layout: horizontal-node-flow
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      columns:
        count: 5                    # 標準。4列でも同じCSSで動く（幹線は列ごとに半分ずつ引く）
        equal_width: true
        align: center               # ノード・文字とも中央ぞろえ
        column:
          elements:
            - node: "01"            # 56px の白丸・1.5px 罫線色の枠・番号20px/400/アクセント色
            - kicker: "STEP n ／ 補足"   # 10px / 700 / .18em / アクセント色
            - heading               # 16px / 700
            - body: 2 lines         # 16px / 400 / 行間1.8（1行8文字以内）
            - note: "例：〜"        # 11.5px / muted
        surfaces:
          default: outline-line     # 白丸＋罫線色の枠
          current: accent_fill      # 「今ここ」の1つだけ塗り（白数字）。塗りは1枚に1つ
          last: outline-accent      # 最後だけ 1.5px のアクセント枠線＋見出しをアクセント色
      trunk:
        type: horizontal-line
        width: 1px
        color: line                 # var(--sk-line)。矢印なし
        from: first node center
        to: last node center

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 円ノード | 各列の上端・中央 | 工程の番号（`01`〜`05`）。白丸に罫線色の枠、番号はアクセント色 |
| 幹線 | ノードの中心を通る水平線 | 順序を示す1pxの線。端点は最初と最後のノードの中心で止める |
| KICKER | ノードの下 | `STEP 1`〜`STEP 5`。補足を添えるときは `STEP 3 ／ 今ここ` の形 |
| 見出し | KICKER の下 | その工程の主内容（2〜6文字の体言） |
| 説明 | 見出しの下 | 工程の説明を2行（1行8文字以内・改行位置を指定） |
| 注記 | 列の最下 | 「例：〜」で目安を1行添える |
| 塗りノード | 5つのうち1つ | 「今ここ」「主役」の工程を示す。1枚に1つだけ |
| アクセント枠のノード | 最後の1つ | 「運用」「公開」など最終・結果の工程を塗らずに区別する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-circle-node-step-flowのレイアウトで、導入の5工程（棚卸し→試作→確認必須→限定導入→運用）を説明してください。STEP 3 を「今ここ」として塗り、STEP 5 は最終工程としてアクセント枠線にしてください。各列は KICKER・見出し・説明2行（1行8文字以内）・「例：〜」の順で書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは1つだけ。「今ここ」が無い工程説明なら、主役の1つ（要になる工程）を塗る
- 最後のノードは塗らずアクセント枠線。最終工程が無い（途中で終わる）場合は既定の白丸でよい
- 説明は1行8文字以内×2行。入らなければ文言を短くする（文字を小さくしない）
- 5列が標準。4列でも同じCSSで幹線の端点はノード中心に収まる。6列以上は文字が入らないので枚数を分ける
- 旧版の「円の中にステップ名を入れる大きな円（100px）＋リード文」は廃止。円は番号だけにし、文字は円の下に出す

## v2 での描き直し（2026-09-02）
- 円の中にステップ名を入れる大きな円（100px・2px枠）を廃し、番号だけの白丸（56px・1.5px 罫線色の枠・番号はアクセント色）にして、文字は円の下に KICKER／見出し16px／説明16px／注記の型で出した
- 幹線を2pxの灰色から1pxの罫線色に変え、端点を最初と最後のノードの中心で止めた（列ごとに左右半分ずつ引く実装）
- 塗りを「ゴール」から「今ここ」の1つに変え（白数字）、最後のノードは塗らず 1.5px のアクセント枠線＋見出しをアクセント色にした
