# SLIDE-PATTERN-case-study-process-kpi

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** case-study-process-kpi
**概要：** 左1/3の白地に案件名（特大太字2行）・発注元ラベル・リード文4行・参照リンク風の1行・正方形アイコン枠の小バッジ行を積み、右2/3を画像プレースホルダにする。右2/3の下端に白地の横断バンドを敷き、「PROCESS」小見出し＋菱形ミニバッジ4個を点線でつないだ縮小プロセス＋右端の濃色反転ボックス（特大数値＋成果ラベル）を並べる。
**適したシーン：** 事例・実績の1件深掘り。ビジュアル（画像）を主役にしつつ、進め方と成果数値まで1枚に収めたい場面。

## Structure（構造）
- 左カラム（33%・白地・縦積み）
  - 発注元の小ラベル → 案件名（特大太字2行） → リード文4行 → 参照リンク風の小さな1行
  - 最下部に小バッジ行（正方形アイコン枠×4）
- 右カラム（67%・上下2段）
  - 上段: 画像プレースホルダ（残り全高）
  - 下段: 横断バンド（白地・上辺に細罫）
    - 英字小見出し → 縮小プロセス（菱形ミニバッジ×4を点線連結・各下に工程名1行） → 濃色反転ボックス（特大数値＋単位＋成果ラベル）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 発注元ラベル | 左カラム上端 | 業種・企業種別などの小さな属性表示 |
| 案件名 | ラベルの下 | この事例の主役となる特大太字タイトル |
| リード文 | 案件名の下 | 背景・提案内容・進め方の要点を4行で記述 |
| 参照リンク行 | リード文の下 | 実物・詳細資料への参照を示す小さな1行 |
| 小バッジ行 | 左カラム最下部 | 提供範囲・チャネルをアイコン枠4個で示す |
| 画像プレースホルダ | 右カラム上段 | 実績のビジュアル（実デッキで画像に差し替え） |
| 縮小プロセス | バンド中央 | 菱形ミニバッジ＋点線で進め方を圧縮再掲 |
| 成果ボックス | バンド右端 | アクセント地・白抜きの特大数値で成果を示す |

## Usage Guide（AIへの使い方）
- 縮小プロセスの意匠（菱形バッジ＋点線）は proposal-process-checkpoints と揃える。工程数は3〜5個
- 点線はミニバッジ中心で始端・終端を止める
- 成果数値は1個だけに絞る（複数の数値を並べたい場合は KPI 系パターンを使う）
- 画像プレースホルダには実デッキで実績画像を差し替える（画像が無い場合は薄グレー地のまま使わない）
