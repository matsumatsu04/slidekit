# SLIDE-PATTERN-section-band-middle

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い）。
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。

## Overview
**パターン名：** section-band-middle
**概要：** 白地のスライドを「余白／帯／余白」の3ブロックに分け、垂直中央に全幅120pxのアクセント塗り帯を置く中扉。帯の中は左80pxから「英字KICKER『SECTION』（10px・白82%）＋章番号（32px・700・白）｜白35%の縦罫線｜章タイトル（24px・700・白）」を横並びで組む。塗りは帯の1つだけで、帯の外は白のまま残す（余白のコントラストがこのパターンの効果の本体）。
**適したシーン：** プレゼンの章区切り、セクション導入。画像を使わず、デッキのパレットの主色をそのまま見せたい章区切り。

## Structure（構造）
```yaml
layout: section-band-middle          # スライド全体を縦3分割（タイトルエリアなし）
top-spacer:
  flex: 1
band:                                # 垂直中央・全幅・アクセント塗り（グレー版のフォールバックは #555555）
  height: 120px
  padding: "0 80px"
  display: flex / align-items: center
  num-block:                         # 縦積み・左ぞろえ
    kicker: "SECTION"                # 10px / 700 / 字間 .2em / 大文字 / 行間 1 / rgba(255,255,255,.82)
    number: "03"                     # 32px / 700 / 字間 .04em / 行間 1 / #FFFFFF。上に 10px
  vrule:  1px × 56px                 # rgba(255,255,255,.35)。左右 28px。唯一の装飾
  title:  章タイトル                  # 24px / 700 / 字間 .06em / 行間 1.35 / #FFFFFF。1行が望ましい
bottom-spacer:
  flex: 1
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 上下の余白 | 帯の上・下 | 帯を浮き立たせるための静かな白。ここには何も置かない |
| アクセント色帯 | 垂直中央・全幅 | 章の切り替わりを示す主役。このスライドで唯一の塗り |
| KICKER | 帯の中・左端 | `SECTION` の英字ラベル。章番号の上に小さく置く（白82%） |
| 章番号 | KICKERの下 | 「01」「02」などのゼロ埋め2桁。32px・700・白 |
| 白縦罫線 | 番号と章タイトルの間 | 1px×56px・白35%。番号とタイトルの領域を分ける唯一の装飾 |
| 章タイトル | 縦罫線の右 | この章の主題。24px・700・白・帯の高さに収まる1行 |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-band-middle を使って中扉を1枚生成してください。
【KICKER】SECTION
【章番号】03
【章タイトル】問い合わせから受注までの流れ
```
### 注意点
- 帯の高さ（120px）は変えず、上下の余白（`flex:1` で均等）とのバランスを保つ
- 章番号は「01」「02」のようなゼロ埋め2桁。章番号だけを大きくしない（大きさの主役は章タイトル）
- 章タイトルは24pxの1行に収める（全角22文字程度が上限）。入らなければ文言を短くする（文字を小さくしない・2行にしない）
- 帯以外の面積は白のまま保ち、装飾を足さない。帯の中の装飾も縦罫線1本だけにする
- 文字はすべて白（塗り帯の上に #333 系を載せない）。KICKER は半透明白で階調を付ける
- 全面を塗って章を強く区切りたいときは section-divider、画像で世界観を持たせたいときは section-geo-texture-left / section-soft-3d-number-row へ

## v2 での描き直し（2026-09-04）
- 帯の中の章番号を 40px・700 の単独表示から「英字KICKER『SECTION』（10px・字間 .2em・白82%）＋章番号 32px・700」の2段組に組み替えた
- 章タイトルを 28px から 24px/700・行間1.35 に落とし、番号とタイトルの間に 1px×56px の白35%縦罫線を1本だけ入れて領域を分けた
- 帯の高さ120px・左右80px・アクセント塗り1つの骨格は維持し、太さを 400/700 の2つに絞って中扉4種（P099・P106〜P108）で文字の組みを共通化した
