# SLIDE-PATTERN-checklist-two-column

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリア・ページ番号・装飾はデザインテーマ側の Frame で定義されるため、このファイルには含みません。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** checklist-two-column
**概要：** チェック項目を左右2列に分けて並べるチェックリスト。各列は「英字ラベル（列名）→項目×4」で、項目は「チェック記号（アクセント色1.5px枠の小さな四角・14px）＋本文16px」を1pxの細罫線で区切る。列の間に1pxの縦罫線（`--sk-line`）。先頭の1項目だけアクセント塗りの四角に白の✓を入れて「済み」を示す。それ以外にアクセント色の塗りは使わない。
**適したシーン：** 準備物・対応範囲・提供内容・確認事項の一覧。6〜8項目を「もれなく」見せたい場面

  items:

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER（列名） | 各列の最上 | `BEFORE ／ 着手前に`・`RELEASE ／ 公開前に` のように、列の切り口（時期・担当など）を英字＋補足で示す。アクセント色 |
| チェック記号 | 各項目の左 | 未了を示す空の四角（アクセント色1.5px枠）。番号バッジ・絵文字にしない |
| 済みの記号 | 先頭1項目 | アクセント塗りの四角＋白の✓。「済み」の見え方を1つだけ示す |
| 項目 | 記号の右 | やること・確認することを動詞で言い切る（16px・400・1行・12〜20文字） |
| 細罫線 | 項目の間 | 1px・`--sk-line` |
| 縦罫線 | 列の間 | 1px・`--sk-line`。2列の束と同じ高さ |
| 注記 | 2列の下 | 運用の一言（「例：〜」）。省略可 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE-PATTERN-checklist-two-column を使ってチェックリストを1枚生成してください。

【スライドタイトル】公開までのチェックリスト
【左列】KICKER: BEFORE ／ 着手前に
  1. 任せる範囲と確認する範囲を1枚に書く（済み）
  2. 確認項目（数字・固有名詞・リンク）を決める
  3. 試作するページを1つ選ぶ
  4. 確認する人と回数を決める
【右列】KICKER: RELEASE ／ 公開前に
  1. 数字と固有名詞を出典と突き合わせる
  2. リンク先を実際に開いて確かめる
  3. 表記ゆれを用語集で直す
  4. 承認者の確認を記録に残す
【注記】例：済んだ項目は □ を塗りの ✓ に変える。列は「時期」や「担当」で分ける
```

### 注意点
- 項目は6〜8個（各列3〜5）。5個以下なら summary-three-points や icon-left-text-list-detailed を検討
- 左右の項目数を揃える（片方だけ多いと縦罫線の下が空く）
- 項目は1行（20文字以内）。補足が要るなら項目を分けるか、注記に回す（文字を小さくして詰めない）
- 済みの✓は先頭1項目だけの見本。実際の進捗を示すときも塗りの✓は少数に留める（塗りが増えると強調が消える）
- 「含まれないもの」を並べる場合は ok-ng-comparison を使う

## v2 での描き直し（2026-09-02）
- 「22pxの枠＋✓の絵文字＋見出し14px＋補足11px」の2カラム×4行を、列ごとに KICKER（列名）→項目（14pxの四角＋16px）を細罫線で積む構成に変えた
- 列の間に1pxの縦罫線（`--sk-line`）を立て、先頭1項目だけアクセント塗りの四角＋白の✓（CSSで描く）で「済み」を示すようにした（それ以外は塗りなし）
- 文字をインク色・palt・禁則・太さ400/700に揃え、左右余白を48pxにし、プレースホルダを具体例（着手前 ／ 公開前）にした
