# SLIDE-PATTERN-sitemap-tree-3level

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** sitemap-tree-3level
**概要：** 最上段にトップページ1個、その下に第2階層5個、さらに下層を持つ第2階層の下に第3階層2〜3個を置く、上から下への3段サイトマップ。ノードは淡い地・角丸で、トップページだけアクセント塗り・白文字にする（塗りは1枚に1つ）。各段の左端に階層の英字ラベル（L1／L2／L3）を置き、接続線は1枚のSVGの直角線だけで、端点をノードの上辺・下辺の中心で止める。
**適したシーン：** Web制作の提案・納品資料でのサイト全体構造の説明、下層ページを含むサイト規模感の共有

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に 864×240px のステージを置き、ノードを絶対配置する。行の高さは48px固定、段の間は48px。各段の左端40px幅に階層KICKER（L1/L2/L3）を行の高さに合わせて縦中央に置く。接続線は1枚のSVGで引き、幹線は「最初の接続点の中心」から「最後の接続点の中心」まで。白い矩形で線を消さない。

    structure:
      layout: top-down-sitemap-tree
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      stage: 864x240               # ノードは絶対配置。行高48px・段間48px
      tier_kicker:
        width: 40px                 # 各段の左端。L1/L2/L3 の英字ラベル
      node_common:
        border_radius: "6-8px"
        height: 48px                # 固定（ページ名の長さで高さを変えない＝線の端点がずれない）
      level-1:
        nodes: 1 (width 200px, accent_fill, white text, bold)   # 塗りはここだけ
      level-2:
        nodes: 5 (width 144px, soft, gap 24px)
      level-3:
        nodes: 2-3 per branch (width 120px, soft, gap 8px)      # 下層を持つ第2階層の下だけに展開
      connector:
        type: right-angle lines only         # 縦の幹線 → 横の母線 → 縦の枝
        stroke: 1px var(--sk-line)
        endpoints: node edge centers         # 上辺・下辺の中心で止まる
      note: "例：〜"                          # ページ総数・展開の条件を1行添える
      constraint: total nodes <= 10 (1 + 5 + up to 5 in level-3)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 階層KICKER | 各段の左端 | `L1` `L2` `L3` で段の意味を示す |
| トップページノード | 最上段中央 | サイトの起点。アクセント塗り・白文字（1枚で塗るのはここだけ） |
| 第2階層ノード | 中段・5個 | 主要ページ（サービス・会社概要・お問い合わせなど）。淡い地 |
| 第3階層ノード | 下段・該当行のみ2〜3個 | 下層を持つ第2階層ページの配下ページ。淡い地・幅120px |
| 接続線 | 段の間 | 1pxの罫線色。縦横の直角線のみ。端点はノード辺の中心 |
| 注記 | ステージ下 | 全ページ数や展開ルールを1行で補足 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-sitemap-tree-3levelのレイアウトで、トップページの下に[第2階層5ページ]を置き、下層を持つページ（例：[サービス][採用情報]）の下に第3階層を2〜3個ずつ展開してください。塗りはトップページだけにし、各段の左に L1/L2/L3 のKICKERを置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- **ノード数は最大10個前後**（トップ1＋第2階層5＋第3階層は展開する行の分だけ）。超えるときは第3階層を展開するページを絞る
- **接続線は1pxの直角線のみ**。斜め線・曲線・矢印は使わない。線を太くしない
- 第3階層は「下層を持つ第2階層だけ」に付ける。全行に無理に展開しない
- ページ名は1行に収める（幅120〜144pxのノードで6〜7文字前後）。収まらない場合は文言を短くする（文字を縮小しない）
- 塗りはトップページだけ。第2階層を強調したいときも塗らず、KICKERの文言や注記で示す
