# SLIDE-PATTERN: cover-blob-side-left

このファイルはスライドのレイアウトパターン定義書です。表紙は共通見出し（`sk-head`）を付けない種類のスライドで、
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。
背景は `assets/covers/` の画像アセットで、この表紙の家族だけに認められた例外です（色ティントの対象外）。

## Overview
**パターン名：** cover-blob-side-left
**概要：** 鮮やかな有機的ブロブ（メタボール）が右2/3を占める白背景の画像を全面に敷き、絵柄が薄い左側に文字ブロックを置く。文字は「英字KICKER → タイトル2行 → 64pxの細い区切り線 → 補足1行」の順に縦に組み、スライドの上下中央にそろえる。ブロブが画面中央まで張り出すため、文字ブロックの幅は300pxに絞る。
**適したシーン：** SaaS・スタートアップ・採用系の、明るくフレンドリーなトーンの表紙。

## Structure（構造）
```yaml
layout: cover-blob-side-left
background:
  image: /assets/covers/cover-bg-organic-blobs.jpg
  fit: center / cover / no-repeat      # 差し替え・削除をしない（色ティント対象外）
text_block:                            # 左 80px から・width 300px・上下中央（top 50% + translateY(-50%)）
  kicker: 英字ラベル ／ 資料の種別       # 10px / 700 / 字間 .2em / 大文字 / var(--sk-ink)
  title:  タイトル                      # 40px / 700 / 字間 .06em / 行間 1.35 / 最大2行 / #1A1A1A
  rule:   区切り線                      # 幅 64px・高さ 1px・#AAAAAA（title から 28px 下）
  meta:   補足1行                       # 16px / 400 / 字間 .06em / #555555（社名 ／ 日付）
notes:
  - ブロブは x≈376px から始まるので、文字ブロックの右端（80+300=380px）を超えない
  - 5種のなかでタイトルが最も短くなる。長いタイトルはこのパターンを選ばない
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景画像 | 全面（`/assets/covers/cover-bg-organic-blobs.jpg`） | 右2/3にブロブ、左1/3が白の余白。そこに文字を置く |
| KICKER | 文字ブロックの先頭 | 英字ラベル＋資料の種別（例：`Recruiting ／ 採用資料`）。背景が明るい側なのでインク色 |
| タイトル | KICKER の下 | 資料タイトル。40px・700・最大2行（この幅では1行6文字前後） |
| 区切り線 | タイトルの下 | 幅64px・1px の細い線 |
| 補足1行 | 区切り線の下 | 社名・日付など（例：`Macminol ／ 2026.04 更新`）。16px |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-cover-blob-side-left を使って表紙を1枚生成してください。
【KICKER】Recruiting ／ 採用資料
【タイトル】採用のための／会社紹介資料
【補足】Macminol ／ 2026.04 更新
```
### 注意点
- **この背景は文字の置ける幅が5種で最も狭い。** タイトルは1行6文字前後・最大2行（合計12文字程度）に収める。入らなければ cover-curve-shape-left か cover-geo-texture-left に替える
- **サブタイトルは置かない**（2026-08-31 代表決定）。副題を出したいときは KICKER の後半に回す
- 補足は1行だけ。11.5px の注記は使わない
- ブロブの色違い素材を作ればブランドカラー版にできるが、素材は `assets/covers/` に既にあるものだけを参照する
- 背景画像レイヤー（`slides[].bg`）は OFF にする（表紙が自前の背景画像を持つため）
- 同じ家族（画像背景の表紙）は cover-geo-texture-left / cover-art-brush-left / cover-soft-3d-left / cover-curve-shape-left。文字の組みは5種で共通なので、背景の雰囲気だけで選ぶ

## v2 での描き直し（2026-09-04）
- タイトルを42pxから40px/700・行間1.35・2行までに統一し、上に英字KICKER（10px・字間.2em・インク色）、下に幅64pxの細い区切り線を足した
- 左上の会社名と左下の更新日を、タイトル直下の16pxの補足1行にまとめた（三隅に散っていた文字を1ブロックに集約）
- 文字ブロックの起点を左64px→80pxに寄せ、上46%から上下中央にそろえた（背景画像はそのまま）
