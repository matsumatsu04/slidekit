## Overview

**パターン名：** vertical-step-three-col
**概要：** 淡い地の等高カード3列に、番号付きのステップ行（番号24px・アクセント色＋テキスト16px）を縦に積む工程レイアウト。各列は KICKER「PHASE n ／ 補足」・見出し・細い罫線・ステップ行・注記の型。中央の列だけアクセント塗り。
**適したシーン：** 長いプロセスフロー説明、段階的な工程表、複数ステップの詳細解説、実装工程の詳細ガイド

## Structure（構造）

コンテンツエリアの上下中央に、等幅・等高（320px）のカード3枚を横に並べる（gap 16px）。各カードは「KICKER → 見出し18px → 細い罫線 → ステップ行×3 → 注記」を上ぞろえで積み、注記だけカード下端に寄せる。ステップ行は左に番号（24px・400・アクセント色・幅32px）、右にテキスト（16px・行高28px）。中央のカードだけアクセント塗り（白文字）にする。

    structure:
      layout: three-col-vertical-steps
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        gap: 16px
        height: 320px               # 3枚は等高（本文エリアを埋める）
      cards:
        count: 3
        layout: horizontal-equal-width
        border_radius: 12px
        padding: "24px 20px 20px"
        card:
          elements:
            - kicker: "PHASE n ／ 補足"   # 10px / 700 / .18em。塗りカード内は白
            - heading                     # 18px / 700
            - rule                        # 1px（塗りカード内は白35%）
            - steps:                      # 縦に3行・行間 12px
                number: "01"              # 24px / 400 / アクセント色（塗りカード内は白）・幅32px
                text: 1 line              # 16px / 400 / 行高28px（11文字以内）
            - note: "例：〜"              # 11.5px / muted。カード下端に寄せる
        surfaces:
          default: soft                   # 淡い地 + 1px 罫線
          center: accent_fill             # 中央の1枚だけ塗り（白文字）。塗りは1枚に1つ

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各カード左上 | `PHASE 1 ／ 準備` のように段階の番号＋補足。塗りカード内は白 |
| 見出し | KICKER の下 | その段階でやることを体言で（8文字前後） |
| 細い罫線 | 見出しの下 | 見出しとステップ行の区切り（塗りカード内は白35%） |
| 番号 | 各ステップ行の左 | `01`〜`03`。24px・細め・アクセント色（塗りカード内は白） |
| ステップ文 | 番号の右 | そのステップでやることを1行で（11文字以内） |
| 注記 | カード最下 | 「例：〜」で所要・目安を1行添える |
| 塗りカード | 中央の1枚 | 主役の段階・「今ここ」。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-vertical-step-three-colのレイアウトで、導入の3段階（準備→構築→運用）をそれぞれ3ステップに分けて説明してください。中央の PHASE 2 を「今ここ」として塗り、各カードは KICKER・見出し・ステップ行3つ（1行11文字以内）・「例：〜」の順で書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは中央の1枚だけ。主役が中央でない場合はその1枚を塗り、中央は淡い地に戻す（2枚以上塗らない）
- ステップは各列3行が標準。4行にするときはカード高さを360pxにする。5行以上は枚数を分ける
- ステップ文は1行11文字以内。入らなければ文言を短くする（文字を小さくしない）
- 列の数は3固定。2段階は比較系、4段階以上は horizontal-timeline-cards か circle-node-step-flow を使う
- 旧版の「バッジ列・ステップ名列・詳細列の3列×5行（点線連結・バッジのグラデーション）」は廃止
