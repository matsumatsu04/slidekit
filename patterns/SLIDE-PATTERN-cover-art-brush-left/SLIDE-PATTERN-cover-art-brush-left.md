# SLIDE-PATTERN: cover-art-brush-left

このファイルはスライドのレイアウトパターン定義書です。表紙は共通見出し（`sk-head`）を付けない種類のスライドで、
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。
背景は `assets/covers/` の画像アセットで、この表紙の家族だけに認められた例外です（色ティントの対象外）。

## Overview
**パターン名：** cover-art-brush-left
**概要：** 水彩・クレヨンの手描きモチーフを右半分に散らした背景画像を全面に敷き、絵柄が薄い左側に文字ブロックを置く。文字は「英字KICKER → タイトル2行 → 64pxの細い区切り線 → 補足1行」の順に縦に組み、スライドの上下中央にそろえる。モチーフが中央近くまで来るため、文字ブロックの幅は画像背景の表紙5種で最も狭い340px。
**適したシーン：** クリエイティブ・デザイン・イベント系資料の表紙。賑やかな絵柄に、静かな文字組みを当てて釣り合わせる。

## Structure（構造）
```yaml
layout: cover-art-brush-left
background:
  image: /assets/covers/cover-bg-handdrawn-art.jpg
  fit: center / cover / no-repeat      # 差し替え・削除をしない（色ティント対象外）
text_block:                            # 左 80px から・width 340px・上下中央（top 50% + translateY(-50%)）
  kicker: 英字ラベル ／ 資料の種別       # 10px / 700 / 字間 .2em / 大文字 / var(--sk-ink)
  title:  タイトル                      # 40px / 700 / 字間 .06em / 行間 1.35 / 最大2行 / #1A1A1A
  rule:   区切り線                      # 幅 64px・高さ 1px・#AAAAAA（title から 28px 下）
  meta:   補足1行                       # 16px / 400 / 字間 .06em / #555555（社名 ／ 日付）
notes:
  - 紫のドット円が x≈441px から始まるので、文字ブロックの右端（80+340=420px）を超えない
  - 旧版の左の縦バーは廃止（区切り線が同じ役目を持つため）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景画像 | 全面（`/assets/covers/cover-bg-handdrawn-art.jpg`） | 手描き画材モチーフ。左半分が余白なので、そこに文字を置く |
| KICKER | 文字ブロックの先頭 | 英字ラベル＋資料の種別（例：`Creative Works ／ 制作事例`）。背景が明るい側なのでインク色 |
| タイトル | KICKER の下 | 資料タイトル。40px・700・最大2行（この幅では1行8文字前後） |
| 区切り線 | タイトルの下 | 幅64px・1px の細い線。旧版の太い縦バーの代わり |
| 補足1行 | 区切り線の下 | 社名・日付など（例：`Macminol ／ 2026.04`）。16px |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-cover-art-brush-left を使って表紙を1枚生成してください。
【KICKER】Creative Works ／ 制作事例
【タイトル】デザイン制作の／事例と進め方
【補足】Macminol ／ 2026.04
```
### 注意点
- **この背景は文字の置ける幅が狭い。** タイトルは1行8文字前後・最大2行に収める。入らなければ cover-curve-shape-left か cover-geo-texture-left（左が広い背景）に替える
- **サブタイトルは置かない**（2026-08-31 代表決定）。副題を出したいときは KICKER の後半に回す
- 補足は1行だけ。11.5px の注記は使わない
- 背景の絵柄が賑やかなので、文字側に装飾を足さない（影・グラデーション・縦バーを重ねない）
- 背景画像レイヤー（`slides[].bg`）は OFF にする（表紙が自前の背景画像を持つため）
- 同じ家族（画像背景の表紙）は cover-geo-texture-left / cover-soft-3d-left / cover-blob-side-left / cover-curve-shape-left。文字の組みは5種で共通なので、背景の雰囲気だけで選ぶ

## v2 での描き直し（2026-09-04）
- タイトル40px/700・行間1.35・2行までに統一し、上に英字KICKER（10px・字間.2em・インク色）、下に幅64pxの細い区切り線を足した
- 左の太い縦バー（5px）を廃止し、区切り線に役目を移した。会社名の別置きもやめて補足1行にまとめた
- 文字ブロックの起点を左72px→80pxに寄せ、上38%から上下中央にそろえた（背景画像はそのまま）
