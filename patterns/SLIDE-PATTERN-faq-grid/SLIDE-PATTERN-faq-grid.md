# SLIDE-PATTERN-faq-grid

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** faq-grid
**概要：** 6つのよくある質問を3列×2行の等高カードに配置するレイアウト。各カードは「Q.01（英字ラベル風）→質問→細罫線→回答」の型で、いちばん多い質問の1枚だけ塗りで主役にする
**適したシーン：** よくある質問ページ、サービス説明の補足Q&A、懸念事項への回答

## Structure（構造）

コンテンツエリア（左右余白48px）を3列×2行の等高カード（gap 16px・角丸11px）に分割する。カードは淡い地で、中身は左ぞろえに「Q番号（`Q.01`・10px・英字ラベル風）」「質問（太字・1行）」「細罫線」「回答（2〜3行）」の順に置く。6枚のうち1枚（いちばん多い質問）だけを塗りカード（白文字）にする。カード群は本文エリアの上下中央に置く。

    structure:
      layout: three-column-two-row-grid
      columns: 3
      rows: 2
      cards:
        equal_height: true
        gap: 16
        emphasis: one filled card (1 of 6)
      card:
        order:
          - q-label ("Q.01", kicker style)
          - question (16px, bold, 1 line)
          - thin-rule
          - answer (16px, 2-3 lines)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| Q番号 | 各カード最上段（`Q.01`〜`Q.06`） | 質問の番号。英字ラベルの流儀で小さく置く |
| 質問 | Q番号の下（太字・1行） | 疑問形で短く（14字以内） |
| 細罫線 | 質問と回答の間 | 質問と回答の切り替え。塗りカード内は白の半透明線 |
| 回答 | 罫線下（2〜3行） | 結論から言い切る。長い補足は別スライドへ |
| 塗りカード | 6枚のうち1枚 | いちばん多い質問を主役にする。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-faq-gridのレイアウトで、6つのよくある質問と回答を3列×2行で配置してください。質問は14字以内の疑問形、回答は2〜3行で結論から書き、主役にする質問を1つ指定してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 質問は1行（14字以内）、回答は3行（42字以内）に収める。入らないときは文字を小さくせず、文言を短くする
- 6項目が適切。4項目の場合はtwo-column-split-boxesを2行、8項目以上は別パターンを検討
- 塗りは1枚だけ。すべてのカードを同じ扱いにしたいときは塗りを外し、全部を淡い地にしてよい
