# SLIDE-PATTERN-mission-vision-editorial-rows

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** mission-vision-editorial-rows
**概要：** 上下2段の行構造。各行は、左22%の英字ラベル（MISSION／VISION・字間広め・垂直中央）→ 細い縦罫線 → 右の本文ブロック（和文太字の大見出し1〜2行＋英字小キャプション＋本文3〜5行）で構成する。段間は大きめの余白で区切る。
**適したシーン：** 理念・約束ごとを文章で語る編集誌トーンの1枚。value-three-pillars より本文の文章量を持てる2項版。

## Structure（構造）
- 2段の行を縦に積む（段間は大きめの余白のみ。罫線は引かない）
- 各行: 英字ラベル（幅22%・垂直中央） → 細い縦罫線（行の高さいっぱい） → 本文ブロック
- 本文ブロック: 和文太字の大見出し1〜2行 → 英字小キャプション → 本文3〜5行

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル | 各行の左22% | MISSION／VISIONなどの項目名（字間広め） |
| 縦罫線 | ラベルと本文の間 | 行の背骨になる細い区切り線（行の高さに揃える） |
| 大見出し | 本文ブロック上段 | その項の主張を和文太字で1〜2行 |
| 英字キャプション | 大見出しの下 | 大見出しに添える小さな英字1行（飾り） |
| 本文 | キャプションの下 | 主張を支える文章3〜5行 |

## Usage Guide（AIへの使い方）
- 2段が基準（3段まで可。3段にする場合は本文を3行までに圧縮する）
- ラベルはMISSION／VISION以外（PROMISE・POLICYなど）でもよい。1単語に絞る
- 縦罫線は行の高さ（ラベル上端から本文下端）に合わせる。スライド全高に伸ばさない
- 本文は文章として書く（体言止めの箇条書きにしない）。読み物のトーンを保つ
