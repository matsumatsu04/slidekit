## Overview

**パターン名：** three-col-numbered-card
**概要：** 番号（32px・細め・アクセント色）を頭に置いた3列カード。淡い地の等高カードに「番号→英字ラベル→見出し→細罫線→本文2行→例：」の型で組み、中央を塗り・右（最終）を1.5pxのアクセント枠線で別扱いにする
**適したシーン：** 進め方の3ステップ、選ばれる3つの理由、確認する3つの前提など、順序を持つ3項目を並べるスライド（最後の項目を「結果・運用」として区別したいとき）

## Structure（構造）

コンテンツエリア（左右余白48px）を3等分した等高カード（336px・gap 16px・角丸11px・`--sk-soft` 地）で構成する。中身は左ぞろえ・上ぞろえで、上から「番号（01/02/03・32px・細め・アクセント色・囲まない）」「英字ラベル（KICKER）」「見出し（18px・太字）」「細罫線」「本文（16px・2行）」「例：の注記」の順に置く。左は淡い地、中央は塗りカード（白文字・番号も白）、右は白地＋1.5pxのアクセント色枠線にして「最終・結果」を塗らずに区別する。カード群は本文エリアの上下中央に置く。

    structure:
      layout: three-equal-columns
      cards:
        equal_height: true (336px)
        gap: 16
        left: soft
        center: filled (accent, white text) — the only fill
        right: white + 1.5px accent outline (final / result)
      card:
        order:
          - number (01/02/03, 32px, regular, accent)
          - kicker (english label + japanese supplement)
          - heading (18px, bold)
          - thin-rule
          - body (16px, 2 lines)
          - note ("例：" 11.5px)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 番号 | 各カード左上（32px・細め・アクセント色） | 順序を示す視覚のアンカー。丸や帯で囲まない・太くしない。塗りカード内は白 |
| 英字ラベル（KICKER） | 番号の下 | `Plan ／ 設計` のように英字＋日本語補足で工程の名前を示す。アクセント色 |
| 見出し | ラベル下（18px・太字） | その工程で「何をするか」（10字前後） |
| 細罫線 | 見出しと本文の間 | 見出しと本文の切り替え。塗りカード内は白の半透明線 |
| 本文 | 罫線下（16px・2行） | 工程の説明。1文で言い切る（26字以内） |
| 注記（例：） | 本文下（11.5px・薄く） | 具体例を1行で添える |
| 塗りカード | 中央 | 3項目の主役（「今ここ」や一番伝えたい工程）。1枚のスライドで塗りは1つだけ |
| 枠線カード | 右（最終） | 結果・運用など「最後の項目」を塗らずに区別する。白地＋1.5pxのアクセント枠 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-three-col-numbered-cardのレイアウトで、[テーマ]の3つの[ステップ/理由]（[項目1]・[項目2]・[項目3]）を番号付きで並べてください。各カードは英字ラベル・見出し・本文1文（2行以内）・「例：」の順で書き、主役にする項目を中央、最終の項目を右に置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 番号は 01/02/03 の2桁ゼロ埋め・32px・細め（400）。バッジ・帯・下線で飾らない
- 塗りは中央の1枚だけ。右の最終カードは塗らず1.5pxの枠線で区別する（塗りが2つにならない）
- 本文は2行（26字以内）。箇条書きにしない。長くなるなら three-col-icon-card-body-text へ
- 4項目なら four-card-2x2、順序が無い3項目なら three-column-icon-card を使う
