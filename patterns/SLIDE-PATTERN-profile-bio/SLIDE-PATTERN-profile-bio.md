# SLIDE-PATTERN-profile-bio

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** profile-bio
**概要：** 左に写真プレースホルダ（240×300）と氏名キャプション、右に氏名24px・肩書・横罫線だけの経歴テーブル（ラベル列は英字ラベル）を置く1名紹介レイアウト。塗りは置かない
**適したシーン：** 登壇者紹介、会社代表者紹介、担当者プロフィール

## Structure（構造）

コンテンツエリア（左右余白48px）を、左の写真列（幅240px）と右の本文列（残り全幅）に分ける（間隔40px）。左列は縦長4:5の写真枠（240×300・淡い地のプレースホルダ。中央に英字ラベル `PHOTO ／ 4:5`）と、その下に氏名キャプション（11.5px・muted・中央ぞろえ）。右列は上から「氏名（24px・太字）」「肩書（16px・muted）」「経歴テーブル」の順。テーブルは横罫線のみ（上端と各行の下に1px・`--sk-line`）で、ラベル列（幅120px）は英字ラベル（KICKER・`CAREER ／ 経歴` のように英字＋日本語）、値は16px・行間1.8。複数行の値は `<br>` で行を分ける。両列とも上ぞろえで、ブロック全体（高さ360px）は本文エリアの上下中央に置く。塗りは置かない。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 写真枠 | 左列上部（240×300） | 人物写真の置き場。実装時は `<img>` を `object-fit:cover` で差し替える。空のときは淡い地に英字ラベルだけ |
| 氏名キャプション | 写真の下（11.5px・muted） | 「山田 太郎（やまだ たろう）」のように読みを添える |
| 氏名 | 右列上部（24px・太字） | 名前を見出しとして立てる |
| 肩書 | 氏名の下（16px・muted） | 会社名・役職・講師名など。複数は `／` でつなぐ |
| 経歴テーブル | 右列中〜下 | 出身・経歴・専門・現在などを横罫線だけの表で構造化する（縦罫線・地色は付けない） |
| ラベル列（KICKER） | テーブル左（幅120px） | `CAREER ／ 経歴` のように英字＋日本語で行の意味を示す |
| 値 | テーブル右（16px） | 1行または3行まで。経歴は「年 出来事」の形で1行ずつ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-profile-bioのレイアウトで、[氏名]のプロフィールを表示してください。写真は左に縦長（4:5）で置き、右に氏名・肩書と、出身・経歴・専門・現在の4行の経歴テーブル（ラベルは英字＋日本語）を書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 写真は縦長4:5で用意する（横長だと顔が切れる）。円形にしたい場合は team-members-grid / profile-two-speakers を使う
- 実画像が無い場合はプレースホルダのまま納品せず、写真を用意してから使う
- テーブルは4行まで。値は1行26字以内、経歴は3行以内。入らないときは文字を小さくせず、行を減らす
- 塗り・色文字は置かない（英字ラベルだけアクセント色）。強調したい実績があるなら別スライドに分ける
- 2名なら profile-two-speakers、4名以上は team-members-grid を使う
