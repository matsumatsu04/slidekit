# SLIDE-PATTERN-area-growth-curve

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** area-growth-curve
**概要：** 上に横長の面グラフ（SVG 1枚・座標は静的計算）、下に説明を置く縦2段。線は2pxのアクセント色、面は淡いティント（`--sk-soft`。アクセントの薄面は使わない）。終点だけ12pxのアクセント塗りドットにし、グラフ右上に最終値（28px/700・アクセント色）とKICKERを重ねて「どこまで伸びたか」を1点で示す。
**適したシーン：** 売上・ユーザー数の成長ストーリー。棒より滑らかに「勢い」を演出したい1枚。

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 面（塗り） | 線の下・ベースラインまで | 積み上がりの量感。淡いティントで、アクセント塗りとは別扱いにする |
| 成長線 | グラフ中央 | 推移そのもの。2pxのアクセント色（線はアクセント色でよい） |
| 終点ドット | 線の右端 | 到達点の1点。このスライドで唯一のアクセント塗り |
| 最終値＋KICKER | グラフ右上 | 結論の数字（28px/700）。終点の真上に置き、線と重ならせない |
| ベースライン・期ラベル | グラフ下部 | 起点の基準線と、年度・四半期などの期（16px） |
| 説明（下段） | グラフの下 | KICKER → 見出し → 罫線 → 本文 → 例：注記 の型で、伸びた理由を書く |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-area-growth-curveのレイアウトで、FY21〜FY26の売上（0.4/0.6/0.9/1.4/1.9/2.4億円）の成長カーブを描いてください。右上の最終値は 2.4億円（KICKER: FY26 ／ 最終期）。下の説明は KICKER: GROWTH ／ 5年の推移 / 見出し: 5年で6倍。〜 / 本文: 〜 / 注記: 例：金額は年度末時点の売上高。デザインはSLIDE.mdに従ってください。」

**注意点：**
- `polygon`（面）と `polyline`（線）は同じ座標列を使う。面はベースラインの2点を足して閉じる（`<script>` は使えないので静的に計算して書く）
- 面は `--sk-soft` にする。アクセント色の薄面（透明度・混色）は使わない
- 最終値のブロックとカーブが重ならないよう、終点のy座標はラベルの下端から12px以上あける（重なるならy換算の係数を下げる）
- 点は5〜7個。目盛り線は置かない（正確な比較が要るときは bar 系のパターンを使う）
- 右肩下がりのデータには使わない（面が上に残って読み違えるため）
