# SLIDE-PATTERN-proposal-process-checkpoints

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** proposal-process-checkpoints
**概要：** 提案プロセスの工程4つを、等幅・等高のカード（淡い地・角丸11px）で横一列に並べ、カードの間を SVG の三角矢印（幅12px）でつなぐ。カードの中身は「KICKER `STEP 1 ／ 期間` → 見出し18px太字 → 細い罫線 → ✓付きのチェックポイント3行（14px）」の型で揃える。現在の工程1枚だけアクセント塗り・白文字にし、下に注記（例：〜）を1行添える。
**適したシーン：** 提案書の「進め方」スライド。各工程でお客様に確認いただく項目を、工程の中にチェックリストとして示したい場面。

## Structure（構造）

コンテンツエリア（左右48px）の上下中央に「カード列 → 注記」を縦に積む。カード列は flex（gap 8px・等高）で、カード4枚と三角矢印3つを交互に置く。

    structure:
      layout: proposal-process-checkpoints
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        gap: 8px                    # カードと矢印の間
        align_items: stretch        # 4枚は等高
      cards:
        count: 4
        border_radius: 11px
        padding: "20px 16px"
        card:
          elements:
            - kicker: "STEP n ／ 期間"   # 10px / 700 / .18em。アクセント色（塗りカード内は白）
            - heading                    # 18px / 700（7文字以内）
            - rule                       # 1px（塗りカード内は白35%）
            - checkpoints: 3 lines       # 14px / 400 / 行間1.8。先頭に SVG の✓（12px・線2px）。1行9文字以内
        surfaces:
          default: soft                  # 淡い地 + 1px 罫線
          current: accent_fill           # 現在の工程1枚だけ塗り（白文字）
      arrows:
        type: svg-triangle
        width: 12px
        color: accent
      note:
        style: "例：〜"                  # 11.5px / muted。カード列の下に左ぞろえ

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各カード左上 | `STEP 1 ／ 1週目` のように番号と期間を示す |
| 見出し | KICKER の下（18px・700） | 工程名（7文字以内） |
| 細い罫線 | 見出しの下 | 見出しとチェックポイントの区切り（塗りカード内は白35%） |
| チェックポイント | 罫線の下に3行（14px） | その工程でお客様に確認いただく項目。先頭は SVG の✓ |
| 三角矢印 | カードの間 | 左から右への流れ（SVG・幅12px・アクセント色） |
| 塗りカード | 4枚のうち1枚 | 現在の工程（今ここ）。1枚に1つだけ |
| 注記 | カード列の下 | 「例：〜」で✓の意味と塗りの意味を1行添える |

## Usage Guide（AIへの使い方）

> 「SLIDE-PATTERN-proposal-process-checkpointsのレイアウトで、Web制作の進め方4工程（ヒアリング→提案・見積→制作→公開・引き渡し）を示してください。各カードの KICKER に期間（1週目 等）を書き、チェックポイントはお客様に確認いただく項目を3行（1行9文字以内）で書いてください。STEP 2 を現在の工程として塗ってください。デザインはSLIDE.mdに従ってください。」

- 塗りは1枚だけ。「今ここ」が無い提案書なら、要になる工程（提案・見積など）を塗る
- 工程は4つ固定。3つなら three-step 系、5つ以上は枚数を分ける
- チェックポイントは3行まで・1行9文字以内。入らなければ文言を短くする（文字を小さくしない）
- 旧版の「点線タイムライン・菱形バッジ・工程間の小菱形マーカー・タグチップ」は廃止。お客様確認は各カードの✓行で示す

## v2 での描き直し（2026-09-03）
- 点線タイムライン＋菱形バッジ＋工程間の小菱形マーカーを廃し、淡い地のカード4枚と SVG の三角矢印（幅12px）だけで流れを示すようにした
- 各工程の「お客様確認」を、カード内の✓付きチェックポイント3行（14px・SVGの✓）に置き換え、Font Awesome の `<link>` を外した
- カードの中身を「KICKER `STEP n ／ 期間`／見出し18px／細い罫線／チェックポイント3行」の型に揃え、現在の工程1枚だけアクセント塗り・白文字にした
