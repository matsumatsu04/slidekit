# SLIDE-PATTERN-proposal-process-checkpoints

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** proposal-process-checkpoints
**概要：** 水平の点線タイムラインに菱形（45°回転の正方形）のフェーズバッジ4個を等間隔配置し、フェーズ間の点線上に小さな菱形マーカー＋注記ラベル（お客様確認等）を挟む。各バッジの下は4等分カラムで、英字ラベル・工程名・説明3〜5行・角丸タグチップ2×2（チップ間に極小矢印）を積む。
**適したシーン：** 提案書の「進め方」スライド。工程そのものに加えて、お客様に動いてもらう確認タイミングを工程の「間」に明示したい場面。

## Structure（構造）
- 上段: 水平の点線タイムライン（始端・終端は両端バッジの中心）
  - 菱形フェーズバッジ×4（アクセント地・白抜きの英字ラベル＋番号）を等間隔（12.5%・37.5%・62.5%・87.5%）
  - フェーズ間の線上に小菱形マーカー×3（第2アクセント）、その上に短い注記ラベル
- 下段: 4等分カラム（カラム間に細い縦罫線）
  - 各カラム: 英字ラベル → 工程名（和文太字） → 説明3〜5行 → タグチップ2×2（行内は チップ→極小矢印→チップ）

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 点線タイムライン | 上段を水平に横断 | 工程の時系列。両端はバッジ中心で止める |
| フェーズバッジ（菱形） | 線上に等間隔4個 | フェーズ番号の主役。アクセント地に白抜き |
| 小菱形マーカー＋注記 | フェーズ間の線上 | お客様確認・承認などの中間チェックポイント |
| 英字ラベル | 各カラム上端 | 工程の英字キーワード（飾り） |
| 工程名 | 英字ラベルの下 | その工程の和文名称（太字） |
| 説明テキスト | カラム中段 | 実施内容・成果物を3〜5行で記述 |
| タグチップ2×2 | カラム最下部 | 作業→成果物などの対応をチップと極小矢印で示す |

## Usage Guide（AIへの使い方）
- フェーズは4個が基準（3〜5個まで可変。バッジ位置とカラム数を揃えて再配分する）
- 中間マーカーは2〜3個まで。注記ラベルは6〜10文字の短句にする（長文を線上に載せない）
- 点線はバッジ中心で始端・終端を止める（コンテンツ幅いっぱいに伸ばさない）
- チップは1行2個×2行が上限。増える場合は説明テキスト側に逃がす
