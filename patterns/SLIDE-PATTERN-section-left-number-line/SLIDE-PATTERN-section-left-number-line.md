# SLIDE-PATTERN-section-left-number-line

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。
中扉は共通見出し（`sk-head`）を付けない種類のスライドです（表紙・目次と同じ扱い。ONにした場合は本文エリアが上76pxから始まる）。

## Overview
**パターン名：** section-left-number-line
**概要：** 白地の本文エリア（左右48px）の上下中央に、左から「章番号（96px・400・アクセント色）｜1pxの縦罫線（`--sk-line`・高さは番号の字高に合わせた76px）｜英字KICKER → 章タイトル（28px・700）→ 説明1行（16px・muted）」を横に並べる。縦罫線の端点は番号の上下端で止め、本文エリアの全高に伸ばさない。塗りはなし。
**適したシーン：** プレゼンの章区切り、セクション導入。落ち着いたトーンで章の切り替えを示したい場面（塗りで反転させたいときは section-divider へ）。

## Structure（構造）
```yaml
layout: section-left-number-line
background: 白
content-area:                     # left/right 48px・全高の上下中央（見出しON時は top 76px）・横並び・垂直中央ぞろえ・左ぞろえ
  number: "03"                    # 96px / 400 / 字間 .02em / 行間 1 / アクセント色
  vline:  1px × 76px              # var(--sk-line)。左右 32px。番号の字高に合わせて止める（コンテナ全高に伸ばさない）
  block:                          # 縦積み・左ぞろえ
    kicker: "SECTION"             # 10px / 700 / 字間 .2em / 大文字 / アクセント色
    title:  章タイトル             # 28px / 700 / 字間 .06em / 行間 1.5 / インク色。max-width 640px・1〜2行。上に 12px
    sub:    説明1行                # 16px / 400 / 行間 1.8 / muted 色。max-width 640px。上に 12px（省略可）
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 章番号 | 左 | 2桁ゼロ埋めの細字（400）・96px・アクセント色。塗り・囲みにせず、大きさと細さで章を示す |
| 縦罫線 | 番号の右 | 1pxの `--sk-line`。番号とタイトルを区切る。端点は番号の上下端（76px）で止める |
| KICKER | 罫線の右・上段 | 「SECTION」の英字ラベル（アクセント色・字間広め） |
| 章タイトル | KICKERの下 | 章の内容を1〜2行で言い切る。標語調にしない |
| 説明 | タイトルの下 | この章で扱うことを1行で補う（省略可） |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-section-left-number-line を使って中扉を1枚生成してください。
【章番号】03
【KICKER】SECTION
【章タイトル】運用で見る数字と、直し方の決め方
【説明】週次で確認する指標を3つに絞り、直す基準を先に決めておく
```
### 注意点
- 章番号は96pxの細字（400）のまま太くしない。淡色（`--sk-soft`）にもしない（読めなくなる。アクセント色の文字で足りる）
- 縦罫線は番号の字高（76px）で止める。本文エリアの上下に伸ばしたり、タイトルの下に短いアクセント線を足したりしない
- 章タイトルは28pxで2行まで（1行あたり全角20文字程度）。2行にするときは `<br>` を意味の切れ目に入れる
- 横並びの束は左ぞろえ（48pxから始める）。上下は本文エリアの中央
- 背景画像レイヤー（`slides[].bg`）は白地なので ON のままでよい

## v2 での描き直し（2026-09-03）
- 「120pxの淡色太字番号＋32px太字タイトル＋角丸のアクセント短線」の旧構成から、「96px・400・アクセント色の番号｜1pxの縦罫線｜KICKER→タイトル→説明」の横並びに描き直した（角丸の短線は撤去・塗りなし）
- 縦罫線の端点を番号の字高（76px）で止め、コンテナ全高に伸ばさない形にした（SPEC「接続線・罫線の端点」）
- 太さを400/700の2つに絞り、章タイトルを28px/700に、英字KICKERと説明1行（16px・muted）を型どおりに足し、`palt`・`line-break:strict`・左右48px・`.content-area`（見出しON時は上76px）の組みに揃えた
