# SLIDE-PATTERN-next-step-cta-band

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。タイトルエリア・ページ番号・装飾はデザインテーマ側の Frame で定義されるため、このファイルには含みません。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** next-step-cta-band
**概要：** 上にまとめ3項目を `--sk-soft` 地の等高カード（KICKER→見出し16px→本文16px）で横に並べ、下に全幅のCTA帯（アクセント塗り・白文字・角丸11px・高さ72px）を置く。帯の左に誘導文（18px・700）、右に1.5pxの白枠だけのボタン風ラベル。帯の下に「例：」の注記を1行添えられる。アクセント色の塗りはCTA帯だけ。
**適したシーン：** セミナー・提案・講座資料の最終ページ。まとめと次のアクション誘導を1枚で完結させたい場面

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| カード | 上段・3枚横並び | まとめの要点。`--sk-soft` 地・等高・上ぞろえ。アクセント色で塗らない |
| KICKER | カード上段 | `POINT 1 ／ 前提` のように番号と補足を英字＋短語で示す。アクセント色 |
| 見出し | KICKER の下 | 要点を言い切りで（16px・700・1行） |
| 本文 | 見出しの下 | 根拠や具体を2〜3行で（16px・400） |
| CTA帯 | 下段・全幅 | 次のアクションへの誘導。唯一のアクセント色の塗り（高さ72px・角丸11px） |
| 誘導文 | 帯の左 | 行動を1文で（18px・700・白・16〜24文字） |
| ボタン風ラベル | 帯の右 | 行動がそのまま書かれた短い文言（白枠・白文字・6〜12文字） |
| 注記 | 帯の下 | 期限・特典・申込方法などの補足を1行（11.5px・muted・省略可） |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE-PATTERN-next-step-cta-band を使って締めのスライドを1枚生成してください。

【スライドタイトル】まとめと次の一歩
【ポイント 1】KICKER: POINT 1 ／ 前提 / 見出し: 判断の基準を先に決める / 本文: AIに任せる範囲と、人が最後に決める範囲を、着手前に線引きしておく。
【ポイント 2】KICKER: POINT 2 ／ 進め方 / 見出し: 小さく試して段階で広げる / 本文: ページ単位の試作から始め、崩れなければ次の工程へ広げていく。
【ポイント 3】KICKER: POINT 3 ／ 運用 / 見出し: 確認の手順を型にする / 本文: 見る順番と確認項目を決めておけば、誰が見ても同じ品質で通せる。
【CTA帯】誘導文: まずは1案件で、線引きの1枚を書くところから / ボタン: 無料相談を予約する
【注記】例：期限・特典・申込方法など、CTAの補足はこの1行に添える
```

### 注意点
- CTAの誘導は1つだけ（複数の行き先を並べない）。ボタンには行動がそのまま書かれた文言を入れる（「詳細はこちら」より「無料相談を予約する」）
- 塗りはCTA帯だけ。カードはアクセント色で塗らず、ボタン風ラベルも白枠のまま（白地で塗らない）
- 誘導文は1行（24文字以内）。帯は高さ72px固定なので、補足は帯の中に入れず注記に回す
- カードは3枚・等高・上ぞろえ。本文は3行以内。入らないときは文字を小さくせず、言い切りに削る
- まとめだけで締めるなら summary-three-points、持ち帰り3点なら summary-key-takeaways へ
