# SLIDE-PATTERN: cover-curve-shape-left

このファイルはスライドのレイアウトパターン定義書です。表紙は共通見出し（`sk-head`）を付けない種類のスライドで、
ワードマーク・©・頁番号などのフッターはHTMLデッキビルダー（フレーム v2）が描くため、このファイルには含みません。
背景は `assets/covers/` の画像アセットで、この表紙の家族だけに認められた例外です（色ティントの対象外）。

## Overview
**パターン名：** cover-curve-shape-left
**概要：** 右端の大きな曲面シェイプと淡ベージュの斜め面でできた背景画像を全面に敷き、絵柄が薄い左側に文字ブロックを置く。文字は「英字KICKER → タイトル2行 → 64pxの細い区切り線 → 補足1行」の順に縦に組み、スライドの上下中央にそろえる。曲面が右端だけなので、文字ブロックの幅は画像背景の表紙5種で最も広い560px。
**適したシーン：** 会社紹介・営業資料・ピッチ。大胆でモダンな印象の表紙。

## Structure（構造）
```yaml
layout: cover-curve-shape-left
background:
  image: /assets/covers/cover-bg-curved-shape.jpg
  fit: center / cover / no-repeat      # 差し替え・削除をしない（色ティント対象外）
text_block:                            # 左 80px から・width 560px・上下中央（top 50% + translateY(-50%)）
  kicker: 英字ラベル ／ 資料の種別       # 10px / 700 / 字間 .2em / 大文字 / var(--sk-ink)
  title:  タイトル                      # 40px / 700 / 字間 .06em / 行間 1.35 / 最大2行 / #1A1A1A
  rule:   区切り線                      # 幅 64px・高さ 1px・#AAAAAA（title から 28px 下）
  meta:   補足1行                       # 16px / 400 / 字間 .06em / #555555（社名 ／ 更新日）
notes:
  - 曲面は x≈660px から始まるので、文字ブロックの右端（80+560=640px）を超えない
  - 旧版の「資料の種別ラベル」は KICKER の後半（例：Service Deck ／ 営業資料）が引き継ぐ
```

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| 背景画像 | 全面（`/assets/covers/cover-bg-curved-shape.jpg`） | 右端に大きな曲面。左〜中央が広い余白なので、そこに文字を置く |
| KICKER | 文字ブロックの先頭 | 英字ラベル＋資料の種別（例：`Service Deck ／ 営業資料`）。旧版の種別ラベルの役目を兼ねる |
| タイトル | KICKER の下 | 資料タイトル。40px・700・最大2行（この幅では1行12文字程度まで） |
| 区切り線 | タイトルの下 | 幅64px・1px の細い線 |
| 補足1行 | 区切り線の下 | 社名・更新日など（例：`Macminol ／ 2026.04 更新`）。16px |

## Usage Guide（AIへの使い方）
### プロンプト例
```
SLIDE-PATTERN-cover-curve-shape-left を使って表紙を1枚生成してください。
【KICKER】Service Deck ／ 営業資料
【タイトル】サービスの内容と／導入までの流れ
【補足】Macminol ／ 2026.04 更新
```
### 注意点
- 5種のなかで左の余白が最も広い。**タイトルが長い資料はこのパターンを選ぶ**（1行12文字程度・最大2行）
- **サブタイトルは置かない**（2026-08-31 代表決定）。副題を出したいときは KICKER の後半に回す
- 旧版にあった「資料の種別ラベル」は独立の行にせず、KICKER に含める（`Service Deck ／ 営業資料`）
- 補足は1行だけ。11.5px の注記は使わない
- 背景画像レイヤー（`slides[].bg`）は OFF にする（表紙が自前の背景画像を持つため）
- 同じ家族（画像背景の表紙）は cover-geo-texture-left / cover-art-brush-left / cover-soft-3d-left / cover-blob-side-left。文字の組みは5種で共通なので、背景の雰囲気だけで選ぶ

## v2 での描き直し（2026-09-04）
- タイトルを52pxから40px/700・行間1.35・2行までに統一し、上に英字KICKER（10px・字間.2em・インク色）、下に幅64pxの細い区切り線を足した
- 独立していた「資料の種別ラベル」を KICKER に統合し、左下に横並びだった会社名（20px）と更新日を16pxの補足1行にまとめた
