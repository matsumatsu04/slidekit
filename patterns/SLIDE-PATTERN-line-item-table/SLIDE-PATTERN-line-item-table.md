# SLIDE-PATTERN-line-item-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** line-item-table
**概要：** 左に「項目名（16px・太字）＋説明（14px・muted）」の2段、右に右ぞろえの金額、という2列だけの明細表。ヘッダーはKICKER型（10px・アクセント色）で塗らず、行は横の細い罫線（`--sk-line`）だけで区切る。表の下に「小計 → 消費税 → 合計」の3行を幅320pxの集計ブロックとして右寄せでまとめ、合計行だけ淡い地（`--sk-soft`・角丸6px）にして金額を20px・太字・アクセント色で見せる。左下に「例：〜」の注記を1行添える。
**適したシーン：** 制作費の明細提示、税込金額まで示す見積、追加オプション・料金メニューの一覧、数量×単価の根拠より「何をするか」の説明を優先したい明細。

## Structure（構造）

コンテンツエリア（左右余白48px）に、表→集計ブロックの順に縦に並べ、まとめて上下中央にする。表は本物の `<table>` で、列は「項目（2段）／金額」の2列。ヘッダーはKICKER型で塗りなし・下罫線だけ。データ行は各セルに「項目名＋説明」の2段を入れ、横罫線だけで区切る。表の下は flex の1行で、左に注記（下端ぞろえ）、右に幅320pxの集計ブロック（小計・消費税は細罫線の行、合計は淡い地の行）を置く。塗り（アクセント色の面）は持たない。

    structure:
      layout: line-item-table + summary-block
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      table:
        element: "<table>"          # div の擬似表ではなく本物の表
        table_layout: fixed
        header_row:
          style: "KICKER（10px / 700 / .18em / アクセント色）。塗らない。下罫線 1px"
          height: 32px
          cells: [Item ／ 項目, Amount ／ 金額(184px・右ぞろえ)]
        data_rows:
          count: 4                  # 3〜5行まで
          divider: "1px の罫線（--sk-line）。縦罫線・縞模様は引かない"
          item_cell:
            name: "項目名（16px・700）"
            desc: "説明（14px・muted・22文字以内で1行）"
          price_cell: "金額（16px・右ぞろえ・tabular-nums・「¥」＋3桁区切り）"
      foot:                         # 表の 12px 下。左右に振り分ける
        note: "例：〜（11.5px・muted）を左下に置く"
        summary_block:              # 右寄せ・幅320px
          rows:
            - subtotal: "小計（16px）。細罫線の行・高さ32px"
            - tax: "消費税（10%）。細罫線の行・高さ32px"
            - total:
                surface: soft       # 淡い地（--sk-soft）・角丸6px・高さ48px。塗りではない
                value: "20px / 700 / アクセント色 / 右ぞろえ"

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 列見出し | 表の最上行 | `Item ／ 項目`・`Amount ／ 金額` のKICKER。塗らない |
| 項目名 | 各行の上段 | 何の費用か（16px・太字） |
| 説明 | 項目名の下 | 作業内容の補足（14px・muted・1行）。金額の根拠を言葉で添える |
| 金額 | 最右列 | 行ごとの金額（右ぞろえ・等幅数字） |
| 行罫線 | 各行の下 | 行の区切り。縦罫線・塗り・縞模様は使わない |
| 小計・消費税 | 集計ブロックの上2行 | 税抜の合計と税額。細い罫線の行 |
| 合計 | 集計ブロックの最下行 | 唯一の地色（淡い地）。金額だけ20pxのアクセント色で目立たせる |
| 注記 | 左下 | 「例：」で有効期限・前提条件を1行 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-line-item-tableのレイアウトで明細スライドを作成してください。明細は『サイト設計｜ページ構成の整理・ワイヤーフレームの作成｜¥120,000』『デザイン｜TOP＋下層4ページ・スマホ対応｜¥320,000』…の4行、小計 ¥720,000・消費税（10%）¥72,000・合計 ¥792,000。左下に有効期限を「例：」の注記で1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは持たない。旧版の「内訳」小見出しバー・ヘッダーの反転塗り・5列（単価／数量／単位）の構成は廃止した。数量×単価を見せたいときは estimate-amount-table を使う
- 集計ブロックは「小計→消費税→合計」の3行が基準。税込表示が不要なら小計・消費税の行を省き、合計行だけ残してよい
- 明細は3〜5行まで。説明は22文字以内で1行に収める（文字は小さくしない）
- 金額は「¥」＋3桁区切りで統一し、右端を集計ブロックの金額と揃える
- 合計は小計＋消費税と必ず一致させる

## v2 での描き直し（2026-09-03）
- 「内訳」小見出しバーと反転塗りのヘッダー・5列（項目／単価／数量／単位／金額）をやめ、「項目名16px/700＋説明14px/muted」の2段と右ぞろえの金額だけの2列・横罫線だけの表にした
- 合計を持たない構図から、表の下に「小計→消費税→合計」の集計ブロック（幅320px・右寄せ）を持つ構図に変え、合計行だけ淡い地（`--sk-soft`・角丸6px）に20px・700・アクセント色の金額を置いた
- 文字を v2 の表に揃え（KICKER 10px・本文16px・注記11.5px・インク色・palt・禁則・太さ400/700のみ・`tabular-nums`）、左右余白48px・左下に「例：」の注記を足した
