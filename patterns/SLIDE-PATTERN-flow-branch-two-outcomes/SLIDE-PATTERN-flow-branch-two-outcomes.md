# SLIDE-PATTERN-flow-branch-two-outcomes

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** flow-branch-two-outcomes
**概要：** 左から「起点 → 判断 → 結果2つ（上＝YES／下＝NO）」へ流れる条件分岐フロー図。ひし形は使わず、4つのノードをすべて同じ型の箱（淡い地・角丸8px・KICKER＋見出し＋1行説明）で描き、推す側の結果（YES）だけアクセント塗り・白文字にする（塗りは1枚に1つ）。接続線は1枚のSVGで、判断ノードの右辺中心から分岐点まで進み、そこで直角に上下へ折れて各結果の左辺中心に三角矢印で入る。
**適したシーン：** 判定フロー・診断チャート・申込条件の説明。「あなたはどっち？」の場合分けを見せる場面。

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に 864×288px のステージを置き、ノードを絶対配置する。ノードの高さは96px固定（文言の長さで線の端点がずれない）。結果2つは上段（top:0）と下段（top:192）、起点と判断は中央行（top:96）。

    structure:
      layout: left-to-right-branch
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      stage: 864x288               # ノードは絶対配置
      node_common:
        border_radius: 8px
        height: 96px                # 固定
        elements:
          - kicker: "START ／ 起点" など   # 10px / 700 / .18em（塗りノード内は白）
          - title                          # 16px / 700 / 1行
          - desc                           # 14px / 400 / 1行
      nodes:
        start:  { x: 0,   y: 96,  w: 240, fill: soft }
        judge:  { x: 280, y: 96,  w: 240, fill: soft }
        yes:    { x: 592, y: 0,   w: 272, fill: accent, text: white }   # 塗りはここだけ
        no:     { x: 592, y: 192, w: 272, fill: soft }
      connector:
        svg: 1 sheet (1px var(--sk-line))
        paths:
          - start.right-center → judge.left-center（三角矢印で入る）
          - judge.right-center → 分岐点(x=544) → 直角に上下 → yes/no.left-center（三角矢印で入る）
        arrow: SVG triangle, width 12px, accent fill
      constraint: outcomes = 2（3つ以上は表かリストに変える）

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 起点ノード | 左・中央行 | 入力・スタート地点。KICKER `START ／ 起点` |
| 判断ノード | 中央・中央行 | 条件・判断。KICKER `JUDGE ／ 判断`。見出しは「〜か」の疑問形 |
| 結果 YES | 右・上段 | 推す側の結果。アクセント塗り・白文字（1枚で塗るのはここだけ） |
| 結果 NO | 右・下段 | もう一方の結果。淡い地 |
| KICKER | 各ノード上段 | 役割の英字＋日本語。アクセント色（塗りノード内は白） |
| 見出し／1行説明 | KICKER の下 | 16px/700 の見出しと 14px の説明を各1行 |
| 接続線 | ノードの間 | 1pxの罫線色。分岐点で直角に折る。端点はノード辺の中心。矢印はSVG三角のみ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-flow-branch-two-outcomesのレイアウトで、起点に[入力]、判断に[条件（〜か）]、YESに[推す結果]、NOに[もう一方の結果]を入れてください。各ノードは KICKER → 見出し → 1行説明の順で書き、塗りは YES だけにしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 分岐は2つまで（3分岐以上は表かリストに変える）
- 推奨する側を YES（上・塗り）に置く。NO 側を否定的な色や文言で描かない
- 見出し・説明は各1行に収める（起点・判断は10文字前後、結果は12文字前後）。長い場合は説明を削る
- ひし形・斜め線・曲線は使わない。線は直角に折るだけ、矢印はSVG三角（幅12px）だけ

## v2 での描き直し（2026-09-03）
- 回転45°のひし形＋斜めの分岐線（2本の回転した div）をやめ、4ノードを同じ型の箱（淡い地・角丸8px・KICKER＋見出し16px/700＋説明14px）にして 864×288 のステージに絶対配置した
- 接続線を1枚のSVG（1px・罫線色）にし、分岐点で直角に折って各ノード辺の中心で止める形にした。矢印はSVG三角（幅12px・アクセント色）だけ
- YES だけアクセント塗り・白文字にし、他は淡い地に揃えた（塗りは1枚に1つ）。ノード高さ96px固定で文言の長さに端点が左右されない
