# SLIDE-PATTERN-two-col-text-body

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** two-col-text-body
**概要：** 左右2カラムにそれぞれ「英字ラベル（KICKER）／見出し18px／本文16px（行間1.8・最大3段落）／例：」を同じ型で置く本文スライド。中央に1pxの縦罫線（`--sk-line`）だけを引き、塗りは使わない。
**適したシーン：** 課題と打ち手、2つの視点の対比、Before/After、2つのトピックの並列説明

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、等幅・等高の2カラムを置き、間に1pxの縦罫線を立てる（罫線はカラムの束と同じ高さ）。カラムの中身は上ぞろえで、左右とも同じ型で組む。カード地・枠線・短い横線などの塗り・装飾は置かない。

    structure:
      layout: two-equal-columns
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        align_items: stretch        # 2カラムは等高。中身は上ぞろえ
      column_common:
        inner_padding: "外側0 / 罫線側 32px"
        elements:
          - kicker: "英字ラベル ／ 補足"   # 10px / 700 / .18em / アクセント色
          - heading                        # 18px / 700 / 行間1.4（12〜18文字）
          - body:                          # 16px / 400 / 行間1.8
              paragraphs: 2                # 最大3段落・段落間 12px
              line_length: "1行23文字前後"
          - note: "例：〜"                 # 11.5px / muted。カラム下端に寄せる
      divider:
        width: 1px
        color: var(--sk-line)              # 縦罫線だけ。塗りなし
      fill: none

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各カラム上段 | `ISSUE ／ 課題`・`APPROACH ／ 打ち手` のように英字＋日本語補足で、カラムの役割を小さく示す。アクセント色 |
| 見出し | KICKER の下 | そのカラムの要点を1文で（12〜18文字・18px・700） |
| 本文 | 見出しの下 | 説明を2〜3段落（16px・行間1.8・段落間12px）。1段落は3行以内 |
| 注記 | カラム最下 | 「例：〜」で数字・条件を1行添える（省略可） |
| 縦罫線 | 中央 | 2カラムの区切り。1px・`--sk-line`。塗りや太線にしない |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-two-col-text-bodyのレイアウトで、左カラム（KICKER「[英字 ／ 補足]」・見出し「[左見出し]」・本文「[2〜3段落]」）、右カラム（KICKER「[英字 ／ 補足]」・見出し「[右見出し]」・本文「[2〜3段落]」）のスライドを作成してください。各カラムの下に「例：〜」を1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 左右の本文は同じ段落数・同じくらいの行数に揃える（片方だけ長いと罫線の下が空く）
- 本文は最大3段落・合計6行以内。入らないときは文字を小さくせず、文言を削るか2枚に分ける
- 塗りは使わない。推す側を塗って対比したいときは two-column-split-boxes を使う（こちらは文章中心の並列説明）
- KICKER は英字＋日本語補足の型（`POINT 01 ／ 前提` など）。旧版の「見出しの下の短い横線」は廃止した
