# SLIDE-PATTERN-phase-cards-with-target

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。

## Overview
**パターン名：** phase-cards-with-target
**概要：** 淡い地のフェーズカード3枚（KICKER「PHASE 1 ／ 期間」・見出し18px・細い罫線・本文2行・下端に KICKER「TARGET」＋目標値16px太字の目標行）を SVG の三角矢印でつなぐ3段階ステップ。中央の1枚だけアクセント塗り。
**適したシーン：** 導入プロセス・ロードマップの3フェーズ提示、支援プラン・サービスの段階説明。段階ごとの「目標」を数値で見せたいとき。

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、等幅・等高（256px）のカード3枚を横一列に置き、カードの間を SVG の三角矢印（幅12px）でつなぐ。カードの中身は v2 の型（KICKER／見出し／細い罫線／本文2行）で揃え、下端に目標行（細い罫線の下に KICKER「TARGET」＋目標値）を寄せる。中央の1枚だけアクセント塗り。旧版の上部センターメッセージは廃止し、結論はデッキ側のメッセージライン（`.sk-msg`）に書く。

    structure:
      layout: phase-cards
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      row:
        display: flex
        gap: 8px                    # カードと矢印の間
        height: 256px               # 3枚は等高
      cards:
        count: 3
        layout: horizontal-equal-width
        border_radius: 12px
        padding: "20px 20px"
        card:
          elements:
            - kicker: "PHASE n ／ 期間"      # 10px / 700 / .18em。塗りカード内は白
            - heading                        # 18px / 700（8文字以内）
            - rule                           # 1px（塗りカード内は白35%）
            - body: 2 lines                  # 16px / 400 / 行間1.8（1行12文字以内）
            - target_row:                    # カード下端。上に1pxの罫線
                kicker: "TARGET"             # 10px / 700 / .18em
                value: "目標値"              # 16px / 700（8文字以内）
        surfaces:
          default: soft                      # 淡い地 + 1px 罫線（左右の2枚）
          hero: accent_fill                  # 中央の1枚だけ塗り（白文字）。塗りは1枚に1つ
      arrows:
        type: svg-triangle
        width: 12px
        color: accent

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER | 各カード左上 | `PHASE 1 ／ 1〜2ヶ月目` のように段階の番号と期間 |
| 見出し | KICKER の下 | その段階でやることの体言（8文字以内） |
| 細い罫線 | 見出しの下 | 見出しと本文の区切り（塗りカード内は白35%） |
| 本文 | 罫線の下 | 段階の内容を2行（1行12文字以内・改行位置を指定） |
| 目標行 | カード下端 | 細い罫線の下に `TARGET` の KICKER と目標値（16px太字）を横並び。3枚で同じ形にする |
| 三角矢印 × 2 | カードの間 | 段階の進行方向（SVG・幅12px・アクセント色） |
| 塗りカード | 中央の1枚 | 主役の段階（要になる段階）。左右は淡い地 |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-phase-cards-with-targetのレイアウトで、導入の3段階（[段階1]→[段階2]→[段階3]）を説明してください。各カードは KICKER（PHASE n ／ 期間）・見出し・本文2行（1行12文字以内）・目標行（TARGET＋目標値）の順で書き、中央の段階を主役として塗ってください。結論の1文はメッセージラインに書いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは中央の1枚だけ。「今ここ」が中央でない場合も塗りは1枚にとどめる（該当の1枚を塗り、他は淡い地）
- 目標行は3枚とも同じ形（`TARGET`＋値）にそろえる。目標が無い段階は「—」でなく、その段階の到達状態を短く書く
- 本文は1行12文字以内×2行。入らなければ文言を短くする（文字を小さくしない）
- 3段階固定。4段階は horizontal-timeline-cards、段階ごとの対象・範囲を長く書きたいときは枚数を分ける
- 旧版の「上部センターメッセージ＋白サブボックス＋Font Awesome の矢印」は廃止。結論はメッセージライン、矢印は SVG の三角だけ

## v2 での描き直し（2026-09-02）
- 上部のセンターメッセージ（強調スパン付き）と補足2行を廃し、結論はデッキ側のメッセージラインに委ねてカード3枚だけの構図にした
- カード内の白サブボックス（対象◯◯）を、細い罫線の下の目標行（KICKER `TARGET`＋数値16px太字）に置き換え、中央の1枚だけアクセント塗りにした（塗りは1枚に1つ）
- Font Awesome の矢印を SVG の三角（幅12px）に変え、外部CSSの読み込みを無くした。文字は v2 の表（KICKER 10px・見出し18px・本文16px）に揃えた
