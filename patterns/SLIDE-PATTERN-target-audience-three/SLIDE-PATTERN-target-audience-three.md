# SLIDE-PATTERN-target-audience-three

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** target-audience-three
**概要：** 対象者3種を等幅・等高のカード（`--sk-soft` 地・角丸12px）で横並びにし、各カードを「小さなアイコン（白い丸地）→ 英字ラベル `TARGET 1 ／ 補足` → 見出し（〜したい方）→ 細罫線 → 本文2行 → 例：」の型で組む。中央の1枚だけ塗り（白文字）で主役にする。「こんな方に」の見出しは共通見出しかリード（ビルダーの `.sk-msg`）で与える。
**適したシーン：** 講座・サービス・イベント案内の対象者提示。読み手に「自分ごと化」させる場面。

## Structure（構造）
コンテンツエリア（左右余白48px・見出しONで上76px）の上下中央に、3等分した等高カード（高さ336px・gap 16px・角丸12px・`--sk-soft` 地）を置く。中身は左ぞろえ・上ぞろえで、上から「アイコン（20px・40pxの白い丸地）」「英字ラベル（KICKER）」「見出し（18px・700）」「細罫線」「本文（16px・2行）」「例：の注記（11.5px）」の順。3枚のうち中央だけを塗りカード（白文字）にして主役を示す。

    structure:
      layout: three-equal-columns
      cards:
        equal_height: true          # 336px
        gap: 16
        radius: 12
        ground: soft                # var(--sk-soft)。枠線なし
        emphasis: center (filled, 1 of 3)
      card:
        align: top-left
        order:
          - icon (20px, in a 40px white circle)          # 塗りカード内は白の半透明
          - kicker ("TARGET 1 ／ 補足"  10px / 700 / .18em)
          - heading (18px / 700 / 「〜したい方」の形)
          - thin-rule (var(--sk-line)。塗りカード内は rgba(255,255,255,.35))
          - body (16px / 400 / 2 lines)
          - note ("例：" 11.5px / muted)

## Elements（各要素の役割）
| 要素 | 配置 | 役割 |
|---|---|---|
| アイコン | 各カード左上（40pxの白い丸地に20px） | 対象者像を一目で識別させる小さな目印。主張させない |
| 英字ラベル（KICKER） | アイコン下 | `Target 1 ／ 個人` のように「TARGET＋番号」と日本語補足で対象の分類を示す |
| 見出し | ラベル下（18px・太字） | 対象者像を「〜したい方」「〜に悩む方」の形で10字前後に |
| 細罫線 | 見出しと本文の間 | 見出しと本文の切り替え。塗りカード内は白の半透明線 |
| 本文 | 罫線下（2行） | その対象者の悩み・状況を1文で言い切る |
| 注記（例：） | 本文下（小さく薄く） | 具体的な状況を1行で添える |
| 塗りカード | 中央 | 3対象の主役。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）
このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-target-audience-threeのレイアウトで、[サービス名]の対象者3種（[対象1]・[対象2]・[対象3]）を並べてください。各カードは英字ラベル・見出し（〜したい方）・本文2行・「例：」の順で書き、主役にする対象を中央に置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 見出しは「〜したい方」「〜に悩む方」の形で11字以内（18pxで1行）。長いと2行になり罫線の位置がカード間でずれる
- 本文はカード幅（1行13字前後）で2行に収まる長さにする。入らないときは文字を小さくせず、文言を短くする
- アイコンは Font Awesome Solid を20pxで使う。大きな図版にしない（主役は見出しと本文）
- 塗りは中央の1枚だけ。他の2枚は soft 地のまま（上辺のアクセント線も付けない）
- カードは3枚固定（4枚なら four-card-2x2 へ）
