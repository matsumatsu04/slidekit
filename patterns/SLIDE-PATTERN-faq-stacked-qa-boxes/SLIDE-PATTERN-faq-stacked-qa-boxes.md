# SLIDE-PATTERN-faq-stacked-qa-boxes

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** faq-stacked-qa-boxes
**概要：** Q&Aのペアを1つの箱にまとめ、3つを縦に積むFAQレイアウト。各箱は淡いティント地（`--sk-soft`）・角丸11pxで、左に英字ラベル型の「Q.01」、右に質問（16px・太字）とその下の回答（16px）を置く。1箱目（いちばん多い質問）だけアクセント色で塗り、白文字にする。箱は等高にせず内容の高さのまま、gap 12px で積む。
**適したシーン：** よくある質問（FAQ）の紹介、疑問点の解消、サービスに関するQ&A、想定質問への事前回答など、問いと答えをセットで伝えるスライド。

## Structure（構造）

コンテンツエリア（左右余白48px）に、Q&Aの箱を縦に3つ積む。箱の束は本文エリアの上下中央に置き、各箱の中身は上ぞろえ。箱は横2段組みで、左の固定幅48pxに「Q.01」（10px・英字ラベル風）、右に「質問（太字・1行）→回答（1〜2行）」を置く。1箱目だけ塗りカード（白文字）。

    structure:
      layout: stacked-qa-boxes
      item_count: 3
      stack:
        gap: 12
        equal_height: false      # 内容高（回答の行数で箱の高さが変わってよい）
        emphasis: first box filled (1 of 3)
      box:
        background: soft
        border_radius: 11
        padding: "16px 24px"
        columns:
          - q-label ("Q.01", kicker style, width 48)
          - text:
              - question (16px, bold, 1 line)
              - answer   (16px, 1-2 lines)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| Q番号 | 各箱の左（`Q.01`〜`Q.03`） | 質問の番号。英字ラベルの流儀で小さく置く。塗り箱内は白 |
| 質問 | Q番号の右・上段（太字・1行） | 疑問形で短く（16字以内） |
| 回答 | 質問の下（16px・1〜2行） | 結論から言い切る（44字以内）。長い補足は別スライドへ |
| 塗り箱 | 3つのうち1箱目 | いちばん多い質問を主役にする。1枚のスライドで塗りは1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-faq-stacked-qa-boxesのレイアウトで、よくある質問3つとその回答を縦に積んでください。質問は16字以内の疑問形、回答は1〜2行で結論から書き、主役にする質問を1箱目に置いてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 箱は2〜4個。5個以上は箱が小さくなるので、スライドを分割する（faq-grid も検討）
- 質問は1行（16字以内）、回答は2行（44字以内）に収める。入らなければ文字を小さくせず、文言を短くする
- 塗りは1箱目だけ。すべて同じ扱いにしたいときは塗りを外し、全部を淡い地にしてよい
- 「A.」の接頭辞・枠線・アイコンは付けない。Q番号と太字で問いと答えを見分ける

## v2 での描き直し（2026-09-02）

- 「Q.／A.」の枠線ボックス（等高・角丸6px）を、淡い地（`--sk-soft`）・角丸11px・内容高の箱に描き直し、左に英字ラベル型の `Q.01` を置く2段組みにした
- 1箱目だけアクセント塗り（白文字）にして「塗りは1枚に1つ」を守り、「A.」接頭辞と説明用ラベルを無くした
- 質問14px／回答13pxを 16px にそろえ、行間1.8・字間.06em・インク色・gap 12px・左右余白48pxに合わせた
