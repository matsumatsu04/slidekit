# SLIDE-PATTERN-vertical-timeline-label-list

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** vertical-timeline-label-list
**概要：** 左に日付ラベル（KICKER型・muted）、中央に1pxの幹線と小さな丸ノード、右に見出し16px太字と本文16pxを置く縦タイムライン。最新の1件だけノードをアクセント塗り＋見出しをアクセント色にする。
**適したシーン：** 手順・フロー説明、プロセス説明、段階的な流れの紹介、参画フローや申込手順など順序のある工程を説明するスライド。

## Structure（構造）

コンテンツエリア（左右余白120px＝幅720px）の上下中央に、高さ固定（88px）の行を4つ積む。各行は「日付ラベル（幅104px）→ ノード列（幅40px）→ テキスト（見出し→本文→注記）」の3列。幹線（1px・罫線色）はノード列の中心に引き、最初のノードの中心から最後のノードの中心まで（`top:14px; bottom:88-14px`）で止める。日付・ノード・見出しは行高28pxで垂直中心を合わせる。最新の行だけノードを塗り、見出しをアクセント色にする。

    structure:
      layout: vertical-timeline
      content_area:
        padding: "24px 120px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      rows: 4                       # 標準。5行のときは行高を80pxにして注記を省く
      row:
        height: 88px                # 固定（幹線の端点をノードの中心で止めるため）
        left:
          date: "2026.04"           # KICKER型: 10px / 700 / .18em / muted・行高28px。幅104px
        center:
          node: circle              # 12px の白丸・1.5px 罫線色の枠。列幅40pxの中心（幹線の上に載る）
          now: accent_fill          # 最新の1件だけ塗り（塗りは1枚に1つ）
        right:
          padding_left: 16px
          elements:
            - heading               # 16px / 700 / 行高28px（最新の1件はアクセント色）
            - body: 1 line          # 16px / 400 / 行間1.8（32文字以内）
            - note: "例：〜"        # 11.5px / muted
      trunk:
        type: vertical-line
        width: 1px
        color: line                 # var(--sk-line)。塗り・矢印なし
        left: 124px                 # 日付列104px＋ノード列の中心20px
        from: first node center
        to: last node center

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 日付ラベル | 各行の左端 | `2026.04` のように時期を示す。KICKER型・muted。補足は `2026.07 ／ 現在` の形 |
| 幹線 | ノード列の中心 | 最初のノードの中心から最後のノードの中心までの1px線。時系列を示す |
| 丸ノード | 幹線の上・各行の見出しと同じ高さ | 各時点の印。白丸に罫線色の枠 |
| 見出し | ノードの右・行の上端 | その時点でやったこと（12文字前後） |
| 本文 | 見出しの下 | 内容を1行で（32文字以内） |
| 注記 | 本文の下 | 「例：〜」で目安・条件を1行添える |
| 塗りノード＋アクセント見出し | 最新の1行 | 「現在」「到達点」を塗りで区別する。1枚に1つだけ |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-vertical-timeline-label-listのレイアウトで、申込から運用までの4つの時点を縦のタイムラインで説明してください。各行は日付・見出し・本文1行（32文字以内）・「例：〜」の順で書き、最新の1行は「現在」としてノードを塗ってください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りは最新の1件だけ。すべて過去の出来事なら最後の行を塗る（2つ以上塗らない）
- 4行が標準。5行は行高を80pxにして注記を省く（本文は1行のまま）。6行以上は枚数を分ける
- 本文は1行に収める。入らないときは文字を小さくせず、文言を短くする
- 幹線はノードの中心で止める（行高を変えるときは `bottom` の値＝行高−14px を保つ）
- 旧版の「右の説明ボックス（角丸枠＋◀）・2pxの連結線・上部の英字ラベル」は廃止。線とノードと文字だけで組む
