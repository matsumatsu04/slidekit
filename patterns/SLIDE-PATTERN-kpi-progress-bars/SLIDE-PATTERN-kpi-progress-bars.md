# SLIDE-PATTERN-kpi-progress-bars

このファイルはコンテンツエリアのレイアウト定義です。タイトル枠・ページ番号・装飾はデザインテーマ側の Frame で定義します。共通見出し（`sk-head`）を付ける本文系スライドです。

## Overview
**パターン名：** kpi-progress-bars
**概要：** KPIの進捗バーを4本、細い罫線（`--sk-line`）で区切って縦に積む進捗ダッシュボード。各行は「英字ラベル（KICKER）＋指標名（16px・太字）を左、達成値（20px・太字・アクセント色）＋単位を右端」→「バー（高さ8px・地は `--sk-soft`・進捗はアクセント塗り・角丸4px）」→「目標値の注記（11.5px・muted）」の型。アクセント色の塗りはバーの進捗だけ。
**適したシーン：** KPIの達成状況報告・OKR進捗・キャンペーン途中経過。目標に対する現在地を直感的に見せる場面。

## Structure（構造）

```yaml
layout: kpi-progress-bars
content_area:            # 左右余白48px・見出しON時は上76px以降。行の束は本文エリアの上下中央
  display: flex
  align-items: center

rows:
  count: 4               # 縦積み・行の間は var(--sk-line) の1px罫線
  each:
    padding: "16px 0"
    head:                # 左右に振り分け（ベースラインをそろえる）
      left:
        kicker: "LEADS"          # 10px / 700 / 字間 .18em / 大文字 / アクセント色
        name:   指標名            # 16px / 700
      right:
        value:  達成値            # 20px / 700 / アクセント色
        unit:   単位              # 11.5px / 400 / インク色
    bar:
      height: 8px
      track:  var(--sk-soft)     # 角丸4px
      fill:   var(--sk-accent)   # width ＝ 達成率（%）。唯一の塗り
    note: "目標 150件 ／ 達成率 85%"   # 11.5px / muted
```

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 各行の左端 | 指標の英字名（`LEADS`・`CVR` など）。アクセント色 |
| 指標名 | KICKER の右（16px・太字） | 指標の日本語名（10字以内） |
| 達成値＋単位 | 行の右端 | 現在の値。数字は20px・アクセント色、単位は小さく |
| バー | 見出し行の下（8px） | 進捗そのもの。塗りの width を達成率に一致させる |
| 注記 | バーの下（`目標 〜 ／ 達成率 〜%`） | 目標値と達成率。バーの読み取りを数字で裏づける |
| 罫線 | 行と行の間 | 行の区切り。カード・塗りは使わない |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE-PATTERN-kpi-progress-bars を使ってスライドを1枚生成してください。

【スライドタイトル】今期KPIの進捗
【行 1】KICKER: LEADS / 指標名: 問い合わせ数 / 達成値: 128 件 / 達成率: 85% / 注記: 目標 150件 ／ 達成率 85%
【行 2】KICKER: CVR / 指標名: 問い合わせ率 / 達成値: 2.4 % / 達成率: 80% / 注記: 目標 3.0% ／ 達成率 80%
【行 3】KICKER: PAGES / 指標名: 公開ページ数 / 達成値: 36 ページ / 達成率: 90% / 注記: 目標 40ページ ／ 達成率 90%
【行 4】KICKER: REVIEW / 指標名: 目視チェック完了率 / 達成値: 62 % / 達成率: 62% / 注記: 目標 100% ／ 達成率 62%
```

### 注意点
- バーの `width`（%）と注記の達成率を必ず一致させる（`style="width:85%"`）
- 行は3〜4本。5本以上は goal-kgi-kpi-dashboard など別パターンを検討する（文字を小さくして詰めない）
- 塗りはバーの進捗だけ。達成した行・主役の行を塗りカードにしない（強調は数字のアクセント色で足りる）
- 指標名は10字以内。長い名前は KICKER 側に英字で逃がす

## v2 での描き直し（2026-09-02）
- 3段のバー（トラック14px・数値24px・左右余白110px）を、細罫線で区切る4行（トラック8px・角丸4px・数値20px・左右余白48px）に描き直した
- 各行を「英字ラベル（KICKER）＋指標名16px太字／右端に達成値＋単位→バー→目標値の注記11.5px」の型にし、塗りをバーの進捗だけに限定した
- 文字を v2 の表（本文16px・KICKER 10px・注記11.5px・太さ400/700・インク色・palt）にそろえ、プレースホルダを具体例にした
