# SLIDE-PATTERN-status-progress-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** status-progress-table
**概要：** 施策・タスクの進捗を本物の表で示す。ヘッダ行だけアクセント塗り（白文字・10px・字間.18em）、行は高さ48px以上で細い罫線だけで区切り、ステータスは色に頼らず「記号＋文字」（● 完了／◐ 進行中／○ 未着手）で示す。
**適したシーン：** 月次レポートの進捗確認、プロジェクト一覧の状況報告、施策ステータスの共有、定例会議の進捗一覧

## Structure（構造）

コンテンツエリアの上下中央に `<table>` を置く。列は「施策／ステータス／期日／備考」の4列。塗りはヘッダ行だけで、データ行は細い罫線（`--sk-line`）で区切る。ステータスは記号（●◐○）と文字の組で表し、完了・進行中はアクセント色、未着手は muted 色にする（バッジ・行の塗りは使わない）。表の下に「例：〜」の注記を1行添える。

      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      table:
        element: "<table>"          # div の擬似表ではなく本物の表
        table_layout: fixed
        corner: "上2隅だけ 10px の角丸"
        header_row:
          surface: accent_fill      # 塗りはここだけ
          text: "白 / 10px / 700 / .18em / 大文字"
          height: 40px
          cells: [施策(240px), ステータス(136px), 期日(112px), 備考]
        data_rows:
          count: 5                  # 4〜6行まで
          min_height: 48px          # 実測は 1行53px
          divider: "1px の罫線（--sk-line）。縦罫線・縞模様は引かない"
          item_cell: "施策名（16px・700・インク色）"
          status_cell:
            done:  "● 完了（アクセント色・700）"

            todo:  "○ 未着手（muted・400）"
          date_cell: "期日（16px）"
          note_cell: "備考（16px・20文字以内で1行）"
      note: "例：〜（11.5px・muted）を表の下 12px に置き、記号の凡例を書く"

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| ヘッダ行 | 最上行 | 列の名称（施策／ステータス／期日／備考）。唯一の塗り |
| 施策名 | 最左列 | 行の主語。太字のインク色（アクセント色はステータスに譲る） |
| ステータス | 2列目 | 記号＋文字（● 完了／◐ 進行中／○ 未着手）。完了・進行中はアクセント色、未着手は muted。色が無くても記号で区別できる |
| 期日 | 3列目 | 当初計画の日付。変更があれば備考に書く |
| 備考 | 最右列 | 状況の補足を1行（20文字以内） |
| 行罫線 | 各行の下 | 行の区切り。塗り・縞模様・遅延行のハイライトは使わない |
| 注記 | 表の下 | 「例：」で記号の凡例と期日の扱いを1行添える |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-status-progress-tableのレイアウトで、[N]件の施策の進捗表を作成してください。列は施策／ステータス／期日／備考の4列、ステータスは ● 完了・◐ 進行中・○ 未着手 の記号＋文字で書き、ヘッダ行だけ塗ってください。表の下に記号の凡例を「例：」の注記で1行添えてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 塗りはヘッダ行だけ。旧版の「遅延行の淡色ハイライト」「ステータスのバッジ」は廃止した（遅延は備考に文字で書く）
- ステータスは3値（完了／進行中／未着手）を基本にし、記号を増やさない。「遅延」を足すなら ○ のまま備考に「遅延・要確認」と書く
- 行は4〜6行まで。備考は20文字以内で1行に収める（2行になる場合は行高が伸びる。文字は小さくしない）
- ヘッダの文字は 10px の英字ラベル扱い。長い列名は短い体言に言い換える（「完了日／状況」→「期日」「備考」）
