## Overview

**パターン名：** feature-metrics-four-cells
**概要：** 4つの特徴を数値つきで2列×2行の等高セルに配置し、各セルを「英字ラベル→大きな数字（32px・アクセント色）＋小さな単位→細罫線→説明→例：」の型で組むレイアウト。1枚だけ塗り、右下の最終項目だけ枠線で別扱いにする
**適したシーン：** サービス仕様・料金に含まれる範囲の数値説明、製品の4つの特長と導入効果、強みの定量訴求（1つを主役にしたいとき）

## Structure（構造）

コンテンツエリア（左右余白48px）を2列×2行の等高セル（gap 16px・角丸11px）に分割する。セルは淡い地で、中身は左ぞろえに「英字ラベル（KICKER）」「数字（32px・太字・アクセント色）＋単位（14px・同じベースライン）」「細罫線」「説明（1〜2行）」「例：の注記」の順に置く。4枚のうち1枚を塗りセル（白文字）で主役にし、右下の1枚（最終項目）は白地＋1.5pxのアクセント色枠線で別扱いにする。セル群は本文エリアの上下中央に置く。three-kpi-big-number との違いは、数字が「特徴の説明」に添える位置づけで、説明文と例：を持つこと。

    structure:
      layout: two-by-two-grid
      columns: 2
      rows: 2
      cells:
        equal_height: true
        gap: 16
        emphasis: one filled cell (1 of 4)
        final: bottom-right cell outlined (not filled)
      cell:
        order:
          - kicker (english label + japanese supplement)
          - number (32px, bold, accent) + unit (14px) on one baseline
          - thin-rule
          - description (16px, 1-2 lines)
          - note ("例：" 11.5px)

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| 英字ラベル（KICKER） | 各セル最上段 | `Delivery ／ 納期` のように英字＋日本語で指標の名前を示す |
| 数字 | ラベル下（32px・太字・アクセント色） | 特徴を表す1つの値。1〜3桁が見やすい。塗りセル内は白 |
| 単位 | 数字の右（14px・同じベースライン） | 日・回・%・ページなど1〜3字 |
| 細罫線 | 数字と説明の間 | 数字と説明の切り替え。塗りセル内は白の半透明線 |
| 説明 | 罫線下（1〜2行） | 数字が何を示すかと、その特徴の要点（36字以内） |
| 注記（例：） | 説明下（小さく薄く） | 数え方の条件や具体例を1行で添える |
| 塗りセル | 4枚のうち1枚 | 主役の特徴。1枚のスライドで塗りは1つだけ |
| 枠線セル | 右下 | 最終・結果にあたる項目を塗らずに区別する |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-feature-metrics-four-cellsのレイアウトで、[サービス]の4つの特徴を数値つきで2×2に並べてください。各セルは英字ラベル・数字＋単位・説明（36字以内）・「例：」の順で書き、主役にする1枚と、最後の項目（右下）を指定してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 4セル固定のパターン。3つの数値なら three-kpi-big-number を使う
- 数字は1セルに1つ。複数の指標を並べたい場合は指標ごとにセルを分けるか、表のパターンを使う
- 説明は2行（36字以内）に収める。入らないときは文字を小さくせず、文言を短くする
- 塗りは1枚だけ。右下は塗らず枠線にする（最終項目の別扱い）。2枚以上塗らない
- 数値は根拠のある実測値だけを入れる。置き数字のまま出さない
