# SLIDE-PATTERN-two-section-stacked-text

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** two-section-stacked-text
**概要：** コンテンツエリアを上下2段に分け、各段を「英字ラベル（KICKER）／見出し18px／本文16px（行間1.8・最大2段落）」の同じ型で組む。段の間は1pxの横罫線（`--sk-line`）。下段だけ `--sk-soft` 地の箱（角丸11px）に入れて、上段＝前提・下段＝主役の主従を付ける。アクセント色の塗りは使わない。
**適したシーン：** 背景と打ち手、概要と方針、前提と結論など、2つのトピックを縦に並べて「下段が主役」と読ませる場面

## Structure（構造）

コンテンツエリア（左右余白48px）の上下中央に、上段（素の本文）→1px横罫線→下段（淡い地の箱）を積む。両段とも中身は左ぞろえ・上ぞろえで同じ型。下段の箱は全幅・角丸11px・内側余白24px。

    structure:
      layout: two-section-stacked
      content_area:
        padding: "24px 48px"
        vertical_align: center      # 見出しON時は上76px以降の上下中央
      upper:                        # 素の本文（塗りなし）
        padding_bottom: 24px
        rule_bottom: 1px            # var(--sk-line)
        elements:
          - kicker: "英字ラベル ／ 補足"   # 10px / 700 / .18em / 大文字 / アクセント色
          - heading                        # 18px / 700 / 行間1.4（12〜20文字）
          - body:                          # 16px / 400 / 行間1.8
              paragraphs: 1〜2             # 段落間 12px
      lower:                        # 主役。淡い地の箱
        margin_top: 24px
        surface: var(--sk-soft)     # 角丸 11px・padding 24px
        elements: 上段と同じ型（KICKER → 見出し → 本文 1〜2段落）
      fill: none                    # アクセント色の塗りは使わない

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| KICKER（上段） | 上段の最上 | `BACKGROUND ／ 背景` のように英字＋日本語補足で段の役割を示す。アクセント色 |
| 見出し（上段） | KICKER の下 | 上段の要点を1文で（18px・700） |
| 本文（上段） | 見出しの下 | 背景・前提・問題提起を1〜2段落（16px・行間1.8） |
| 横罫線 | 段の間 | 1px・`--sk-line`。上段の下端に引く |
| 下段の箱 | 罫線の下 | `--sk-soft` 地・角丸11px。下段を主役として浮かせる。アクセント色で塗らない |
| KICKER・見出し・本文（下段） | 箱の中 | 上段と同じ型。`APPROACH ／ 打ち手` のように結論側を書く |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-two-section-stacked-textのレイアウトで、上段（KICKER「[英字 ／ 補足]」・見出し「[上段見出し]」・本文「[1〜2段落]」）、下段（KICKER「[英字 ／ 補足]」・見出し「[下段見出し]」・本文「[1〜2段落]」）のスライドを作成してください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 下段が主役（結論・打ち手・方針）。上段はその前提。逆にしない
- 本文は各段2段落以内・合計6行以内。入らないときは文字を小さくせず、文言を削るか2枚に分ける
- 下段の箱は `--sk-soft` 地だけ。アクセント色で塗ったり枠線を足したりしない（塗りは使わない）
- 番号付きリストを置きたいときは numbered-list-with-body へ。この構図は文章2段が基本
- 見出しに左バーは付けない（共通見出しの縦バーと重なる）。段の区別は KICKER と罫線・箱で付ける

## v2 での描き直し（2026-09-02）

- 段の間を1pxの横罫線（`--sk-line`）にし、下段だけ `--sk-soft` 地の箱（角丸11px）に入れて主従を付けた（アクセント塗りなし）
- 文字をインク色・palt・禁則・太さ400/700に揃え、左右余白を48pxにし、プレースホルダを具体例（背景 → 打ち手）にした
