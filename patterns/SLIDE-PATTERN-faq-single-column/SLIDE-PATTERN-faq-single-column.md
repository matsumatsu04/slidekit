# SLIDE-PATTERN-faq-single-column

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview

**パターン名：** faq-single-column
**概要：** 3つのQ&Aを1列に縦に並べる。各件は「`Q.01`（英字ラベル風）→質問（太字）→回答」の型で書き、いちばん多い質問の1件目だけ淡い地（`--sk-soft`）の箱に入れて主役にする。2件目以降は細罫線で区切る。アクセント色の塗りは使わない。
**適したシーン：** 重要なよくある質問3点の詳細説明、サービス購入前の懸念事項への回答

## Structure（構造）

コンテンツエリア（左右余白48px）にQ&Aを3件、縦に並べる。1件目は淡い地の箱（角丸12px・padding 20px 24px）、2件目以降は左右24pxの余白で箱と文字の頭を揃え、各件の下に細罫線を引く。中身は左ぞろえに「Q番号（`Q.01 ／ 補足`・10px・英字ラベル風）」「質問（16px・太字・1行）」「回答（16px・1〜2行）」の順。1件目にだけ「例：〜」の注記を添えてよい。ブロック全体は本文エリアの上下中央に置く。

    structure:
      layout: single-column-list
      items: 3
      lead_item:                       # 1件目＝いちばん多い質問
        surface: soft                  # var(--sk-soft) の箱・角丸12px（塗らない）
        order: [q-kicker, question, answer, note]
      other_items:
        surface: none
        rule: bottom 1px               # var(--sk-line)
        order: [q-kicker, question, answer]

## Elements（各要素の役割）

| 要素 | 配置 | 役割 |
|---|---|---|
| Q番号 | 各件の最上段（`Q.01 ／ 補足`） | 質問の番号と分類。英字ラベルの流儀で小さく置く（アクセント色） |
| 質問 | Q番号の下（太字・1行） | 疑問形で短く（16字以内） |
| 回答 | 質問の下（1〜2行） | 結論から言い切る。長い補足は別スライドへ |
| 注記 | 1件目の回答の下 | 「例：〜」で具体を1行添える（11.5px・muted） |
| 淡い地の箱 | 1件目だけ | いちばん多い質問を主役にする。塗りは使わない |
| 細罫線 | 2件目以降の下 | 件と件の区切り |

## Usage Guide（AIへの使い方）

このパターンをAIに指示する際のプロンプト例：

> 「SLIDE-PATTERN-faq-single-columnのレイアウトで、3つのよくある質問と回答を縦に並べてください。各件は `Q.01 ／ 補足`・質問（16字以内の疑問形）・回答（1〜2行・結論から）で書き、1件目をいちばん多い質問にしてください。デザインはSLIDE.mdに従ってください。」

**注意点：**
- 3件が最適。2件の場合も箱と罫線の構成は変えず、上下中央に置く。4件以上は faq-grid を検討する
- 回答は2行（44字以内）に収める。入らないときは文字を小さくせず、文言を短くする
- 淡い地の箱は1件目だけ。すべてを同じ扱いにしたいときは箱を外し、全件を罫線区切りにしてよい
- Q番号は `Q.01 ／ 補足` の形にする。「Q.」だけの大きなラベルにしない

## v2 での描き直し（2026-09-02）
- 3つの枠線ボックス＋「Q.」ラベル横並びを、「`Q.01 ／ 補足`（KICKER型・10px）→質問16px太字→回答16px」の縦積みに変え、1件目だけ `--sk-soft` の箱で主役にした（塗りなし）
- 2件目以降は枠線をやめ、下の細罫線（`--sk-line`）で区切る構成にした。左右余白48px・箱の中と文字の頭を24pxで揃えた
- 回答を12pxから16pxに上げ、文字を v2 の表に揃えた（インク色・palt・禁則・太さ400/700のみ）。プレースホルダを具体例にした
