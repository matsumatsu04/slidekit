SlideKit 導入手順

SlideKitは、スライドの「デザイン」と「構図」を型として固定し、Claude Codeとの会話だけで 統一感のあるスライド（HTML＋PDF）を生成する仕組みです。導入は2ステップ、数分で終わります。

準備するもの

  • Claude Code（ターミナルで claude が起動できる状態）
  • Node.js（バージョン18以上。ビルド・一覧の更新・チェックのツールが使います。node -v で確認）
  • Google Chrome（PDF書き出しに使用。ブラウザ印刷でも代替できます）
  • GitHub CLI（gh）（構図パターンを提案するときだけ必要。スライドを作るだけなら不要）

導入（2ステップ）

1

リポジトリを取得する

ターミナルで次を実行します（フォルダはどこでもOK）。

git clone https://github.com/matsumatsu04/slidekit.git

gitを使ったことがない場合は、GitHubのページ右上の「Code → Download ZIP」からダウンロードして解凍しても動きます （ただし後述の「更新」と「提案」にはgitが必要です。Claude Codeに「gitを入れて」と頼めば導入できます）。

2

そのフォルダでClaude Codeを起動して、話しかける

cd slidekit
claude
スライドを作って

スキルはリポジトリの中（.claude/skills/）に入っているので、コピーや設置は不要です。 slidekit フォルダの中でClaude Codeを起動すれば自動で使えます。

タイトル・対象・目的・枚数などのヒアリングに答え、構成案を承認すると、 index.html（そのまま画面表示できるスライド）と deck.pdf が生成されます。

以前の手順で ~/.claude/skills/ にスキルをコピーした方は、二重登録を避けるため削除してください： rm -rf ~/.claude/skills/slidekit-*

できたスライドの確認・修正・PDF保存

  1. 生成された index.html を スライド確認・修正依頼 のページにドラッグ＆ドロップ
  2. スライドが一覧表示されるので、直したいスライドの下の欄に修正指示を書く（構図を変えたい場合はギャラリーで探したパターンID（P045等）を記入）
  3. 「修正プロンプトを出力」を押してコピーし、そのままClaude Codeに貼り付けると修正版が生成される
  4. 仕上がったら「PDFとして保存（印刷）」からPDF化（印刷ダイアログで「PDFに保存」を選択）
カラーパレット（配色セット）はギャラリー・確認ページのどちらでも試着できます。 気に入った配色があれば、修正プロンプトに自動で含まれるので、そのままClaude Codeに渡せば反映されます。

更新（新しい構図パターンを受け取る）

構図パターンは随時増えます。slidekit フォルダで次を実行するだけです。

git pull

自分で実行しなくても、「スライドを作って」と言った最初にClaude Codeが更新の有無を確認し、 新しいパターンがあれば「更新しますか？」と聞いてくれます（「はい」で反映）。

構図パターンを提案する（任意）

自分で作った構図パターンをギャラリー（誰でも使える公開ライブラリ）に提案できます。 承認されるとギャラリーに載り、SlideKitを使う全員の手元に「更新」で届きます。

  1. 初回のみ：GitHub CLIを導入してログインします（GitHubアカウントが必要）。 
    brew install gh
gh auth login
    （macOS以外は cli.github.com から導入）
  2. Claude Codeで構図パターンを作ります（「構図パターンを作って」）。作った時点で自分の環境ではすぐ使えます。
  3. Claude Codeにこう頼みます。
    このパターンをギャラリーに提案して
    提出前チェック（ダミー文言のみ・素材追加なし等）のあと、Pull Request（提案）が自動で作られ、URLが返ってきます。
  4. 承認されるとギャラリーに反映され、次回の更新確認で手元にも届きます（パターンIDはこの時に確定します）。 修正コメントが付いた場合は、直してもう一度「このパターンをギャラリーに提案して」と言えば同じ提案が更新されます。
提案したパターンはMIT Licenseで公開されます。実案件の文言・社名・人名・画像は入れず、ダミー文言だけで作ってください。 詳しい決まりは CONTRIBUTING にまとめています。 「こういう構図が欲しい」だけの場合は、GitHubのIssue「パターンリクエスト」からどうぞ（対応期限はありません。誰が作ってもOKです）。

うまくいかないとき

  • 「スライドを作って」に反応しない → slidekit フォルダの中で claude を起動しているか確認（pwd の末尾が /slidekit）。別のフォルダで起動しているとスキルが読み込まれません
  • 以前 ~/.claude/skills/ にコピーしたことがある → 二重登録を避けるため rm -rf ~/.claude/skills/slidekit-* で削除し、Claude Codeを再起動
  • ビルドでNode.jsのエラーが出る → node -v が18以上か確認。古い場合は最新のLTS版を導入（Claude Codeに「Nodeを更新して」と頼んでもOK）
  • 更新確認でエラーが出る → ZIPで取得した場合はgit管理外のため更新確認が働きません。git clone で取得し直すか、そのまま使い続けても問題ありません（スライド生成は止まりません）
  • 提案でエラーが出る → gh auth status でログイン済みか確認。未ログインなら gh auth login をもう一度
  • PDFがうまく書き出せない → index.html をChromeで開いて ⌘P →「PDFに保存」でも同じものが得られます
